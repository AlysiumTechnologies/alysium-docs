<span id="what-is-alysium" />

Alysium is an app for creating AI assistants called **agents**, giving them information to answer from and letting people chat with them. You can build a helper for a focused job, try its replies and choose how visitors reach it.

For example, a workshop agent might explain what to bring to a class. You supply the workshop's actual preparation notes and describe how the agent should answer. The agent's replies give you something to check against those notes before sharing it.

## What goes into an agent

An agent brings together several parts:

| Part | What it contributes |
|---|---|
| **Agent Instructions** | The job, audience, answer style and boundaries you want the agent to follow. |
| **Knowledge** | Reference information from files, pasted text or saved website material you attach. |
| **AI model** | The system that uses the setup and available information to produce replies. |
| Visitor chat | The place where people ask questions and read the replies. |

For the workshop example, the instructions could ask for brief, friendly answers and a referral to the workshop organizer when information is missing. The knowledge would contain the real preparation notes. Writing “answer workshop questions” during creation does not supply those facts or connect the agent to a booking system.

Try questions with known answers, a question the source cannot answer and a request outside the agent's job. Compare the replies with your material and instructions, then correct the setup where needed. Each test request should include the context it needs.

## Where you build and organize it

[Home](https://app.alysium.ai/spaces) shows the agents in your current **space**. A space holds your agents, files and plan usage. Select **Build** on the agent's card to open its builder.

- **Build** is where you set the agent's behavior and sources. In its **Settings** view, scroll to **Knowledge** to add reference material.
- **Design** controls the visitor chat's appearance and features. Changes there use **Save Changes**.
- **Deploy** holds publication, access and delivery choices.

[Library](https://app.alysium.ai/library) stores reusable sources organized into projects and folders. Attach the material an agent should use; storing it in Library alone does not give every agent access. The [navigation guide](/help/where-things-are-in-alysium) explains where the other app areas fit.

## How people use an agent

People can chat with available agents in the app, open a standalone chat link or use a chat widget installed on a website. A widget is the chat window visitors open on that site.

A saved draft lets you keep building and testing. Public delivery requires the agent's publication and access settings, plus the chosen delivery method's setup. You can [make an agent live](/share-and-deploy/make-your-agent-live) when it is ready for visitors.

[AgentHub](https://app.alysium.ai/agenthub) is where people discover agents offered by creators. Each offer has its own access and purchase terms. Browsing an offer, buying access and building your own agent are different starting points.

## Choose a first step

If you want to use an existing agent, browse AgentHub and read an offer's purpose, access and price before choosing it.

If you want to build, choose one small job with information you can check. You can [create a complete practice agent](/about-alysium/how-to-get-started) to learn the setup, knowledge, preview and sharing controls. For more ideas, consider [the kinds of helpers you can build](/about-alysium/what-you-can-build-with-alysium) alongside [the current capability limits](/help/what-alysium-cannot-do-yet).
