You can build an agent that explains information you supply or guides a focused conversation. Start with one audience and one useful job, such as answering workshop questions or helping someone think through a plan.

An agent's **instructions** describe its job and behavior. Its **knowledge** supplies reference information, and its **AI model** produces the replies. The projects below are fictional examples you can adapt to your own material.

## An information helper

A workshop FAQ agent could explain what attendees should bring, where to find class notes and whom to contact about a booking. Give it the approved preparation notes and policies as knowledge. Its instructions could ask it to identify the relevant class, answer briefly and refer unanswered questions to the workshop team.

Those two parts serve different purposes. The preparation note contains the actual equipment list; the instructions tell the agent how to explain it. Describing the workshop during creation does not add its real policies automatically.

To find the source controls, open [Home](https://app.alysium.ai/spaces), select **Build** on the intended agent's card, open **Settings** if needed and scroll to **Knowledge**. You can upload a supported document, use **Paste Text** for a short note, attach existing Library material, or add saved website content. A source stored in Library still needs to be attached to the agent. You can [choose the right knowledge source](/knowledge-and-library/give-your-agent-knowledge) as the material grows.

## A guided conversation

An agent can ask questions and organize a discussion. For example, a planning helper could ask what you want to achieve, help you compare possible approaches and turn the discussion into a draft plan for you to review.

Use **Agent Instructions** in Build's **Agent Builder** section to describe the questions, approach and answer style you want. Reusable skills can supply methods and reference material for a type of work. Attaching a skill does not guarantee it will be used in every reply, so try requests that show whether the agent follows the intended approach.

This kind of helper is useful when the conversation itself is the work. An instruction to book an appointment or update a customer account does not give the agent access to the service needed to perform that action.

## A chat people can reach

The builder separates developing an agent from preparing it for visitors:

| Area | What you do there |
|---|---|
| **Build** | Set the job, model and knowledge, then try replies. |
| **Design** | Adjust the visitor chat's appearance and features. Select **Save Changes** after editing and wait for **All Changes Saved**. |
| **Deploy** | Make the agent live and set up a delivery method. |

A [standalone link and QR code](/share-and-deploy/share-your-agent-with-a-link-and-qr-code) let people open the chat directly. A [website widget](/share-and-deploy/put-your-agent-on-your-website) puts it on a site you manage. You can also [prepare a paid offer](/about-alysium/selling-agents-with-alysium).

Each method has its own setup. Making an agent live saves its Published status and Public access; a standalone chat also needs **Direct link** enabled. Designing a widget does not install it on a website, and making the agent live does not create an AgentHub listing.

## Keep the job within the available capabilities

Choose a first task whose important results you can check. For the workshop FAQ, try a question answered by the notes, a question the notes leave unanswered and a request to change a booking. Compare the replies with the source and the agent's instructions.

Use the Build preview beside the settings on a wide screen, or select **Chat Preview** within Build on a smaller screen. Include the context each request needs. Preview messages use the space's credits. If a document-based answer is wrong, check that the intended file is attached and Ready, then save one correction to the source setup or instructions before trying the same request again. You can [plan a broader set of checks](/build-your-agent/test-your-agent-while-you-build) as the agent develops.

Saved website knowledge gives the agent reference content; it does not provide unrestricted live browsing or a way to change another service's records. [Current capability limits](/help/what-alysium-cannot-do-yet) help you assess projects that depend on those actions.

For a complete first project, [build and check a practice café agent](/about-alysium/how-to-get-started).
