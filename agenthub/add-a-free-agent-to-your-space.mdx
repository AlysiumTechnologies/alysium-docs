<span id="add-a-free-agent-to-your-space" />

Add a free AgentHub agent to your active space so you can find it on Home and return to it for a conversation. Free access to the agent is separate from your space's [AI credit allowance](/plans-and-billing/how-credits-work).

## Open the free listing

Open [AgentHub](https://app.alysium.ai/agenthub) and select an agent that offers free access. Read its purpose and access terms to check that it fits the job you have in mind.

## Add the agent

1. On the listing, select **Add to My Agents**.
2. If an account screen opens, complete the offered flow and return to the listing. Select **Add to My Agents** there to start adding it.
3. Wait while the button says **Adding…** and check for the success message.

The installation is saved in your active space. An editable copy opens in the builder, where you can review any setup it needs. A managed agent stays on the listing after it is added.

## Find the installed agent

1. Open [Home](https://app.alysium.ai/spaces).
2. Find the agent's card in your active space.
3. Select **Chat** to open a conversation with it.

The card offers **Build** only when you can edit the copy. A managed agent keeps the setup version you accepted and uses knowledge controlled by its creator, which they can update. An editable copy has its own settings and knowledge in your space.

Adding an agent does not make you its original creator or give you permission to resell it.

<span id="understand-add-copy-and-ownership" />

## If you have already added the agent

The listing's button can change to **Add Copy**. Using it again can reuse or repair the agent already in your space instead of creating a second one. Check Home for the installed agent before using it again.

If the listing says **You own this agent**, open your original agent from Home.

## If adding fails

If you see **Failed to add agent. Please try again.**, check Home for the installation before retrying the listing's add action. If you still cannot add or find it, email [support@alysium.ai](mailto:support@alysium.ai) with the agent's name, the action you tried and the message shown.
