Add an available free AgentHub agent to your active space so you can return to it later. Adding gives you an installation of someone else's agent; it does not make you the original creator.

Adding requires a named account with an active space. You cannot add your own listing this way. Read the free offer's access terms first: some installed agents allow editing, while managed copies are for chatting and do not open the builder. Free access does not promise unlimited platform usage.

## Open the free listing

**Already on the intended free agent's page?** Continue with [Add the agent](#add-the-agent).

1. Open [AgentHub](https://app.alysium.ai/agenthub).
2. Select the free agent you want.
3. Read its purpose and access details.
4. Continue with [Add the agent](#add-the-agent).

The link opens the general marketplace. You choose the agent there. Browsing alone does not add anything.

## Add the agent

1. Select **Add to My Agents**.
2. If asked, use the offered sign-in or account-creation flow.
3. If you used an account flow, follow its offered continuation back to the agent.
4. Wait for the adding action to finish.
5. Continue with [Find the installed agent](#find-the-installed-agent).

If you need help with the account step, follow [Sign in to Alysium](/getting-started/sign-in-to-alysium) or [Create an Alysium account](/getting-started/create-an-alysium-account). Return through the offered continuation afterward.

## Find the installed agent

An editable installation can open the builder directly. If that happens, review any setup needed for the copy. A managed copy uses the available agent/chat destination instead; the absence of a builder redirect does not establish that adding failed.

To find it again:

1. Open [Home](https://app.alysium.ai/spaces).
2. Find the installed agent in your active space.
3. Open its available agent or chat destination.

Do not assume an agent can be edited just because it appears in your space. For chatting steps, follow [Chat with your agents](/share-and-deploy/chat-with-your-agents).

## Understand Add Copy and ownership

After an installation, the action can change to **Add Copy**. Selecting it adds another copy. Check Home for the first installation before using it again.

If the page says **You own this agent**, open your existing source agent from Home. To make your own assistant instead, follow [Create your first agent](/build-your-agent/create-your-first-agent).

If adding fails, read the displayed error. Check the account and active space, then check Home for the installation before retrying. See [How credits work](/plans-and-billing/how-credits-work) if you can access the agent but have questions about conversation usage.
