Find an agent for a task you want help with, then read its listing to decide whether to try it or add access. AgentHub contains assistants made by creators for different jobs.

## Search for a task

1. Open [AgentHub](https://app.alysium.ai/agenthub).
2. In the **Search agents...** box, type a short topic or task, such as writing or study help.
3. Read the updated result count and agent cards.
4. Select a promising card to open its listing.

Search checks agent names, descriptions and tags as you type. You do not need to submit the search or save it. On the listing, compare the agent's purpose, creator and access terms; you can [check what the listing's details mean](/agenthub/read-an-agents-page) when weighing an offer.

## Narrow or reorder results

Select **Filters** to show **Categories** and **Price**. Choose the available chips that fit what you want. You can select more than one category or price option, and the results update as you change them. Use **Show more** if it is offered to reveal additional categories.

For example, search for writing and choose a free price option if one is available. Read the listing's terms before [adding a free agent to your space](/agenthub/add-a-free-agent-to-your-space).

To reorder the results, open the sort menu and choose **Newest** for recently created agents first or **Highest Rated** for higher-rated agents first. A high rating does not tell you whether the agent fits your particular task, so read its description before choosing it.

To broaden the results, deselect selected chips. The × control beside Categories or Price clears that group's choices.

## If the list is empty or fails to load

- **No agents found:** shorten or delete the search text and remove category or price choices. You can use **Clear all filters** to clear the applied filters; delete any text that remains in the search box before starting a new search.
- **Failed to load agents:** select **Try Again** to reload the list. This message means the agents did not load, rather than that your search had no matches.
