AgentHub is Alysium's collection of agents from creators. An agent is a chat assistant made for a particular job. Search for a task you want help with, then read a promising listing before deciding whether to add or buy access.

You can browse without building your own agent. Adding an agent or buying access requires a named account.

## Search for a task

**Already in the marketplace?** Start at step 2 below.

1. Open [AgentHub](https://app.alysium.ai/agenthub), or select **Agenthub** in the sidebar.
2. Find **Search marketplace agents** in the marketplace section.
3. Enter a short topic, such as writing or study help.
4. Read the updated result count and cards.
5. Select a relevant card.
6. Continue with [Read an agent's page](/agenthub/read-an-agents-page).

Search updates as you type. There is no Save or Search submission to complete. Use the marketplace's search box; other searches in the app may search a different collection.

## Narrow or reorder results

The available categories and price choices come from the marketplace. More criteria can leave fewer matches. A sort order describes marketplace activity; it does not establish that an agent fits your task.

1. Select **Filters**.
2. Select an available category or price choice that fits what you want.
3. Check the updated results.
4. Use the sort menu if you want an offered order such as **Most Popular**, **Highest Rated** or **Newest**.
5. Select a promising card.
6. Follow [Read an agent's page](/agenthub/read-an-agents-page) to compare its purpose and offer.

For example, search for writing, then apply a free-price choice if available. Read the listing's actual access terms before adding it.

## If the list is empty or fails to load

| Message | What to do |
|---|---|
| **No agents found** | Simplify the search or remove criteria. Use **Clear all filters** to return to an unfiltered list, then try a broader task. |
| **Failed to load agents** | Select **Try Again**. A loading failure is different from a search that completed without matches. |

Browsing, filtering and sorting do not purchase anything. Once you find a suitable listing, you can [try an offered preview](/agenthub/try-an-agent-for-free), [add an available free agent](/agenthub/add-a-free-agent-to-your-space), or read the paid offer before subscribing.
