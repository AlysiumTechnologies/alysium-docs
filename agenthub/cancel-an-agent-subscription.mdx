Stop a paid agent subscription from renewing and check when access will end. Your space's Alysium Pro plan is [managed separately](/plans-and-billing/cancel-pro).

## Find the correct record

1. Open [Billing](https://app.alysium.ai/spaces?settings=billing), which opens settings for your active space.
2. Wait for the details to load, then scroll to **Agent Access and Subscriptions**.
3. Match the agent and creator names, and read the card's access description and status.

A paid subscription has a recurring fee. **Access without a subscription** and **Legacy access** describe grants with no linked recurring agent subscription. An active paid subscription offers **Unsubscribe**; an active grant offers **Remove access**. These actions end access at different times.

## Stop a paid renewal

Canceling a paid subscription keeps access through the current paid period and stops its renewal. It does not refund a charge already made; [requesting a payment review](/agenthub/get-a-refund-for-an-agent-subscription) is a separate task.

1. Select **Unsubscribe** on the intended agent's card.
2. Read **Cancel subscription?**, including the period-end date if shown.
3. Select **Unsubscribe** in the confirmation to proceed. Choose **Keep subscription** if you want to leave the renewal in place.
4. Wait for **Agent subscription will end after the current billing period.** Check that the card shows **Ending** with a date, or **Ending at period end**.

The confirmation and resulting card state let you check that cancellation was scheduled. Closing the confirmation alone does not complete it.

## Remove an access grant

Removing a grant ends that access immediately. Use this path when the card offers **Remove access**.

1. Select **Remove access** on the intended card.
2. Read **Remove agent access?** and its immediate-access warning.
3. Select **Remove access** in the confirmation to proceed. Choose **Keep access** if you want to keep the grant.
4. Wait for **Agent access was removed.** Check that the card shows **Access removed**.

There is no linked recurring agent subscription on this grant, so this action removes access rather than canceling a renewal.

## Understand a later resubscription

After access ends, an eligible card may offer **Re-subscribe**, **Subscribe** or **Retry checkout**. The action opens the agent's current listing, where you can review the offer before [subscribing again](/agenthub/subscribe-to-an-agent). The current price and terms may differ from your previous subscription.

**Re-subscribe** is for eligible ended access. It does not undo a cancellation that is still scheduled for the end of the paid period.

## Check an unclear result

If Billing shows an error or you cannot confirm the change, reopen [Billing](https://app.alysium.ai/spaces?settings=billing), wait for it to load and find the same agent under **Agent Access and Subscriptions**. Read its current status and dates before repeating the action.

If the result is still unclear, email [billing@alysium.ai](mailto:billing@alysium.ai) with the agent and creator names, the displayed status and any error message.
