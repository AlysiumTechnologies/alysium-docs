Stop renewal of a paid agent subscription and check when its access ends. This is separate from canceling your space's Alysium Pro plan.

Use the account that holds the agent subscription or access grant. A paid subscription has a recurring fee. **Access without a subscription** and **Legacy access** describe grants without a linked recurring agent subscription; removing one ends that grant immediately.

## Find the correct record

**Already viewing the intended agent's Billing card?** Continue with [Stop a paid renewal](#stop-a-paid-renewal), or [Remove an access grant](#remove-an-access-grant) if that is what the card describes.

1. Open [Billing](https://app.alysium.ai/spaces?settings=billing).
2. Find **Agent Access and Subscriptions**.
3. Match both the agent and creator names.
4. Read the card's access description and status.
5. Continue with [Stop a paid renewal](#stop-a-paid-renewal) for a subscription, or [Remove an access grant](#remove-an-access-grant) for a grant.

Billing opens settings for your active space. Choose the record for the agent you intend to stop using.

## Stop a paid renewal

Ordinary cancellation keeps access until the current paid period ends, then stops renewal. It does not return a payment already made. For that separate task, use [Get a refund for an agent subscription](/agenthub/get-a-refund-for-an-agent-subscription).

1. Select **Unsubscribe** on the intended card.
2. Read **Cancel subscription?** and the period-end date if shown.

Select **Keep subscription** to leave it active. To confirm cancellation:

1. Select **Unsubscribe** in the confirmation.
2. Wait for the result.
3. Check the card's **Ending** state and end date.

You can retain access for the remainder of that paid period. The ending state does not mean a refund was issued.

## Remove an access grant

Use this path for a card offering **Remove access**. Unlike a paid cancellation at period end, grant removal takes effect immediately.

1. Select **Remove access** on the intended card.
2. Read **Remove agent access?**.

Select **Keep access** to leave the grant in place. To proceed:

1. Select **Remove access** in the confirmation.
2. Wait for the result.
3. Look for **Agent access was removed.**
4. Check the card's **Access removed** state.

If the result is unclear or an error appears, use [Check an unclear result](#check-an-unclear-result).

## Understand a later resubscription

An ended subscription can offer **Re-subscribe** when the listing still permits purchases. That opens a new checkout at the current offer. It does not guarantee your older price or undo a scheduled cancellation before it ends.

Read the current amount before paying. Follow [Subscribe to an agent](/agenthub/subscribe-to-an-agent) if you decide to buy access again.

## Check an unclear result

1. Reopen [Billing](https://app.alysium.ai/spaces?settings=billing).
2. Find the intended agent under **Agent Access and Subscriptions**.
3. Read its current status and dates before repeating the action.

If you still cannot confirm the result, contact billing@alysium.ai with the agent and displayed state. See [Manage your agent subscriptions](/plans-and-billing/manage-your-agent-subscriptions) for the card's other meanings. Use [Cancel Pro](/plans-and-billing/cancel-pro) only if you also intend to stop the separate space plan.
