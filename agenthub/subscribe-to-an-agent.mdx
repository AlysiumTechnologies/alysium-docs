Buy access to a paid AgentHub agent, then wait for confirmed access before using its installed chat. This purchase is separate from your space's Alysium Pro plan.

A purchase needs a named account, an active space and a payment method. You cannot buy your own agent. Use the space where you want the installation, and read the agent's purpose and creator details before paying.

The monthly access fee, included **Premium Allowance** and usage-rate explanation are separate parts of the offer. Compare them together; a lower monthly fee alone does not describe all the usage terms. Use the actual checkout price rather than an old message or screenshot.

## Open checkout

- **Already in the intended agent's subscription window?** Continue with [Review the offer and pay](#review-the-offer-and-pay).
- **Already see You're subscribed?** Continue with [Start using the installed agent](#start-using-the-installed-agent).
- **Already on its listing?** Select **Subscribe**, then continue with [Review the offer and pay](#review-the-offer-and-pay).

From elsewhere:

1. Open [AgentHub](https://app.alysium.ai/agenthub).
2. Select the intended agent.
3. Select **Subscribe**.
4. Continue with [Review the offer and pay](#review-the-offer-and-pay).

AgentHub opens the marketplace; you choose the listing there. If asked to create an account or sign in, use the offered continuation back to that listing. Continue with [Review the offer and pay](#review-the-offer-and-pay) if the subscription window opens; otherwise, select **Subscribe** on the listing to open it.

If checkout asks you to select a space, open [Home](https://app.alysium.ai/spaces) to return to your active space. Then follow [Open checkout](#open-checkout) to return to the intended agent's subscription window.

## Review the offer and pay

1. Confirm the agent and creator names in the subscription window.
2. Read the displayed monthly fee, included usage and rate explanation.
3. Enter the payment information requested by the secure payment form.
4. Select the subscription confirmation button, which includes the displayed price when available.
5. Complete any additional payment verification requested.
6. Wait for confirmation that access is active.
7. When **You're subscribed** appears, continue with [Start using the installed agent](#start-using-the-installed-agent).

Opening checkout or entering card details does not confirm active access. For a processing or pending state, use [Check pending payment or missing access](#check-pending-payment-or-missing-access) before opening another checkout.

## Start using the installed agent

1. On **You're subscribed**, select **Start chatting**.
2. Check that the intended installed agent opens.
3. Follow [Chat with your agents](/share-and-deploy/chat-with-your-agents) to send a question.

When you return to the listing later, **Chat Now** can take you back to that installation.

To inspect the subscription:

1. Open [Billing](https://app.alysium.ai/spaces?settings=billing).
2. Find **Agent Access and Subscriptions**.
3. Match the agent and creator names.
4. Read the subscription state and included usage.

Billing opens your active space's settings. See [Manage your agent subscriptions](/plans-and-billing/manage-your-agent-subscriptions) for the card's other meanings.

## Check pending payment or missing access

Read the payment notice or error. Open [Billing](https://app.alysium.ai/spaces?settings=billing) and find the intended agent under **Agent Access and Subscriptions** to check status before starting another checkout. Complete any offered verification and wait for active confirmation.

If a confirmed payment still has no access, contact billing@alysium.ai with the agent and confirmation reference. For payment warnings, follow [Fix a failed payment](/plans-and-billing/fix-a-failed-payment).

Use [Cancel an agent subscription](/agenthub/cancel-an-agent-subscription) if you want to stop a future renewal. See [How credits work](/plans-and-billing/how-credits-work) for questions about usage.
