Use an offered marketplace preview to see how a paid agent responds before subscribing. A preview is a limited set of messages, not an ongoing subscription or permanent free access.

The creator chooses whether preview messages are available. Read the listing's purpose first so you can ask a useful sample question.

## Find the offered preview

**Already in the intended agent's preview chat?** Continue with [Try a relevant question](#try-a-relevant-question).

1. Open [AgentHub](https://app.alysium.ai/agenthub).
2. Select the paid agent you want to try.
3. Find the preview conversation if one is offered.
4. If a preview is offered, continue with [Try a relevant question](#try-a-relevant-question).

AgentHub opens the marketplace. You choose the agent there. If no preview is offered, use [Read an agent's page](/agenthub/read-an-agents-page) to compare its purpose, offer and reviews. There is no free trial button promised for every agent.

## Try a relevant question

Use a small question related to the agent's stated job. For a fictional writing agent, you might supply a short, nonprivate announcement and ask for a friendlier customer message. Compare its answer with your request; this example does not claim a particular writing agent is listed.

1. Read any remaining-preview notice.
2. Enter your question in the message box.
3. Select the arrow button labelled **Send message**, or press Enter.
4. Wait for the reply.
5. Read the reply and updated preview notice.

You have completed the trial task when you have inspected the sample reply and can decide whether to review the offer further. There is no configuration to save.

## When preview messages are spent

A paywall can offer a subscription when the included preview ends. Sending a preview message does not subscribe you or automatically charge you.

You can stop without paying. If you want to continue as a buyer, read the monthly fee, included allowance and usage-rate explanation, then follow [Subscribe to an agent](/agenthub/subscribe-to-an-agent).

## If the preview cannot send

Read the exact notice. A spent preview, unavailable listing, pending payment and creator usage pause are different states. Follow [Free preview and paywall messages](/help/free-preview-and-paywall-messages) for the relevant next action.

If you already paid, check your installed agent and its record in **Billing** → **Agent Access and Subscriptions**. The public preview allowance is separate from your paid subscription allowance. Use [Manage your agent subscriptions](/plans-and-billing/manage-your-agent-subscriptions) to find that record.
