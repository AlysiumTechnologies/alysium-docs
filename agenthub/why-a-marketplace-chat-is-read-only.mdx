A read-only marketplace conversation lets you inspect existing messages but prevents another turn through that agent. The visible history does not establish that the subscription or listing is still active.

Read the chat's notice first. Pending payment, ended access, an unavailable listing and a disabled agent need different responses. Deleting the history does not restore access.

## Find the affected conversation

If you are already viewing its notice, continue with [Payment is pending](#payment-is-pending), [The subscription ended](#the-subscription-ended), or [The listing or agent is unavailable](#the-listing-or-agent-is-unavailable), according to what it says.

To reopen it from elsewhere, use the navigation sidebar in Chat. It is available on the agent-selection screen as well as while a conversation is open.

1. Open [Chat](https://app.alysium.ai/chat).
2. On a narrow screen, select **Conversations and agents** to open the sidebar.
3. Select **Conversations** in the sidebar.
4. Select the affected saved conversation.
5. Read the exact notice.

You can select the saved conversation even when the agent's start action is unavailable. For other main-chat controls, see [Chat with your agents](/share-and-deploy/chat-with-your-agents).

## Payment is pending

A pending-payment notice means access has not been confirmed. **Return to checkout**, when offered, revisits the listing. Complete any requested payment verification, then wait for active confirmation.

Check the existing purchase using [Check the agent's Billing record](#check-the-agent%E2%80%99s-billing-record) before starting another checkout. Entering card information alone does not prove that access is active. For a payment error, follow [Fix a failed payment](/plans-and-billing/fix-a-failed-payment).

## The subscription ended

An ended-subscription notice means the access behind that conversation is no longer active. Existing messages can remain readable.

[Check the agent's Billing record](#check-the-agent%E2%80%99s-billing-record). If the listing still offers a new subscription, review its current offer before buying again. A new checkout does not guarantee the price of an older subscription. Follow [Subscribe to an agent](/agenthub/subscribe-to-an-agent) if you decide to proceed.

## The listing or agent is unavailable

A notice that the listing is unavailable or the creator disabled the agent concerns availability. Paying again is not a reliable remedy.

Open [AgentHub](https://app.alysium.ai/agenthub) and look for the named agent's current page to check availability. If you already paid and need help, contact the creator through an available published contact route or contact billing@alysium.ai.

## Check the agent's Billing record

Use the account that obtained the access.

1. Open [Billing](https://app.alysium.ai/spaces?settings=billing).
2. Find **Agent Access and Subscriptions**.
3. Match both the agent and creator names.
4. Read its current checkout/access status.
5. Follow the notice's checkout or billing action when offered.
6. Reopen the affected conversation after the access state is confirmed.

The Billing link opens your active space's settings. Check the account and space used at checkout if the record is missing. Use [Manage your agent subscriptions](/plans-and-billing/manage-your-agent-subscriptions) for the card's other meanings.

A subscription-ended notice differs from a spent free preview. A creator-disabled notice differs from your space running out of credits. If active access still conflicts with the chat notice after reopening, report the agent, state and exact message to billing@alysium.ai.
