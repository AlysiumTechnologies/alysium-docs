<span id="why-a-marketplace-chat-is-read-only" />

A read-only marketplace conversation keeps existing messages available but stops you from sending another message. Read the notice in the chat to understand whether payment, subscription access or agent availability is blocking it.

A managed agent's locked setup is a different restriction: you can chat with an active managed agent even though you cannot edit its configuration. A managed installation keeps its purchased setup and uses the creator's current knowledge. An editable installation has its own setup and knowledge in your space.

## Find the affected conversation

Open [Chat](https://app.alysium.ai/chat). On a narrow screen, select **Conversations and agents** to open the navigation sidebar. Select the saved conversation you want to read from the list.

If you are already viewing an agent's chat, select the sidebar's **Conversations** tab if another tab is selected, then choose the saved conversation. You can reopen saved history even when starting a new chat with that agent is unavailable. Read the notice above the disabled message box; deleting the conversation will not restore access.

## Payment is pending

A notice that says **Your payment is still pending. Complete checkout to start chatting.** means access has not yet been confirmed.

Check the existing purchase in Billing before making another payment. **Return to checkout**, when offered in the chat, takes you back to the agent's listing. Complete any payment verification requested, then wait for confirmed access before reopening the conversation. Entering card details alone does not establish active access.

If payment was confirmed but the chat remains blocked, keep the confirmation reference for a billing enquiry.

## The subscription ended

The notice **This subscription is no longer active. Existing conversations are now read-only.** means the access associated with this conversation is no longer active. You can still read its existing messages.

Check the agent's Billing record. If it offers **Re-subscribe**, that action returns to the current listing. Review the current price and allowance before buying again; an older subscription's terms are not guaranteed. You can [review how subscribing works](/agenthub/subscribe-to-an-agent) before committing to the new offer.

## The listing or agent is unavailable

The chat can say **This marketplace listing is no longer available. Existing conversations are now read-only.** or **This agent has been disabled by its creator. Existing conversations are now read-only.**

These notices describe an availability restriction on the conversation you opened. Look for the named agent in [AgentHub](https://app.alysium.ai/agenthub) to check its current listing. Buying again is not a reliable way to resolve an unavailable agent. Keep the history, and contact billing if paid access appears to conflict with the notice.

A more general notice can say **You no longer have access to chat with this agent. Your existing conversation remains available as read-only history.** Check the associated subscription record to understand its current access state.

<span id="check-the-agents-billing-record" />

## Check the agent's Billing record

1. Open [Billing](https://app.alysium.ai/spaces?settings=billing). It shows your active space; use the space where you obtained the agent.
2. Scroll to **Agent Access and Subscriptions** and match both the agent and creator names.
3. Read the checkout or subscription status and use any relevant action offered on that record.
4. After access is confirmed active, reopen the saved conversation in Chat and check whether you can send again.

For example, **Checkout pending** needs confirmation, while **Subscription ended** describes ended access. A **Re-subscribe**, **Subscribe** or **Retry checkout** action takes you to the current listing to review its offer. You can [read the subscription card's other details](/plans-and-billing/manage-your-agent-subscriptions) without starting another purchase.

If active access still conflicts with the chat notice after reopening, email [billing@alysium.ai](mailto:billing@alysium.ai) with the agent and creator names, the Billing status, the exact chat notice and any payment confirmation reference.
