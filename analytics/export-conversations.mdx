Download a text or CSV copy of a conversation, or request a broader download from one agent. Open and inspect the actual file before relying on it: exports can have missing message text and are not guaranteed to contain a complete history.

<span id="start-where-you-are" />
<span id="i-cannot-see-export" />

## Find the conversation

1. Open [Analytics](https://app.alysium.ai/analytics) and select the intended agent under **Your Agents**. Check its name on the detail page.
2. Open **Conversations**, or **Chats** on a smaller screen, to see **Recent Conversations**.
3. Select the conversation and wait for its messages to appear. Check the question and answer to confirm it is the conversation you want.

On a smaller screen, selecting a row switches to **Messages** or **Msgs**. The **Export** button is in the message viewer's header. If you are already reading the intended conversation, you can use that button there.

You can [search the message text](/analytics/search-conversations) or [filter the list by date](/analytics/filter-conversations-by-date) to find a conversation. Turn on **Show teammate conversations** to include your own practice chats. After changing a search or filter, select the intended row; the previously opened messages can remain on screen.

## Choose a format and understand its limits

| Format | Useful for |
|---|---|
| **Export as Text** | A `.txt` file laid out as a transcript, with role and timestamp information. |
| **Export as CSV** | A `.csv` file with message rows for a spreadsheet, preceded by metadata comment lines. |

Both formats can show **No content available** in place of message text, even when the message is readable in Alysium. Do not rely on changing formats or repeating the download to restore that text. Long conversations and large downloads are also not guaranteed to include every message or conversation. Compare the actual contents before using the file as a record.

The files can contain private messages, names and conversation or agent identifiers. Feedback notes are not included. Downloading keeps the originals in Alysium; anyone you share the local copy with can read its contents.

## Download one conversation

1. In the message viewer's header, select **Export**, then **Download Conversation**.
2. Under the **Current Conversation** heading, select **Export as Text** or **Export as CSV**. Choosing the format starts the download.
3. Open the downloaded file from your browser's downloads. Check the conversation information and compare the message text with the messages displayed in Alysium, looking for missing text or gaps.

The file's name begins with `conversation-`. Your browser may save it automatically or ask where to save it. Opening the right file and checking its contents completes the export check; a completed browser download alone does not establish that all its text is present.

## Download several conversations

**Bulk Download** requests a broader set of accessible conversations with messages from this agent. It is not limited to the conversations currently shown in the list. It ignores the current search, date range and **Show teammate conversations** setting. Your own practice conversations can be included even when the list hides them. If you need only particular matches, export those conversations individually.

1. Open a conversation's messages so the viewer header is visible. Select **Export**, then **Bulk Download**.
2. Under the **All Conversations** heading, select **Export as Text** or **Export as CSV**.
3. Wait while the menu shows **Preparing export...**.
4. Open the resulting file, whose name begins with `bulk-export-`. It is one combined text or CSV file. Check which conversations and messages it actually contains before using or sharing it.

The number shown in the menu is not a confirmed count of conversations in the downloaded file. Empty conversations and conversations whose details could not be read can be left out. A bulk download does not guarantee an exhaustive archive.

## If you get stuck

### I cannot find the file

Open **Downloads** from your browser's menu and look for the recent `conversation-` or `bulk-export-` file with a `.txt` or `.csv` extension. Wait for an active download to finish, then open it. If no file was downloaded, return to the loaded conversation and repeat the intended export action.

### Alysium reports an export error

If you see **Failed to export conversation. Please try again.** or **Failed to export conversations. Please try again.**, check that the selected conversation's messages have loaded, then retry the same export action. For a bulk download, check that you selected the intended agent and can read its conversations.

### The file has missing text or conversations

If the file contains **No content available**, or appears incomplete, compare it with the messages you can read in Alysium. Contact [support@alysium.ai](mailto:support@alysium.ai) with the agent's name, whether you used **Download Conversation** or **Bulk Download**, the chosen format and what was missing from the result. Changing the format or retrying is not a dependable repair for missing message text.
