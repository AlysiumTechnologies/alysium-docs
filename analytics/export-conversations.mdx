Keep a copy of a conversation on your device. Choose a text file to read the messages, or a CSV file to use in a spreadsheet.

## Start where you are

- **Already reading the conversation's messages?** Continue with [Download one conversation](#download-one-conversation).
- **Already on the right agent's Analytics page?** Select the conversation under **Recent Conversations**. Wait for its messages to appear. Continue with [Download one conversation](#download-one-conversation).
- **Somewhere else?** Start with [Find the conversation](#find-the-conversation).

On a small screen, select a conversation under **Chats**. Open **Msgs** to see its messages.

## Find the conversation

1. Open [Analytics](https://app.alysium.ai/analytics).
2. Under **Your Agents**, select the agent whose conversation you want to download.
3. Under **Recent Conversations**, select the conversation.
4. Wait for its messages to appear in **Conversation Messages**.
5. Continue with [Download one conversation](#download-one-conversation).

The Analytics link opens the general area. You choose your own agent and conversation there. If it opens a sign-in page, sign in. Open Analytics again if needed.

## Download one conversation

Check the messages to make sure you selected the right conversation. The download includes that conversation's messages.

Choose the format that suits your task:

| Format | Use it for |
|---|---|
| **Export as Text** | Reading or keeping a transcript as a `.txt` file. |
| **Export as CSV** | Working with message rows in a spreadsheet as a `.csv` file. |

1. In the message viewer's header, select **Export**.
2. Select **Download Conversation**.
3. Under **Current Conversation**, select **Export as Text** or **Export as CSV**.
4. Open the downloaded file.
5. Check that it contains the conversation you intended to keep.

Your browser may save the file automatically or ask where to save it. You are finished when you can open the correct file.

## Download several conversations

Use **Bulk Download** for a broader download from the selected agent. It includes accessible conversations with messages; empty conversations are not included.

**Need only certain conversations?** Download them individually using [Download one conversation](#download-one-conversation). Bulk Download ignores the current search, date filter, and **Show teammate conversations** setting, if that setting is present.

1. In the message viewer's header, select **Export**.
2. Select **Bulk Download**.
3. Under **All Conversations**, select **Export as Text** or **Export as CSV**.
4. Wait while the menu shows **Preparing export...**.
5. Open the downloaded file.
6. Check its contents before using it as a report or sending it to someone.

## If you get stuck

### I cannot see Export

1. Select a conversation under **Recent Conversations**, or **Chats** on a small screen.
2. Wait for its messages to appear.
3. On a small screen, open **Msgs**.
4. Continue with [Download one conversation](#download-one-conversation).

### I cannot find the file

1. Open **Downloads** from your browser's menu.
2. Look for a recent `.txt` or `.csv` file.
3. If it is still downloading, wait for it to finish.
4. Open the completed file.

If there is no new file, return to Alysium. Retry the steps in [Download one conversation](#download-one-conversation) or [Download several conversations](#download-several-conversations).

### Alysium reports an export error

1. Check that the conversation's messages load.
2. Retry the export.

For a bulk export, check that the agent has accessible conversations with messages.

### The file includes more than I wanted

Check whether you chose **Bulk Download**. Use [Download one conversation](#download-one-conversation) for each conversation you want to keep.

Downloading does not delete the original conversation. Anyone you send the downloaded file to can read its contents.

Use [Search conversations](/analytics/search-conversations) to find another exchange, or [Who can see which conversations](/analytics/who-can-see-which-conversations) to understand access and downloaded copies.
