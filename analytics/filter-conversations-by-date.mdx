<span id="filter-conversations-by-date" />

Review an agent's conversations from the days you want to investigate. The list's dates follow user activity: a conversation started earlier can appear if the visitor returned during your chosen range.

The date control in **Recent Conversations** filters the list. The header's **Period** controls its summary numbers separately. A keyword search covers all time, so clear it before choosing dates.

## Open the conversation list

1. Open [Analytics](https://app.alysium.ai/analytics) and select the intended agent under **Your Agents**. Check its name on the detail page.
2. Open **Conversations**, or **Chats** on a smaller screen, to see **Recent Conversations**.

## Choose a date range

1. If **Search conversations...** contains text, select its **Clear search** X. While a search is active, **Searching all conversations** replaces the calendar.
2. Select **Filter by date range**, or the dates already displayed in that control.
3. Use the calendar's month arrows to reach the month you need. Select your start day, then your end day.
4. Check that the control shows both intended dates. Click outside the calendar or press Escape to close it.

The dates apply immediately; there is no Apply or Save step. The list can change after the first selection, so confirm both endpoints before reading it.

Both selected days are included, using your local calendar days. Matching follows the latest user message before the range ends, rather than the date the conversation was created. Results stop at the page's current activity snapshot.

## Read the filtered list

Select a matching row to read that conversation's messages. Changing the list's dates can leave the previously selected conversation open, so select a result even if messages are already visible. On a smaller screen, selection switches to **Messages** or **Msgs**; **Back to conversations** returns to the list. Scroll inside the list to load older matching rows.

To include your own practice chats, turn on **Show teammate conversations**. In your current space this includes you, its owner. It changes the list and search results; the summary metrics still describe visitors.

Custom list dates do not change the summary cards. The header's **Period** offers **Last 7 days**, **Last 30 days** and **Last 90 days**, which are rolling windows. Changing Period restores the list to that period and clears a custom range, although typed search can still cover all time. The **View** action on the header's **Conversations** card clears search and restores the list to the selected Period.

To keep only the matching conversations, [export each conversation individually](/analytics/export-conversations). **Bulk Download** ignores the list's dates and search.

## Clear the date range

Open the date control and select **Clear Date Filter** in the calendar. You can also select the X labelled **Clear date filter** beside the active range. Check that the dates disappear and the list refreshes: clearing the range returns the list to all time.

## If the list is empty or the dates seem ignored

Check the selected agent's name and both dates. If **Searching all conversations** is showing, clear the search to return to the dated list. For your own practice chat, turn on **Show teammate conversations**. Clear the date range to look for activity outside those days.

An empty result can mean no conversations match. If the list instead says **Couldn't load these conversations.**, select its **Retry** to retry that read. If an older page of results fails while scrolling, use the Retry beside that failure.
