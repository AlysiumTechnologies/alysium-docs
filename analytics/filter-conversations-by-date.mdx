title: "Filter conversations by date"
description: "Narrow one agent's conversation list to a date range, check the filtered results and clear the range when you need the ordinary list again."
keywords: ["Alysium", "Filter conversations by date", "Analytics"]
---

Narrow an agent's conversation list to the dates you want to review.

The date control inside **Recent Conversations** changes the list. The summary's **Period** control changes its activity cards. These can show different ranges. Clear any keyword search before choosing list dates: an active search covers all time and can hide the calendar.

**Already on the right agent's Analytics page?** Continue with [Choose a date range](#choose-a-date-range).

## Open the conversation list

1. Open [Analytics](https://app.alysium.ai/analytics).
2. Under **Your Agents**, select the intended agent.
3. Open **Conversations**, or **Chats** on a smaller screen, if the list is hidden.
4. Continue with [Choose a date range](#choose-a-date-range).

The link opens the Analytics overview, where you choose your own agent. If it asks you to sign in, sign in. Open Analytics again if needed.

## Choose a date range

1. Under **Recent Conversations**, clear any text in **Search conversations...** with its **Clear search** X control.
2. Select **Filter by date range**, or the dates already shown in that control.
3. Use the calendar's month navigation if your dates are not visible.
4. Select the start day.
5. Select the end day.
6. Check that the control displays both intended dates.
7. Click outside the calendar or press Escape to close it.

The dates apply as you select them; there is no Apply or Save step. The list can update after the first day, so check both endpoints before reading the results.

For example, to review a fictional workshop held on October 10 and 11, select October 10 as the start and October 11 as the end in the relevant year. Use your own event dates when following these steps.

## Read the filtered list

Select a matching conversation to read its messages. On a small screen, open **Msgs** if needed. Read the question and reply together to confirm that you found the exchange you wanted.

If **Show teammate conversations** is available, turn it on to include your own practice chats. This setting includes you as the space owner; your space currently has no other members. It changes the conversation list, while the summary metrics continue to describe visitors.

The summary cards can still show **Last 7 days**, **Last 30 days** or **Last 90 days**. Choosing a custom list range does not change those cards. Selecting the summary's Conversations **View** action or changing its period can return the list to that summary period.

## Clear the date range

1. Open the date-range control.
2. Select **Clear Date Filter** in the calendar.
3. Check that the custom range disappears and the list refreshes.

The X beside an active date control, labelled **Clear date filter**, performs the same action. Clearing the custom range returns the list to all time.

Filtering changes a view of existing messages. It does not delete or rewrite them. The range can be retained when you navigate within the page.

## If the list is empty or the dates seem ignored

1. Check that **Search conversations...** is empty.
2. Check that both intended dates appear in the date control.
3. Check the selected agent's name.
4. Turn on **Show teammate conversations**, if available, when looking for your own practice chat.
5. [Clear the date range](#clear-the-date-range) to check for conversations outside it.

An empty range can mean there are no matching chats. If a failed-read message offers **Retry**, select it to retry that read.

To keep copies of matching chats, use [Export conversations](/analytics/export-conversations). **Bulk Download** does not use the date or search filter: download conversations individually when you need only the ones in your chosen range.
