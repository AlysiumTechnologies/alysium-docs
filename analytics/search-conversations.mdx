Find an agent's saved conversations by a word in a question or reply, then read the exchange to check that it is the one you wanted.

## Open the conversation list

1. Open [Analytics](https://app.alysium.ai/analytics).
2. Under **Your Agents**, select the intended agent's card and check the agent name on the page that opens.
3. If the list is hidden on a smaller screen, select **Conversations** or **Chats**.

The overview shows up to 20 agent cards. If the intended agent is missing, [check the dashboard's scope and active space](/analytics/read-your-analytics-dashboard#if-something-is-missing).

## Search the messages

Start with one distinctive word likely to appear in the exchange. Search includes the agent's replies: a search for **receipt** can find a reply mentioning a receipt even if the visitor never used that word.

1. Under **Recent Conversations**, click **Search conversations...** and type the word.
2. Wait for the list to finish loading the matches. Typing starts the search automatically.
3. Select a matching conversation and wait for its saved messages.
4. Read the question and reply to confirm the match. On smaller screens, selection switches to **Messages** or **Msgs**; open that tab if needed.

Changing the search can leave an earlier transcript open. Select a row from the matching list before treating the displayed messages as a search result.

Search matches words and beginnings of words, rather than any sequence of letters inside a word. With several words, all must match within a message. Punctuation does not turn a search into an exact-phrase request. Try a distinctive plain word first, then add words to narrow the results.

## Understand which conversations are searched

**Searching all conversations** appears in place of the list calendar while you have a search word entered. Search covers the selected agent's saved questions and replies across all time. Matches come from message text, not just conversation titles. Search is limited to this agent; it does not search other agents or your Library.

The summary's **Period**, custom list dates and **Showed it didn't** filter do not restrict keyword results. A **Last 7 days** summary can therefore sit above results from much earlier conversations.

**Show teammate conversations** still affects search. It starts off; turn it on to include your own practice chats. Your space currently contains only you, its owner. This control changes the list and search without changing the visitor summary metrics.

## Return to the ordinary or dated list

Select the X labelled **Clear search** in the search field. Wait for the ordinary list and its calendar to return. The list returns to its retained date range and other list choices, so check those controls if you expected a broader result.

To choose a custom range, open **Filter by date range**, or the displayed dates, and select its start and end days. The list updates when you select the range. The X labelled **Clear date filter** returns the list to all time. You can [read more about which activity the dates include](/analytics/filter-conversations-by-date).

Searching and clearing search need no **Save** action. Selecting a result yourself can mark it as read after the update succeeds.

## If nothing matches

Check the agent name and spelling, then try one distinctive word or fewer words. When looking for your own practice chat, turn on **Show teammate conversations**.

A topic in a knowledge document will only match here if it also appears in a searchable conversation message. No matches do not establish that the topic has never come up; try another word you remember from the exchange.

Newly saved activity does not automatically appear in the current view. Refresh or reopen the agent's Analytics page if you are looking for a conversation that just happened, then enter your search again.

## If searching fails

If the list shows **Couldn't load these conversations.**, select its **Retry**. You can also use **Clear search** to check whether the ordinary list loads.

If a matching row loads but its saved messages do not, reload or reopen the agent's page. Alternatively, select a different conversation, then select the intended result again and wait for its messages.
