Give your agent reusable guidance for a kind of work, such as drafting or organizing an answer. A skill can guide a method; knowledge documents supply facts. Attaching a skill does not add an unavailable integration or make uploaded scripts run.

**Already in the agent's Skills area?** Continue with [Choose a skill](#choose-a-skill).

## Open Skills

1. Open [Home](https://app.alysium.ai/spaces).
2. Select the intended agent.
3. Open **Build**.
4. Open **Settings**.
5. Find **Skills**.
6. Continue with [Choose a skill](#choose-a-skill).

Home opens your active space, where you choose the agent. If it asks you to sign in, sign in. Open Home again if needed.

## Choose a skill

The attached Skills list shows what this agent currently has. A suggestion, including one from guided creation, is a choice to consider rather than an attached skill.

1. Select **Browse skill library**.
2. Search or browse for the task you need.
3. Select a skill's name to open its details.
4. Read its description and contents.

The picker includes **My Skills** and available discovery categories. Add a skill when its method supports your agent's actual job. For a fictional FAQ assistant, guidance for organizing clear answers may fit better than a skill that writes long sales pitches. The example does not promise a particular catalog item is available.

Use [Review a skill before adding it](/build-your-agent/review-a-skill-before-adding-it) to understand its contents and trust setting. Avoid attaching skills that give the agent conflicting instructions.

## Add it to your space and attach it

Adding a catalog skill to your space and attaching it to an agent are separate actions. Use the action that matches its state:

| Offered action | What it means |
|---|---|
| **Add to my space** | Acquire an available free skill that your space does not yet hold. |
| **Attach to agent** | Attach a skill your space already holds to this agent. |
| **Purchase soon** | Paid purchase is not available. This does not complete a checkout. |

Shorter list controls can say **Add** or **Attach**. Read the action actually offered. An unavailable skill cannot be acquired through a disabled button.

1. Select **Add to my space** if the available free skill is not yet in your space.
2. Reopen the skill's details if needed.
3. Select **Attach to agent** when the skill is in your space but not attached.
4. Check that it appears in the agent's attached **Skills** list.

Being able to read a public description does not mean the skill is already in your space. If it is already attached, you do not need to add it again.

## Check the result

Skill actions save as you perform them; they do not wait for Design's **Save Changes**. Try a task the skill should help with and read whether its guidance fits. [Test your agent while you build](/build-your-agent/test-your-agent-while-you-build) explains the builder preview.

If an action fails, read the message and check the attached list before retrying. If the skill is in your space but missing from the agent, reopen its details and select **Attach to agent** when offered.

Removing a skill from one agent leaves its library entry in your space. See [Review a skill before adding it](/build-your-agent/review-a-skill-before-adding-it) for disabling and removal, or [Upload your own skill](/build-your-agent/upload-your-own-skill) if the needed guidance is not in the catalog.
