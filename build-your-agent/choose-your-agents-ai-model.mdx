The AI model writes your agent's replies. Choose one that suits the work you want the agent to do, then try it with a question your sources can answer. Changing the model keeps the agent's instructions and attached knowledge.

Different models use credits at different rates. A model that uses more credits may be useful for a demanding task, but a simpler option may handle short FAQ answers well.

## Open the model picker

1. Open [Home](https://app.alysium.ai/spaces) and select **Build** on your agent's card.
2. Select **Settings** if it is not already selected.
3. Scroll past the name, welcome message and conversation starters to the **Agent Builder** section.
4. Under **AI Models**, select the control showing the current model's name or **Select a model...**.

The picker is titled **Choose Your AI Model**. Note the current model's name before changing it so you can return to it after comparing replies.

## Choose from the available options

You can browse the groups shown in the picker, such as **Fast & Affordable**, **Balanced & Versatile**, **Maximum Capability** and **All Models**. Read each model's description for the sort of work it suits. Use **All Providers** or the provider chips to narrow the choices by provider.

To find choices for your task, type into **What do you plan to use this model for?** For example:

> Answer short factual questions using my shop's product and returns documents. Ask for clarification when a question is unclear.

The picker updates its suggestions after a pause. Press Enter to submit your description immediately.

Each row shows the model's name, provider, description and a relative cost from **\$** to **\$\$\$\$**. These symbols compare credit use; they are not dollar prices, and **\$** does not mean free. A crown marks a model included with Pro.

## Select and save the model

Select the model you want to use. Its name appears in the control, and the choice saves automatically. Let saving finish before leaving the builder. Where the save indicator is shown, you can hover over it to check for **All changes saved**.

If you select a Pro model in a Free space, Alysium shows **This model is included with Pro. Upgrade to unlock all models.** Choose an included model, or use **Upgrade** if you want to review the Pro offer. The blocked choice has not replaced your current model.

## Check the saved choice and try it

Return to [Home](https://app.alysium.ai/spaces) and select **Build** on the same agent's card. Select **Settings** if needed, then scroll to **Agent Builder** and check the model under **AI Models**. This confirms the saved choice, rather than just the change you saw when selecting it.

Try a question that matters to the agent's job. Use the chat beside the settings on a wide screen, or select **Chat Preview** within Build on a smaller screen. Type the question, then select **Send message** or press Enter. Preview conversations use your space's credits.

For the shop example, ask a returns question answered in the attached document. Compare the full reply with that source and the agent's instructions. You can [plan a broader set of preview checks](/build-your-agent/test-your-agent-while-you-build) for a fuller comparison.

## If the result is unexpected

- **The preview shows Running as:** a Free space can use the free fallback for a saved Pro model while keeping that Pro model as the saved choice. Read the notice, choose an included model in the picker or review **Upgrade**. The guide to [replies from a different model](/build-your-agent/when-your-agent-answers-with-a-different-model) explains this distinction.
- **The reopened model is different from the one you selected:** select your intended model again, wait for saving to finish and reopen the agent to check it.
- **The answer misses or changes a fact:** compare the attached source and instructions before choosing another model. A different model still needs the right information.
- **The reply stops partway through:** check **Max Length** in the [response settings](/build-your-agent/fine-tune-how-your-agent-answers).
- **The model handles your task poorly:** select the previous model you noted, let it save and try the same question again.
