<span id="create-your-first-agent" />

Create an assistant for one useful job, give it the information it needs and try a conversation before sharing it. You can start with a blank agent or describe what you want and let Alysium draft its setup.

Two parts of the setup work together: **instructions** tell the agent how to behave, and **knowledge** supplies reference information. A café assistant's instructions might ask for short, friendly answers; its knowledge would contain the café's actual menu and accessibility details.

AI-assisted drafting, instruction refinements and preview conversations use your space's credits.

## Choose how to start

Open [Home](https://app.alysium.ai/spaces) and select **Create New Agent**.

<span id="prepare-your-description-and-source" />
<span id="example-description" />

### Have Alysium draft the setup

In the description box, explain who the agent will help, what it should do and any limits. For example:

> Create a friendly assistant for visitors to my café. Use the café FAQ that I will add to answer questions about the menu and accessibility. Keep replies short. If the FAQ does not contain an answer, ask the visitor to speak to the café team. Do not make bookings or invent prices.

Select **Draft my agent**. Alysium creates the agent and opens its builder with a drafted name, instructions, greeting and suggested questions for you to review. You will add the FAQ as knowledge separately.

### Start from scratch

Below the description box, find **or pick a starting point**. On the **Create Your AI Agent** card, which describes starting with a blank canvas, select **Create Agent**.

The builder opens with a basic name for you to change. If you stay on Home after creating the agent, open its new card. You supply the instructions, greeting and suggested questions. You can use the Agent Builder helper inside the editor if you want help writing the instructions later.

## Review or write the setup

The builder opens in **Build**. Its **Settings** view contains the fields below. If you are viewing Profile or Chat Preview, select **Settings** to return to them. On a phone, the main Build, Design and Deploy tabs are in the bottom dock.

| Field | What to put there |
|---|---|
| **Agent Name** | A name that tells people what the agent helps with. |
| **Welcome Message** | A greeting that explains what visitors can ask. |
| **Suggested Conversation Starters** | A few questions the agent's sources can answer. |
| **Agent Instructions**, in the **Agent Builder** section | Whom to help, the task, answer style, sources to use and limits. |

In **Agent Builder**, check **AI Models**. The model produces the agent's replies. If the selector says **Select a model...**, open it, browse the categories and choose an available model whose description fits your task. Its name should appear in the selector. If a model name is already shown, you can keep it for the first test.

If Alysium drafted these fields, read them and correct any invented facts or promises. If you started blank, fill them in yourself. For the café example, the instructions should use the FAQ, give brief answers and send booking requests or unanswered questions to a café team member.

For help writing a blank agent's instructions:

1. In **Agent Builder**, select **Generate Agent Prompt**.
2. Describe the job, source and limits, then select **Draft prompt**.
3. Read the proposed instructions. To change them, describe the change in the box and select **Refine**.
4. Select **Insert instructions** to use them. If instructions already exist, the action is **Replace instructions**. Use **Discard** to reject the proposal.

This helper drafts the instructions; the greeting and suggested questions are separate fields. You can [use it for later refinements](/build-your-agent/let-ai-draft-or-refine-your-instructions) as the agent's job develops.

The agent's name, valid greeting and instructions save automatically. Starter text saves when you click or tap outside its field. Use **Add prompt** for another starter or its **Remove prompt** button to remove one. Wait for saving to finish before leaving, and resolve any displayed validation or save error. On a computer, the save indicator's tooltip can confirm **All changes saved**.

## Add a reference file

Scroll down in the Build settings to **Knowledge**. This is where you add the information the agent should use for its answers.

You can use your own short FAQ or practice with this fictional example. Copy it into a plain-text editor and save it as **Practice café FAQ.txt**:

> Practice café FAQ — fictional example
>
> Menu: Coffee, tea and sandwiches.
>
> Accessibility: The entrance is step-free.
>
> Contact and bookings: Speak to a café team member at the counter. The chat assistant cannot make or change bookings.
>
> Opening hours are not supplied in this FAQ.

For real users, choose information you are allowed to share with them and give them a real contact route.

1. Under **Upload Documents**, select **Browse files**.
2. Choose your file on your device and confirm the selection. Uploading starts when you select it.
3. Wait for the file to show **Ready** in **Attached knowledge**.

A successful builder upload saves the file in Library and attaches it to this agent. PDF, Word and plain-text files are useful starting choices; the limit is **25 MiB per file**, with enough available storage needed in your space. You can [check other supported formats](/knowledge-and-library/upload-files-to-your-agent) when choosing more sources.

If the material is already in Library, select **Add from Library** in Knowledge, expand its project and folder, select the file and choose **Attach**. Check it in Attached knowledge. You can also [attach a whole folder or project](/knowledge-and-library/use-library-files-in-an-agent); that includes eligible material added there later.

## Try a conversation

Use the chat beside the Build settings on a wide screen. On a smaller screen, select **Chat Preview** within Build.

Enter a question, then select **Send message** or press Enter. For the practice café, try:

- **Is the entrance step-free?** Compare the reply with the FAQ: it should say yes.
- **Can you change my booking?** The reply should direct you to a café team member at the counter.
- **What time does the café open?** The FAQ has no opening hours, so the agent should acknowledge the gap and give the contact route.

For your own material, test a question it answers and a request outside the agent's job. If a reply is wrong, check that the source is attached and Ready, then review the instructions for a conflicting or missing rule. Save any correction before testing again. You can [plan a broader set of preview checks](/build-your-agent/test-your-agent-while-you-build) as you refine it.

Return to [Home](https://app.alysium.ai/spaces) and reopen this agent's card. Check that your setup and reference attachment remain. You now have a draft you can edit and test; [making it live](/share-and-deploy/make-your-agent-live) is the next step when it is ready for visitors. Replace the fictional information before using the café example with real customers.

## If a step fails

- **Drafting credits are unavailable:** you can use the blank starting-point card instead and write the setup yourself. Preview messages still use credits.
- **Creation reports an error:** read the message before retrying. If Alysium says it created the agent but could not open its builder, find that agent on Home and open its card.
- **An upload row shows Failed:** use its **Retry** action if offered and read the result. If the attempt cannot continue, [check the available file-recovery actions](/knowledge-and-library/fix-a-file-that-failed-to-process).
- **The file was saved in Library but not attached:** select **Retry attachment**, then check Attached knowledge.

For an unresolved problem, email [Alysium support](mailto:support@alysium.ai) with the agent's name, the step you tried and any message displayed.
