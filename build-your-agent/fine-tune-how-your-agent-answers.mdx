Adjust your agent's response settings when you want more predictable wording, more variety or a different reply length. Fine tuning here changes how the model produces answers. It does not train the model or add facts to it.

If the agent gives the wrong business information, correct its instructions or knowledge first. For replies that are simply too long, start by asking for a concise style in the [agent's instructions](/build-your-agent/write-your-agents-instructions), then adjust the response budget if needed.

## Find the response settings

1. Open [Home](https://app.alysium.ai/spaces) and select **Build** on your agent's card.
2. Select **Settings** if it is not already selected.
3. Scroll past the name, welcome message and conversation starters to **Agent Builder**.
4. Under **Fine Tuning Settings**, select **Fine Tune Agent**.

Note the current values before changing them. You can restore those values if a change makes the answers less useful.

## Choose a starting point

The **Presets** menu offers these starting points:

| Preset | When to use it |
|---|---|
| **General Use** | A balanced starting point for everyday questions. |
| **Creative** | When you want more varied wording and ideas. |
| **Precise** | When you want more focused, predictable wording. |
| **Custom** | Keep the current values and adjust individual controls yourself. |

Selecting General Use, Creative or Precise changes several values and saves them immediately. Selecting Custom leaves the values as they are. For a first FAQ agent, General Use or Precise is a useful place to begin.

Check the individual values when comparing changes. Slider edits do not automatically change the label to Custom, and the preset label is not saved when you reopen the builder.

## Understand the main controls

| Control | What it changes |
|---|---|
| **Temperature** | A value from 0 to 1. Lower values make wording more predictable; higher values allow more variety. A lower value does not make an unsupported answer accurate. |
| **Max Length** | The maximum response budget, measured in tokens: small pieces of text rather than whole words. The minimum is 50, and the upper limit depends on the model and output limiter. A low budget can cut an answer off. |
| **Top P** | A value from 0 to 1 that narrows or widens the set of likely wording choices. Lower values narrow the choices; higher values allow a broader range. Leave it unchanged while comparing Temperature. |

A response budget gives the model room to finish; it does not ask the model to use all that room. Use instructions to describe the length you want, such as “Answer ordinary FAQ questions in two or three sentences.”

## Make one adjustment and compare

To try a smaller response budget:

1. Note the current **Max Length** value.
2. Move its slider to a modestly lower value.
3. Pause for at least a second to let the change save, then click outside the menu to close it.
4. In the chat beside the settings, ask a representative question. On a smaller screen, select **Chat Preview** within Build first. Select **Send message** or press Enter to submit it.
5. Check that the reply answers the question accurately and reaches a useful ending.

Preview conversations use credits. Compare the same kind of question before and after the change; the guide to [testing your agent while you build](/build-your-agent/test-your-agent-while-you-build) can help you plan the comparison.

Change one setting at a time so you can tell which change helped. If the reply now stops before it finishes, reopen **Fine Tune Agent** and increase **Max Length** or restore the previous value.

## Use advanced settings only for a specific need

Select **Show Advanced Settings** to reveal more controls.

| Control | When it matters |
|---|---|
| **Top K** | Limits the number of likely wording choices the model considers, from 1 to 100. Keep the existing value unless you have a specific reason to narrow or widen that choice. |
| **Stop Sequences** | Comma-separated text sequences that end a reply when they appear. Use these only when your output format needs a particular stopping point. A common word entered here can end an otherwise useful answer early. |
| **Output Limiter (10K max)** | Appears when the model allows more than 10,000 output tokens. When checked, it limits the Max Length slider to 10,000. |

Some models do not use every sampling control, so changing a visible control may have little effect with your chosen model.

For ordinary questions, keep **Output Limiter (10K max)** checked when it appears. If you need a larger response budget, clear it, then increase **Max Length** separately. Clearing the checkbox only expands the slider's range.

The limiter checkbox is temporary: it starts checked again when you reopen the builder. If you saved a Max Length above 10,000, reopening the builder can reduce it to 10,000 and save that lower value. Recheck Max Length after reopening before relying on a larger budget.

## Confirm the saved settings

Individual edits save after a one-second pause. Clicking outside the menu to close it also sends pending changes. Let saving finish before leaving; where the save indicator is shown, its hover text can confirm **All changes saved**.

Return to [Home](https://app.alysium.ai/spaces) and select **Build** on the same agent's card. Select **Settings** if needed, then scroll to **Agent Builder**. Open **Fine Tune Agent** and check the values you changed. Use those values to confirm the result rather than relying on the preset label.

If replies have become too varied, restore your noted values or apply Precise. If replies stop unexpectedly, check Max Length and any Stop Sequences. If the settings still do not give useful answers, compare [another model for the same task](/build-your-agent/choose-your-agents-ai-model).
