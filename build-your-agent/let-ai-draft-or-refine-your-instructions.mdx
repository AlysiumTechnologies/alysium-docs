Use the instruction helper to turn a description of your agent's job into proposed instructions. Read the proposal, ask for changes and choose when to put it into **Agent Instructions**.

Each draft and refinement uses your space's credits, including a refinement started by a suggestion chip. You can also [write the instructions directly](/build-your-agent/write-your-agents-instructions).

## Open the instruction helper

1. Open [Home](https://app.alysium.ai/spaces) and select **Build** on your agent's card.
2. Select **Settings** if it is not already selected.
3. Scroll past the name, welcome message and conversation starters to **Agent Builder**.
4. Select **Generate Agent Prompt** above **Agent Instructions**.

Keep a copy of any current instructions you want to preserve before replacing them.

A fresh request uses the description you type. Include the audience, job, style, rules and limits you want; the helper does not read the current instructions, agent name or description for you. To revise existing instructions in a fresh helper request, copy the current text into your request and explain the change you want.

If you arrived here after guided agent creation, the helper may already show its drafting conversation with **Refine** and **Dismiss**. That conversation carries the earlier draft, so you can give it a follow-up request.

## Request a proposal

Describe the behavior you want in enough detail for the helper to write it. For a fictional shop assistant:

> Draft instructions for an assistant that answers visitors' questions about our hiking shop. It should use the shop FAQ I will attach as knowledge. Keep answers short and friendly. Ask one question at a time when a visitor's request is unclear. If the FAQ does not answer a question, tell the visitor to contact the shop team. Do not invent prices, stock availability or returns policies.

Replace this with your agent's real job and rules. Include the actual wording of any policy you want in the instructions. Reference documents that the finished agent should use belong in **Knowledge** separately.

1. Enter your request in the helper's text box.
2. Select **Draft prompt** and wait for the proposal.
3. Read the entire proposal, scrolling through it to check the task, rules and assumptions.

The proposal is ready for your review. Applying it is a separate action.

## Refine the proposal

Describe a specific change in the follow-up box and select **Refine**. For example:

> Keep the same job and source rules. Ask only one clarification question at a time, and make the suggested next step one short sentence.

Wait for the revised proposal and read it again. Check that it keeps any rules you still need and removes invented policies or promises.

Selecting a suggestion chip starts a refinement immediately and uses credits. A suggested skill has its own separate chip action; use that action if you want to [add the skill to your agent](/build-your-agent/add-skills-to-your-agent).

## Apply or discard the proposal

Choose the action that matches what you want:

| Control | Result |
|---|---|
| **Insert instructions** | Puts the proposal into an empty instructions editor. |
| **Replace instructions** | Replaces the text already in the editor. |
| **Discard** | Rejects the proposal and leaves the editor's instructions as they were. |

To use the proposal, select **Insert instructions** or **Replace instructions**, then check the text in **Agent Instructions**. Applying starts the normal automatic save for instructions. Let saving finish before leaving the builder.

After a replacement, **Undo replace** is available for eight seconds. Select it promptly if you applied the wrong proposal; keep your own copy for changes you may want to reverse later.

## Refine instructions already in the editor

If you created the agent with guided drafting, its initial instructions are already in **Agent Instructions**. The helper's continuing conversation may offer **Refine** and **Dismiss**.

Select **Dismiss** to keep those initial instructions and close the helper. To change them:

1. Read the instructions in the editor.
2. Enter a specific follow-up in the helper and select **Refine**.
3. Read the new proposal, including any unchanged rules you need to keep.
4. Select **Replace instructions** to use it, or **Discard** to keep the current instructions.

The continuing conversation supplies the earlier draft. If you have since edited the instructions yourself, include the updated text in your request so the helper can work from those changes.

For an agent whose helper is starting fresh, paste the instructions you want revised into its request box with your change, select **Draft prompt**, then review and apply the proposal in the same way.

## Check the saved instructions

Check **Agent Instructions** after applying the proposal. If the editor flags a length problem, shorten the text until it passes validation. The limit is estimated at 20,000 tokens, which are pieces of text rather than a word count.

Wait for saving to finish. Where the save indicator is shown, hover over it to check for **All changes saved**. Return to [Home](https://app.alysium.ai/spaces) and select **Build** on the same agent's card. Select **Settings** if needed, then scroll to **Agent Builder** and confirm that the intended text remains in **Agent Instructions**.

Try a question related to the instructions. Use the chat beside the settings on a wide screen, or select **Chat Preview** within Build on a smaller screen. Type your question, then select **Send message** or press Enter. Preview messages also use credits. Compare the answer with the intended behavior and the agent's actual sources. You can [test more of the agent’s behavior](/build-your-agent/test-your-agent-while-you-build) before relying on the revised instructions.

## If drafting or refinement fails

- **The space is out of drafting credits:** continue by editing **Agent Instructions** yourself. Each new draft or refinement needs credits.
- **A refinement fails:** the last good proposal stays visible. Read the error, then enter or re-enter your desired change in the follow-up box before selecting **Refine**.
- **The proposal invents a policy or capability:** describe the correction and refine it before applying.
- **The reopened editor does not contain your intended text:** preserve your copy, enter the text in **Agent Instructions**, let saving finish and reopen the agent to check it again.
