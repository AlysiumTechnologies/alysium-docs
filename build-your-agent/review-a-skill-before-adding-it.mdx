Read a skill's instructions before deciding whether to use it. Check who published it, what it asks the agent to do and how it fits with the agent's existing rules. You can review a public catalog skill before adding it, or inspect a skill your space already holds.

## Open the skill details

Open [Home](https://app.alysium.ai/spaces). On the intended agent's card, select **Build**. Select **Settings** if another builder view is open, then scroll to **Skills** in the **Agent Builder** section.

Select a skill's name in the attached list to inspect it. For another skill, select **Browse skill library**, find it in **My Skills** or a discovery category, then select its name or description. Reading the details does not add the skill to your space or attach it to the agent.

## Read its guidance

Start with the description and the information shown in the details:

| Detail | What to check |
|---|---|
| **Added by** | The space that published the skill. Decide whether you recognize and want guidance from that publisher. |
| **Version** and **Last updated** | Which version you are reviewing and when it changed. |
| **Price** and **Visibility** | The skill's listed price and how it is offered. Paid skill checkout is not yet available. |
| **Access**, when shown | How your space holds the skill. **Purchased** can also appear for a free catalog addition; it does not by itself mean you paid. |

Categories, tags and **Featured** help you discover skills. The **Alysium** filter identifies the Alysium publisher, and the Premium crown identifies a priced skill. These labels do not certify that you should trust all of its instructions.

The viewer opens **SKILL.md**, which contains the skill's instructions. Read it, then select relevant reference files in the file list on the left. On a phone, select **Browse skills** to open the list, choose a file and close the list to read it. **Formatted preview** and **Markdown source** offer two ways to read the same content.

Compare the guidance with your agent's actual work:

- Does it expect information you can supply?
- Does its method produce the kind of answer you want?
- Does it respect the agent's limits and work with its other instructions and skills?

For a concise customer FAQ assistant, look for guidance that uses the supplied facts and handles unanswered questions sensibly. Instructions that require a sales pitch in every answer could conflict with that role.

The **Uses** badges list tool names declared by the skill. Alysium can provide only its supported capabilities; naming another tool does not make that tool available. Script files can be read, but Alysium stores them for portability and does not execute them.

## Decide whether to trust it

After your space holds a skill, its details show **Trust this skill**. This setting applies to your space's use of that skill across agents, rather than just this agent or conversation.

| Setting | How Alysium presents the loaded guidance to the agent |
|---|---|
| **Untrusted** | The default. The skill is treated as guarded guidance within the agent's rules. |
| **Trusted** | The skill's instructions are treated as authoritative guidance. |

Leave **Trust this skill** off while you are deciding whether you accept its instructions. Turn it on only when you want the guidance treated as trusted throughout your space. Trust changes how the instructions are treated; it does not grant arbitrary tools, outside integrations, private data or script execution.

## Choose what to do with it

If the skill fits, add and attach it from the details:

1. For an available free skill your space does not hold, select **Add to my space** and wait for it to finish. This puts the skill in **My Skills**.
2. Select **Attach to agent** when it appears. If your space already holds the skill, start here.
3. Return to **Skills** and check that the skill has a row with its switch on.

The picker uses **Add** and **Attach** for these same actions. A disabled **Purchase soon**, or **Get** showing the coming-soon message, means a priced skill cannot yet be purchased. If you decide against a skill, close its details without adding it.

For an attached skill, use **Disable on this agent** to stop using it while preserving the attachment. Use **Enable on this agent** to restore it. **Remove from agent** removes this agent's attachment and leaves the skill in My Skills. These actions save as you perform them; wait for the result and check the attached list after a change.

## If a skill is unavailable or the result is unexpected

If loading or changing a skill reports an error, read the message and check its current state before retrying. If an addition succeeded but the skill is absent from the attached list, use **Attach to agent**.

If the guidance makes the agent's answers worse, disable the skill and reread its instructions for a conflict. Raising trust changes the weight of its guidance; it does not correct unsuitable instructions.

An attached catalog skill keeps its acquired version until you accept an update. An **Update** action on its row adopts a newer published version. This differs from uploading a replacement bundle for a skill your space authored; you can [maintain or retire a skill you created](/build-your-agent/update-or-retire-a-skill-you-created) from its details.
