Help people understand what your agent can do and give them a useful first question. The welcome message is its opening greeting; starter prompts are questions people can select to begin a conversation.

Choose a greeting and questions that match the agent's actual job. Its [instructions](/build-your-agent/write-your-agents-instructions) guide how it answers, and its knowledge supplies reference information.

## Find the fields

Open [Home](https://app.alysium.ai/spaces) and select **Build** on the intended agent's card. In the builder, select **Settings** if you are viewing Profile or Chat Preview. Find **Welcome Message** and **Suggested Conversation Starters**.

## Write the welcome message

Tell people what they can ask and, if useful, where to go for questions the agent cannot answer. Keep the greeting to **50 words or fewer**. The field's word counter shows your length, and an overlong greeting will not save.

For a fictional café assistant:

> Hi, I can help with the café's menu and accessibility information. Ask a question or choose one below. If our FAQ does not cover your question, I will point you to a café team member.

Replace the example with your own agent's scope and contact route. Enter it in **Welcome Message**, then pause to let it save automatically. Correct any displayed validation message. On a computer, you can hover over the builder's save indicator, where shown, to check for **All changes saved**.

## Choose useful starter questions

You can have **up to five** starter prompts. Write specific questions that your agent's sources can answer. For a café FAQ covering its menu, accessibility and booking contact, suitable questions might be:

- What food and drinks does the café serve?
- Is the café entrance step-free?
- How can I ask about a booking?

Check each question against your own information. A starter offers a task to the person choosing it, so use questions that the agent is equipped to handle.

### Edit an existing starter

Replace the text in its field, then click or tap outside the field to save the edit.

### Add a starter

Select **Add prompt**, enter a question in the new field, then click or tap outside it to save the text. You can add another entry while the list has fewer than five prompts.

### Remove an unwanted starter

Select the entry's X button, labelled **Remove prompt**. Adding or removing an entry starts saving that list change; edited text saves when you leave its field.

After your edits, wait for saving to finish. To confirm the text was stored, return to [Home](https://app.alysium.ai/spaces), reopen the same agent and check the greeting and questions in **Build** → **Settings**.

## Show starters to visitors

Writing questions in Build and displaying them in the widget are separate choices. To show them:

1. Open **Design** in the builder. If you are viewing its Preview subtab, select the **Design** view.
2. Scroll to **Features** and turn on **Starter prompts**.
3. Return to **Save Changes** near the top and select it.
4. Wait for **All Changes Saved**.
5. Check the greeting and questions on the widget preview's opening screen. On a narrow screen, select the **Preview** subtab within Design to see it.

The preview can reflect changes before they are saved, so use **All Changes Saved** to confirm the display setting was stored. You can [check the rest of the widget preview](/design-your-widget/preview-your-widget) before sharing the agent.

## If the greeting or starters are missing

- **The greeting has a validation message:** shorten it to 50 words or fewer and let it save. Starter changes save separately, so saved questions do not confirm that the greeting saved.
- **A starter edit did not remain after reopening:** enter it again in **Suggested Conversation Starters** and click or tap outside its field.
- **The saved questions are absent from the widget opening:** check **Design** → **Features** → **Starter prompts**, turn it on, select **Save Changes** and wait for **All Changes Saved**.

Check the intended agent and the widget's opening screen when comparing the result. A conversation already in progress is a different view from that opening.
