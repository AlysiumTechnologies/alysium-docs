Give your agent a name people can recognize, a description of its job and images that fit it. The avatar is its small identifying picture on cards and in chat; the banner is a wide header image.

## Find the right field

Open [Home](https://app.alysium.ai/spaces) and select **Build** on the intended agent's card. The builder has separate **Settings** and **Profile** views:

| What you want to change | Where to find it |
|---|---|
| Name | **Settings** → **Agent Name** |
| Description | **Profile**, then scroll to **Description** |
| Avatar or banner | **Profile** → **Agent Images** |

## Choose a name and description

Choose a name that suggests the agent's purpose. Use the description to explain what people can ask it to do. The description is shown on agent pages.

For a fictional café assistant, the name could be **Café Visitor Guide**, with this description:

> Answers questions about our menu and accessibility from the café FAQ, and points visitors to the café team when a question is not covered.

Replace the example with your own job and sources. Keep the claims specific to what the agent can help with. To change how it responds, edit its [Agent Instructions](/build-your-agent/write-your-agents-instructions).

## Change the name

In **Build**, select **Settings** and replace the text in **Agent Name**. Pause to let the change save automatically.

## Change the description

Select **Profile**, scroll to **Description** and enter your text in the field marked **Describe what your agent does**. Pause to let it save automatically.

On a computer, the builder's save indicator, where shown, has a tooltip you can check for **All changes saved**. Reopening the agent lets you confirm the stored text on any screen size.

## Prepare an image

Choose a **PNG, JPEG, WebP or GIF** file you have permission to use. The two images have different file limits:

| Image | Maximum file size |
|---|---|
| Avatar | **2 MiB** |
| Banner | **5 MiB** |

An image that works well as a wide banner may be difficult to recognize as a small avatar. Choose each for the space it will fill.

## Upload an avatar

In **Build** → **Profile**, find **Agent Images** → **Avatar**.

1. Select the current avatar or image placeholder, labelled **Upload avatar image**.
2. Choose the image file on your device. Selecting it starts the upload.
3. Wait for **Image uploaded**, then check the resulting picture.

Use the same upload control to replace an existing avatar.

## Upload or remove a banner

In **Agent Images** → **Banner**:

1. Select **Browse images** and choose a file, or drop it onto **Drop a banner image here**.
2. Wait for **Image uploaded**.
3. Check the resulting banner.

If a banner is already present and you want to clear it, select **Remove banner** and check that the image disappears.

## Confirm the saved profile

Return to [Home](https://app.alysium.ai/spaces) and reopen the same agent. Check **Agent Name** in **Build** → **Settings**, then select **Profile** and check the description, avatar and banner.

The intended values should remain after reopening. This confirms the saved setup you are editing. When you are ready to share the agent, [make it live](/share-and-deploy/make-your-agent-live) and check the visitor-facing result there.

## If an image or edit fails

- **The image type is rejected:** export the image as PNG, JPEG, WebP or GIF and select that file.
- **The image is too large:** resize or compress it to fit the avatar's 2 MiB limit or banner's 5 MiB limit, then select it again.
- **The upload reports an error:** read the message and correct the stated problem before trying the upload again. A changed preview alone does not confirm that the image was stored; check it after reopening the agent.
- **A text change did not remain:** enter it again in its Settings or Profile field, wait for saving to finish and reopen the same agent to check.
