Give your agent an identity people can recognize. Its name, avatar, banner and description describe the assistant; they do not change your personal account name or photo.

Use images you have permission to show publicly. Some AgentHub agents cannot be edited, so use an agent you created or a copy that allows changes.

## Find the right field

Open [Home](https://app.alysium.ai/spaces) and select the agent you want to change. The text and image fields are in different places:

| Field | Location | Continue with |
|---|---|---|
| **Agent Name** | **Build** → **Settings** | [Change the name](#change-the-name) |
| **Description** | **Build** → **Profile** | [Change the description](#change-the-description) |
| **Avatar** | **Build** → **Profile** → **Agent Images** | [Upload an avatar](#upload-an-avatar) |
| **Banner** | **Build** → **Profile** → **Agent Images** | [Upload or remove a banner](#upload-or-remove-a-banner) |

Home opens your current space; select the intended agent there. If its builder is already open, use the table to find the field and follow its linked task.

For behavior changes, use [Write your agent's instructions](/build-your-agent/write-your-agents-instructions). Public profile text does not replace instructions.

## Choose a name and description

For a fictional outdoor-shop assistant, an example name is **Ridge and River Guide**. Its description could be:

> Helps customers understand our hiking-boot notes and shop FAQ, and points them to staff when a question is not covered.

Replace the name and claims with your own. Describe what people can actually ask the agent to do.

## Change the name

1. Open **Build** → **Settings**.
2. Edit **Agent Name**.
3. Pause to let the change save.

## Change the description

1. Open **Build** → **Profile**.
2. Edit **Description**.
3. Pause to let it save.

These text fields save automatically. There is no separate Publish or Design **Save Changes** step to store them.

## Prepare an image

An avatar is the small identifying picture; a banner is the wider image.

| Image | Maximum size |
|---|---|
| Avatar | **2 MB** |
| Banner | **5 MB** |

Use **PNG, JPG, GIF or WebP**. These limits apply to agent pictures, not knowledge documents.

## Upload an avatar

In **Build** → **Profile**, find **Agent Images** → **Avatar**.

1. Select the current avatar picture, labelled **Upload avatar image**.
2. Select an image on your device.
3. Wait for **Image uploaded**.
4. Check the resulting picture.

Selecting the image starts the upload and saves it to the agent. You do not need to add the picture through Knowledge.

## Upload or remove a banner

In **Build** → **Profile**, find **Agent Images** → **Banner**.

1. Select **Browse images**.
2. Select a banner image on your device.
3. Wait for **Image uploaded**.
4. Check the resulting banner.

You can also drop an image into **Drop a banner image here**, then continue from step 3.

To remove the banner, select **Remove banner**. Wait for **Image removed**, then check that the banner is gone.

## Confirm the saved profile

Return to [Home](https://app.alysium.ai/spaces) and reopen the same agent. Check **Agent Name** in **Build** → **Settings**, then the description and images in **Build** → **Profile**.

You are finished when the intended text and images remain after reopening. To write the first words visitors see, continue with [Set a welcome message and starter prompts](/build-your-agent/set-a-welcome-message-and-starter-prompts).

## If an image or edit fails

- **The image type is rejected:** export it to one of the supported formats.
- **The file is too large:** resize or compress it to fit the limit for that image.
- **An upload reports an error:** read the message before trying again. A changed preview alone does not confirm the upload saved.
- **The agent still behaves the same:** profile changes do not rewrite **Agent Instructions**. Use the instructions guide for behavior changes.
