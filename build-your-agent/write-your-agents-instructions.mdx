<span id="write-your-agent’s-instructions" />

Use **Agent Instructions** to tell your agent whom it helps, what job to do and how to answer. Write in ordinary language, with clear rules for requests it cannot handle.

Instructions and knowledge work together. Knowledge holds reference information, such as a menu or returns policy. Instructions explain how to use that information, how to present an answer and when to direct someone to a person.

## Open the instructions editor

Open [Home](https://app.alysium.ai/spaces) and select **Build** on the intended agent's card. Select **Settings** if needed, then scroll to **Agent Builder** and find **Agent Instructions**.

Read any existing instructions before replacing them. An agent created with a drafted setup may already have text worth keeping. Copy useful wording into your notes if you want to preserve it while editing.

## Decide what to write

Cover the decisions that will shape a useful answer:

- **Audience and job:** who will use the agent, and what should it help them do?
- **Sources:** which attached information should it use for facts?
- **Answer style:** should it give a short explanation, a list of steps or another useful format?
- **Unclear requests:** what should it ask before answering?
- **Limits:** which requests belong with a person, and what should the agent say when information is missing?

Give a real contact route for unanswered requests, either in the instructions or in a source they name. Keep long reference material in Knowledge so the instructions can focus on the job and its boundaries. You [add that reference information separately](/knowledge-and-library/give-your-agent-knowledge); naming a document in the instructions does not attach it.

## Adapt an example

For a fictional café assistant with an attached **Café FAQ** covering its menu, accessibility and contact details, you could write:

> You help café visitors understand the menu and accessibility information in the attached Café FAQ. Use that FAQ for café facts. Give a short, friendly answer in plain language. Ask a brief question when the visitor's request is unclear. If the FAQ does not answer a question, say you do not have that information and give the contact route in the FAQ. Direct booking requests to that contact route. Do not claim to make or change bookings, and do not invent prices, policies or opening hours.

This gives the agent a job, a source, an answer style and a way to handle requests beyond its job. For your own version, replace the audience, tasks, source name and limits. Check that the named source is attached and contains the contact details you want people to use.

## Apply and save your version

1. Replace or revise the text in **Agent Instructions**.
2. Check the estimated token counter. The limit is **20,000 tokens**; shorten the text if the counter or an inline validation message says it is too long.
3. Pause to let valid instructions save automatically, and wait for saving to finish before leaving the builder.

On a computer, hover over the save indicator near the top, where shown, to check for **All changes saved**. If you need to shorten the instructions, remove repetition and move reference facts into Knowledge while keeping the important limits and contact route.

## Confirm that the text remains

Return to [Home](https://app.alysium.ai/spaces) and reopen the same agent. In **Build** → **Settings**, scroll to **Agent Builder** and check that **Agent Instructions** contains your intended text. This confirms what was stored, including on a touch screen where a hover message may be unavailable.

## Try the instructions in a conversation

Use the chat beside the Build settings on a wide screen. On a smaller screen, select **Chat Preview** within Build. Each preview request uses your space's credits.

Type a question, then select **Send message** or press Enter. Test both a question the source answers and a request outside the agent's job. For the café example:

- Ask **What food and drinks does the café serve?** Compare the reply with the menu in the attached Café FAQ and check that the answer is short and clear.
- Ask **Can you change my café booking?** Check that the reply gives the FAQ's contact route without claiming to change the booking.

For your own agent, choose equally specific questions and compare the replies with your actual sources and instructions. If an answer is wrong, check that the intended source is attached and shows **Ready**, then look for a missing or conflicting rule in the instructions. Save a correction before testing again. You can [plan a broader set of preview checks](/build-your-agent/test-your-agent-while-you-build) as you refine the setup.

## Use nearby controls for different needs

If you want help drafting the wording, **Generate Agent Prompt** opens a separate proposal helper in Agent Builder. Describe the job, sources and limits you want it to use, select **Draft prompt** and review the proposal. You choose **Insert instructions** or **Replace instructions** to apply it. The [drafting and refinement guide](/build-your-agent/let-ai-draft-or-refine-your-instructions) explains the complete helper workflow.

**AI Models** selects the model that produces replies. Its choice is separate from the instructions and reference facts; [choose a model](/build-your-agent/choose-your-agents-ai-model) when you need to change it. Knowledge also has [source-use settings](/knowledge-and-library/control-how-your-agent-uses-its-knowledge) for how the agent draws on attached material.

## If you cannot save the instructions

Keep a copy of your intended text in your notes. Correct any inline validation message, including a length error, and let the edited text save. Reopen the same agent from Home and inspect **Agent Instructions**. If your changes did not remain, enter your saved copy again, wait for saving to finish and repeat the check.
