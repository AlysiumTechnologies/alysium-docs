Choose a readable appearance for your agent's visitor chat. These controls are in **Design** for an agent you can edit.

The widget's appearance is separate from the workspace theme you use while editing Alysium. Changing its look does not publish the agent or install it on a website.

## Open the appearance controls

1. Open [Home](https://app.alysium.ai/spaces).
2. Select the intended agent.
3. Open **Design**.
4. Find **Theme** and **Widget Preview**.

Home opens your current space; choose the agent whose visitor appearance you want to change. If its Design controls are already open, continue with [Choose the appearance](#choose-the-appearance).

On a smaller screen, the **Design** subtab holds controls and **Preview** shows the widget. You will return to Design to save.

## Choose the appearance

The selected theme appears first. Open the chooser to see other options.

For a fictional customer-help widget, **Light** is a simple first theme to inspect. **Dark** is another choice if it suits your site. These are examples, not a claim about what your visitors prefer.

1. Open **Theme**.
2. Select the theme you want.
3. In **Chat Window**, set **Show avatars** if you want to change picture visibility.
4. Inspect **Widget Preview**.

On a small screen, select **Preview** for step 4. Check that the actual greeting, starter questions and message text are easy to read.

**Show avatars** changes whether pictures appear. To upload a different agent picture, use [Set your agent's name, picture and description](/build-your-agent/set-your-agents-name-picture-and-description).

## Save the appearance

The preview reflects edits immediately. The saved visitor configuration changes after the Design save succeeds.

1. Return to the **Design** subtab if you are viewing Preview on a small screen.
2. Select **Save Changes**.
3. Wait for **All Changes Saved**.

If saving reports an error, keep the page open and read it before leaving. A different-looking preview can still contain unsaved edits.

## Check the saved result

Reopen the same agent from [Home](https://app.alysium.ai/spaces), then return to **Design**. Confirm the intended theme and avatar setting remain.

If the widget is already shared, check that same agent's visitor widget too. For a mismatch, first confirm the save succeeded and that you are looking at the correct agent. The workspace theme does not control visitors' widgets.

For visible wording, continue with [Change the widget's title and message box text](/design-your-widget/change-the-widgets-title-and-message-box-text). Use [Preview your widget](/design-your-widget/preview-your-widget) for a fuller visitor check before deployment.
