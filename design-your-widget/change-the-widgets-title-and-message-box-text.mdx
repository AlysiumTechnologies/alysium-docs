Change the header title and typing hint in an editable agent's visitor chat.

**Widget Title** labels the chat window. **Input text** is the hint inside the empty message box. They are separate from the agent's welcome message, name and instructions.

## Open Chat Window

1. Open [Home](https://app.alysium.ai/spaces).
2. Select the intended agent.
3. Open **Design**.
4. Find **Chat Window**.

If Chat Window is already open for the right agent, continue with [Choose the words](#choose-the-words). These are widget controls, separate from your personal account settings.

On a smaller screen, use the **Design** subtab for the fields and **Preview** to inspect the widget. Return to Design to save.

## Choose the words

For a fictional shop helper:

| Field | Example |
|---|---|
| **Widget Title** | Ridge and River Guide |
| **Input text** | Ask about our boot notes or shop FAQ |

Replace these with your own wording. A short hint helps visitors choose a first message. Avoid promising an action, such as order tracking, that the agent cannot perform.

## Enter and save the text

1. Edit **Widget Title** if you want a different header.
2. Edit **Input text** if you want a different typing hint.
3. Inspect the title and empty message box in the preview.
4. Return to **Design** if you used the small-screen Preview subtab.
5. Select **Save Changes**.
6. Wait for **All Changes Saved**.

The preview can show these changes before they are saved for visitors. If saving fails, keep the page open and read the error.

## Check the intended field changed

Reopen the same agent from [Home](https://app.alysium.ai/spaces) and check **Design** → **Chat Window**. If already shared, inspect that agent's actual visitor widget too.

For other wording problems, use the corresponding Build field:

| What needs to change | Where to change it |
|---|---|
| Opening greeting | **Build** → **Settings** → **Welcome Message** |
| Answer style or behavior | **Build** → **Settings** → **Agent Instructions** |
| Agent's name elsewhere | **Build** → **Settings** → **Agent Name** |

Changing Input text only changes the typing hint. It does not send a message or add knowledge.

If wording is clipped, shorten it and preview it again before saving. If visitors still see old text, confirm the saved state and the intended agent before changing another field.

[Set a welcome message and starter prompts](/build-your-agent/set-a-welcome-message-and-starter-prompts) covers the opening conversation. [Preview your widget](/design-your-widget/preview-your-widget) covers the overall visitor experience.
