<span id="change-the-widget’s-title-and-message-box-text" />

Give your visitor chat a clear title and a useful hint for writing a first message. **Widget Title** appears in the chat header. **Input text** appears inside the empty message box.

## Open Chat Window

Open [Home](https://app.alysium.ai/spaces), select **Build** on the agent's card, then select the main **Design** tab. Scroll the controls to **Chat Window**.

On a wide screen, the widget preview is beside the controls. On a smaller screen, use the **Design** subtab to edit and **Preview** to inspect the result.

## Choose the words

Keep the title short and use the typing hint to suggest something the agent can help with. For an agent that answers questions from a café FAQ, you might use:

| Field | Example |
|---|---|
| **Widget Title** | Café guide |
| **Input text** | Ask about our menu or accessibility |

Match the wording to your agent's actual job and information. A hint such as “Track your order” would be misleading if the agent cannot look up orders.

## Enter and save the text

1. Enter your title in **Widget Title** and your typing hint in **Input text**.
2. Read the header in the preview. Open **Chat** to see the hint in an empty message box. Check the wording at the width visitors will use, and shorten it if it is clipped.
3. On a smaller screen, return to the **Design** subtab. Scroll to the save card at the top of the Design controls and select **Save Changes**.
4. Wait for **All Changes Saved**.

Clearing either field can make the widget display fallback wording rather than an empty label.

If the save card shows an error, keep the page open, read it and retry **Save Changes** when available. The preview can show text that has not yet been saved.

## Check the intended field changed

Reopen the same agent from [Home](https://app.alysium.ai/spaces), return to **Design** and scroll to **Chat Window**. Check that both fields retain your wording. If the widget is already on your website, inspect that agent's visitor widget too.

For other text, use **Build** → **Settings**:

| What you want to change | Field |
|---|---|
| The agent's name | **Agent Name** |
| Its opening greeting | **Welcome Message** |
| Questions offered to start a conversation | **Suggested Conversation Starters** |
| How it answers and behaves | **Agent Instructions**, in **Agent Builder** |

Changing the widget title does not rename the agent. The typing hint guides what visitors enter; use [the agent's instructions](/build-your-agent/write-your-agents-instructions) to change how it responds, or [edit its greeting and starters](/build-your-agent/set-a-welcome-message-and-starter-prompts) to change the opening conversation.
