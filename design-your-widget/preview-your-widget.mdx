See your agent as a visitor would: inspect its opening screen, chat, appearance and account menu before sharing it. Design preview shows your current edits, including ones you have not saved yet.

The preview can send real chat requests. Sending a message or selecting a starter question uses your space's credits.

## Open Widget Preview

Open [Home](https://app.alysium.ai/spaces), select **Build** on the agent's card, then select the main **Design** tab.

On a wide screen, **Widget Preview** is beside the controls. On a smaller screen, select the **Preview** subtab; return to **Design** when you want to edit settings. If you close the small-screen preview, select **Open widget preview** to reopen it. A floating desktop preview can be reopened with its launcher.

## Read it as a first-time visitor

Start on the widget's **Home** view. Check that the greeting and description explain what the agent helps with, and that any starter questions fit its job and sources. Read the title and check that the text is easy to see against the selected theme.

Open **Chat** to inspect the empty message box and typing hint. To reach the account menu from Chat, select **Back to browse** in the header, then **Account**.

In Account, open **About This Agent** and **Help & Support** and check what visitors will find. These entries are built in. With a Help URL configured, Help & Support opens an external page; without one, Help & Support opens the widget's contact screen. **Terms & Privacy** appears when you have supplied a policy URL. Open it and check the destination if you use it.

Check the **Conversations** shortcut too if you have enabled it. You can [edit the menu's information and links](/design-your-widget/set-up-your-widget-menu) when a destination or description needs changing.

## Try a conversation if useful

Choose a question answered by an actual source attached to this agent. Include all the context needed to answer it in the question.

1. Open **Chat** in the preview and enter the question.
2. Select **Send message**, or press Enter.
3. Read the full reply and compare it with the source. Check both the facts and whether the answer helps with the request.

Selecting a starter question also sends a real request. If a request fails, read the displayed message before sending another one. You can [plan a broader set of preview checks](/build-your-agent/test-your-agent-while-you-build) to test source gaps, task limits and answer style.

## Save edits you want to keep

If you changed Design settings, return to the **Design** subtab on a smaller screen, scroll to the save card at the top of the controls and select **Save Changes**. Wait for **All Changes Saved**.

If an error appears there, keep the page open, read it and retry **Save Changes** when available. A working preview conversation does not confirm that appearance changes were saved.

Reopen the same agent from Home and return to Design to check that the choices you want to keep remain saved.

## Check deployment separately

The desktop preview's sample website background is a place to inspect the widget. To make it available to visitors, [make the agent live](/share-and-deploy/make-your-agent-live) and [install it on your website](/share-and-deploy/put-your-agent-on-your-website).

Check the saved widget on the actual website as well. If it differs from the preview, confirm that the site uses the intended agent and that the Design save succeeded, then check the installation settings.
