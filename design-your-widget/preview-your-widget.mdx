Inspect your agent's chat appearance, menus and enabled features before sharing it. The Design preview is interactive and can show unsaved edits.

Use an agent you can edit. If you try a conversation, it is a working chat and uses credits. A preview does not verify a website installation or guarantee the accuracy of the agent's answers.

## Open Widget Preview

1. Open [Home](https://app.alysium.ai/spaces).
2. Select the intended agent.
3. Open **Design**.
4. Find **Widget Preview** beside the controls.

On a smaller screen, select the **Preview** subtab for step 4. Use the **Design** subtab when you want to change or save settings.

If the widget preview is already open, continue with [Read it as a first-time visitor](#read-it-as-a-first-time-visitor).

## Read it as a first-time visitor

For a fictional shop helper, imagine you have never used the assistant. Use its actual configured content for these checks:

| Check | What to look for |
|---|---|
| Title and greeting | Can a visitor tell what the agent helps with? |
| Starter questions | Do the offered questions fit the supplied information and task? |
| Message box | Is the typing hint useful? |
| Appearance | Are text contrast and avatar visibility suitable? |
| File upload, if enabled | Is the visitor attachment control present? |
| Account and conversation menus | Are the available choices understandable? |

Open **Account** in the preview. Inspect any help, about or contact entries you added, including their wording and destinations. Features vary with configuration; do not expect every possible menu entry.

Use the widget's **Home** view for an opening-screen check rather than judging only an older conversation.

## Try a conversation if useful

Choose a question answered by an actual attached source.

1. Open **Chat** in the widget preview.
2. Enter the question in the message box.
3. Select **Send message**, or press Enter.
4. Read the full reply.
5. Compare it with the source.

A good-looking opening is separate from correct source facts. [Test your agent while you build](/build-your-agent/test-your-agent-while-you-build) gives a fuller answer-checking procedure.

## Save edits you want to keep

If you changed Design:

1. Return to the **Design** subtab if needed on a small screen.
2. Select **Save Changes**.
3. Wait for **All Changes Saved**.

If saving fails, keep the page open and read the error. The preview's appearance and a preview conversation do not confirm that Design changes were saved.

Reopen the same agent from [Home](https://app.alysium.ai/spaces) and return to Design to check the saved choices. You have completed this preview task when you have inspected the intended visitor presentation and saved any Design edits you want to retain.

## Check deployment separately

When ready to share, use **Deploy** and follow [Make your agent live](/share-and-deploy/make-your-agent-live), then [Put your agent on your website](/share-and-deploy/put-your-agent-on-your-website).

Design preview does not install website code, change allowed websites or make the agent public. If an installed widget differs, confirm the intended agent and saved configuration, then follow the installation guide to check the published site.
