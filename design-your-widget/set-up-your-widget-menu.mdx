Add useful information and contact routes to the widget's account menu. **Agent Menu** can hold your policy link, help destination, creator background and public contact details.

Use current information you are allowed to show publicly and an agent you can edit. Adding an entry does not create an external page, write a policy or contact a person for the visitor.

## Open Agent Menu

1. Open [Home](https://app.alysium.ai/spaces).
2. Select the intended agent.
3. Open **Design**.
4. Find **Agent Menu**.

If Agent Menu is already open, continue with [Choose the entries](#choose-the-entries).

On a smaller screen, use the **Design** subtab for controls and **Preview** to inspect the widget. Return to Design to save.

## Choose the entries

Add only the entries your visitors need:

| Entry | Prepare before adding it |
|---|---|
| **Terms & Privacy** | The actual public address of the applicable policy. |
| **Help & Support** | A real help page you have checked. |
| **About profile** | The public name and background you want visitors to read. |
| **Contact info** | A contact route people can actually use. |

Select an entry to add it. Expand an existing entry to edit it, or remove one you no longer want.

For a fictional shop helper, a useful first menu could contain the shop's real help page and a Contact info message such as:

> Contact our shop team for questions the notes do not cover.

Use your own actual contact address. You can omit About or extra social fields when they do not help visitors.

## Set policy and help destinations

In **Terms & Privacy** or **Help & Support**, enter the real public destination in that entry's URL field.

Use a page you control and have checked in a browser. A policy entry should lead to the applicable policy; a help entry should lead to the help you intend for these visitors. Do not use a fabricated tutorial address or an unfinished page.

Removing an entry removes it from this configured menu after saving. It does not delete the external page.

## Describe the creator in About profile

Start with **Your name** and **Your story**. These describe the public creator background, not the agent's instructions or your personal account settings.

Optional details include **Bio**, credentials and public links. The add controls and **More** section can offer LinkedIn, Twitter, Website, Book a call, Space name, Space description and Unique value.

Supply genuine details and remove fields you do not need. **Learn more** and **Book a call** destinations point to your own pages or scheduling route. Filling a field does not make the agent book an appointment. Keep the story focused on what helps this visitor.

## Set Contact info

For the minimal shop example:

1. Add or expand **Contact info**.
2. Enter the introduction in **Message at top**.
3. Enter your actual monitored contact address in **Email**.

Optional add controls offer phone, website and Discord. Further choices include Twitter, address and additional information. Use only public details you intend to share.

Follow the format guidance for Website, Discord and Twitter and correct any visible validation message.

## Save and inspect the menu

1. Remove entries or optional fields you do not intend to show.
2. Review the wording and destinations you entered.
3. Return to the **Design** subtab if you used small-screen Preview.
4. Select **Save Changes**.
5. Wait for **All Changes Saved**.
6. Open **Account** in the widget preview.
7. Open the corresponding menu entries.
8. Check the displayed details and destinations.

On a smaller screen, select **Preview** after step 5 to inspect Account.

Reopen the same agent from [Home](https://app.alysium.ai/spaces) and check the saved Agent Menu entries. If the widget is already shared, inspect its actual visitor menu too.

## If an entry is missing or wrong

If an entry is missing, confirm it was added and the Design save succeeded. Keep the page open and read any save error before leaving.

If an external page is wrong, correct the URL and save again. The menu entry did not create that page. If an email or public detail is wrong, correct the source field before visitors rely on it.

Continue with [Preview your widget](/design-your-widget/preview-your-widget) for a fuller visitor check.
