**Workspace Theme** changes the appearance of the Alysium app you work in. Use it when you prefer another reading appearance. You do not need to open an agent to change it.

For the chat visitors open on your website, use [Change how your widget looks](/design-your-widget/change-how-your-widget-looks) in the agent's **Design** area instead.

**Already looking at Choose Theme?** Continue with [Apply a theme](#apply-a-theme).

## Open the theme choices

1. Open [Home](https://app.alysium.ai/spaces).
2. Open the sidebar navigation if it is collapsed.
3. Select **Workspace Theme**.
4. Find the **Choose Theme** menu.
5. Continue with [Apply a theme](#apply-a-theme).

Home opens your current space. If it asks you to sign in, sign in. Open Home again if needed.

## Apply a theme

1. Review the available themes.
2. Select the theme you prefer.
3. Check that the app's appearance changes and the menu closes.

There is no separate **Save Changes** action for this choice. Reopen **Workspace Theme** to check the marked selection if you want to confirm it.

Changing your own reading theme does not require redesigning every agent in your space. It does not rewrite agent instructions, knowledge or publication settings.

## If the appearance is not what you expected

If you meant to change a website chat, open the intended agent from [Home](https://app.alysium.ai/spaces). Continue with [Change how your widget looks](/design-your-widget/change-how-your-widget-looks) in **Design**. Your workspace theme does not set that widget's visitor theme.

If the app theme itself does not appear to change, reopen **Workspace Theme** and check the selected item. For a repeated display problem, use [Browsers and devices](/getting-started/browsers-and-devices) to report the device, browser and theme choice.

Return to your task when the intended app theme is selected. [Where things are in Alysium](/help/where-things-are-in-alysium) helps locate the next screen.
