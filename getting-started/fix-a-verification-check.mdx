Complete the verification check on an account form so you can continue signing in, registering or requesting a password reset.

A form check is separate from confirming your email inbox. If the screen asks for an email link or **Verification code**, use [Sign-in and verification messages](/help/sign-in-and-verification-messages) for that step.

## Complete a waiting check

Stay on the form where **Complete verification to continue.** appeared.

| Your task | Form action |
|---|---|
| [Sign in](/getting-started/sign-in-to-alysium) | **Sign in** |
| [Create an account](/getting-started/create-an-alysium-account) | **Create an Account** |
| [Request a password reset](/getting-started/reset-your-password) | **Reset Password** |

1. Find the verification area.
2. Complete any interaction it requests.
3. Wait until the check succeeds.
4. Select the form action for your task.

Filling the email or password fields does not complete verification. A successful check also does not submit the form by itself.

## Retry a failed check

If the form shows **Verification failed. Retry to continue.**:

1. Select **Retry verification**.
2. Complete the new check on the same form.
3. Wait for it to finish.
4. Select the original form action from the table above.

For example, while recovering a password, the next action is **Reset Password**. You do not need to switch to registration. Keep the existing form open while the new check runs.

## If the submit button is still unavailable

After verification succeeds, check the other required fields. An incomplete name, invalid email or short signup password can still prevent submission. A disabled button is not always a verification failure.

Use the guide for the form you are completing: [Create an Alysium account](/getting-started/create-an-alysium-account), [Sign in to Alysium](/getting-started/sign-in-to-alysium) or [Reset your password](/getting-started/reset-your-password).

You have finished this verification task when the check succeeds and the original form action can run. Check the result of that submission separately; verification alone does not establish successful sign-in or registration.

## If the check keeps failing

Use [Get help from a person](/help/get-help-from-a-person) after the offered retry does not resolve it. Include the account screen, device and browser, exact visible message and whether **Retry verification** appears. Do not include a password or code.

If you need to reopen the account form, use the one for your task: [Sign in](https://app.alysium.ai/auth/login), [Create an account](https://app.alysium.ai/auth/signup) or [password recovery](https://app.alysium.ai/auth/forgot-password).
