Reset the password for your existing Alysium account when you cannot sign in with it. You need access to that account's email inbox. A reset does not create another account or move your agents.

If you normally use Google, first try the same Google option in [Sign in to Alysium](/getting-started/sign-in-to-alysium). This guide covers an Alysium password reset.

**Already have the reset email?** Continue with [Open the reset link](#open-the-reset-link). **Already on the new-password form?** Continue with [Enter a new password](#enter-a-new-password).

## Request the reset email

1. Open [Reset a forgotten password](https://app.alysium.ai/auth/forgot-password), or select **Forgot password?** from sign-in.
2. Enter the account address in **Email**.
3. Complete verification if shown.
4. Select **Reset Password**.
5. Wait for the screen saying a link was sent to that address.
6. Continue with [Open the reset link](#open-the-reset-link).

Use the registered inbox, rather than an unrelated address. A sent-link notice is not confirmation that the password has changed.

## Open the reset link

1. Open the reset email.
2. Follow its password-reset link.
3. Continue with [Enter a new password](#enter-a-new-password).

If the email is missing, check spam and the spelling of the requested address. If you entered the wrong address, [request the reset](#request-the-reset-email) for the correct one. If the link is not accepted, request a new reset.

## Enter a new password

1. Enter your chosen password in **New Password**, using at least 8 characters.
2. Enter the same value in **Confirm Password**.
3. Select **Change Password**.
4. Wait for the submission result.
5. Follow any further instructions shown.

The confirmation field checks for a typing mistake. A mismatch warning means the two values differ; enter them again. Typing a new password alone does not save it.

## Confirm access to the existing account

After the reset succeeds, return to [Sign in](https://app.alysium.ai/auth/login) and use the new password. [Sign in to Alysium](/getting-started/sign-in-to-alysium) covers the form and Google alternative.

Reaching the existing account's work is the useful result. You do not need to recreate agents because a password changed.

If recovery still fails, use [Get help from a person](/help/get-help-from-a-person) with the exact message. Do not share the reset link or password.
