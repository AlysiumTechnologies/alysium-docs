Chat with an agent before creating a named account when that agent permits guest access. Its access settings and offer still apply. A shared link does not promise unlimited free usage.

Guest access does not make you a member of the creator's space, let you edit their agent or give you a space where you can build your own.

## Open an available agent

1. Open the actual agent link shared with you, or browse [AgentHub](https://app.alysium.ai/agenthub) to choose one.
2. Read its description and access or preview message.
3. Find the chat or offered preview's message box when access is available.
4. Enter a question.
5. Select the arrow labelled **Send message**, or press Enter.
6. Read the reply.

AgentHub opens the catalog; you choose an agent there. [Try an agent for free](/agenthub/try-an-agent-for-free) covers a marketplace preview when one is offered. If [Chat](https://app.alysium.ai/chat) shows no agents, use the link you received or browse AgentHub. Do not guess a private agent address.

If an offer blocks further use, read [Free preview and paywall messages](/help/free-preview-and-paywall-messages). Creating another guest session is not a substitute for the agent's access requirements.

## Keep a main-app guest conversation connected

Guest access is temporary. If you want to return to the conversation through a named account, start the account transition before logging out or losing the guest session.

In the main app:

1. Keep the current guest session open.
2. Open or expand the app sidebar if needed.
3. Select **Create Free Account** in the sidebar's **Temporary Session** area.
4. If you already have an account, select **Sign in** on the account screen.
5. Complete the existing registration or sign-in flow.
6. Check the signed-in account and available conversations.

Use [Create an Alysium account](/getting-started/create-an-alysium-account) or [Sign in to Alysium](/getting-started/sign-in-to-alysium) for that flow's fields and confirmation steps. Guest signup can ask for a code and a password-completion step. Finish the flow already open rather than logging out and starting an unrelated guest session.

The transition can keep guest chats connected; check the actual result rather than assuming every transition succeeded.

## If you are using a website widget

A widget has separate **Account** navigation. Use [Visitor accounts and saved history](/widget-visitors/visitor-accounts-and-saved-history) for its account and history controls. Do not assume a temporary guest chat will appear on another device or website.

## Choose at a guest logout warning

As a guest, selecting **Log Out** from the main app opens a warning that ending the session removes access to its chats.

- Select **Stay signed in** to keep the session, then finish the account transition above if you want to retain its chats.
- Select **Log out anyway** only when you intend to end access to that session's chats.

[Log out](/getting-started/log-out) explains the main-app menu. Closing or losing a temporary session is not a dependable way to save it.

## Move from chatting to building

After creating a named account, open [Home](https://app.alysium.ai/spaces) to reach your active space. Follow [Create your first agent](/build-your-agent/create-your-first-agent) to begin building.

Using someone else's chat link grants access to that agent under its settings. It does not grant team membership or permission to manage the creator's agents.
