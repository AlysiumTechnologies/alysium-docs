Use this reference for documents added through **Knowledge** or **Library**. Visitor chat attachments, agent pictures and skill bundles have separate rules.

To add knowledge, open [Home](https://app.alysium.ai/spaces), select your agent, then open **Build → Settings → Knowledge**. [Library](https://app.alysium.ai/library) opens the area for storing and organizing your reference material.

## Supported knowledge formats

| Document type | Accepted extensions |
|---|---|
| PDF | `.pdf` |
| Word | `.doc`, `.docx` |
| Excel | `.xls`, `.xlsx` |
| CSV | `.csv` |
| Text | `.txt`, `.text` |
| Markdown | `.md`, `.markdown` |

The actual contents must match the format. Renaming an extension does not convert a file. HTML files, PowerPoint presentations and image files are not accepted as stored knowledge documents.

For a short first FAQ, a clear text or Word document is often easier to inspect than a complex export.

## Document, pasted-text and space limits

| Limit | Amount | What it applies to |
|---|---|---|
| Individual document | 25 MiB | Each stored knowledge document. The upload area may label this binary limit as 25 MB. |
| Pasted text | 1,000,000 characters | One pasted-text submission, which also needs storage space. |
| Free storage | 2 GB | Stored material across the space. |
| Pro storage | 100 GB | Stored material across the space. |

The storage allowances are per space, rather than per agent. A whole file selection needs enough available space even when each file is individually below 25 MiB.

Files in **Trash** still count toward storage until erased. Chat-credit overages do not increase document storage.

## Match the remedy to the limit

| Problem | What to do |
|---|---|
| Unsupported format | Export the contents to an accepted format. Changing the extension alone will not help. |
| Individual file too large | Reduce it or split it into useful topic documents. Each resulting file must meet the format and size rules. |
| Space storage full | Review stored material, including Trash, and your space's plan. Read [Storage limits](/knowledge-and-library/storage-limits) before erasing material to make room. |

For example, split a large handbook into understandable topic files rather than arbitrary fragments. This helps you inspect the material as well as meet the individual-file cap.
