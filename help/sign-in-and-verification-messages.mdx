Match the message on your account screen to the section below. A verification check on a form, email confirmation, a password mismatch and guest-account completion need different actions.

Use [Sign in](https://app.alysium.ai/auth/login) for an existing account, or [Create an account](https://app.alysium.ai/auth/signup) for registration. Finish an outstanding confirmation step before registering again.

## Complete verification to continue.

Finish the verification check displayed on the form before submitting it. This check is separate from an email confirmation link.

If the message changes to **Verification failed. Retry to continue.**:

1. Select **Retry verification**.
2. Complete the new check.
3. Submit the original form.

[Fix a verification check](/getting-started/fix-a-verification-check) explains the task in context.

## You're almost there! Just confirm your email

The full notice says: “You're almost there! 🚀 Just confirm your email to sign in — check your inbox (and spam) for the verification link, then you're in.”

1. Check the inbox and spam folder for the account's email address.
2. Follow the confirmation link and instructions in the email.
3. Try signing in again.

Use **Resend email** on the notice if the email has not arrived. You do not need another account to complete confirmation.

## That email and password don't match.

The full message says: “That email and password don't match. Give it another go, or reset your password if you're stuck.” It does not identify which entry is wrong.

Check the email address, password and account method you intended to use. For a Google account, use the Google sign-in flow. If you cannot recover the password, select **Forgot password?** and follow [Reset your password](/getting-started/reset-your-password).

## Wait before resending another link

**Almost — you can request another link in a moment. Hang tight, then try again.** means you need to wait before requesting another resend.

**We couldn't resend just now. Give it another go in a moment.** also asks for a later retry. Neither message establishes an exact wait duration. Repeated clicks do not complete verification.

If the message continues, use [Get help from a person](/help/get-help-from-a-person) with its exact wording.

## Verification code or Choose a password

These screens can appear while completing a guest account. Finish the existing flow so the guest chats can remain connected.

For **Verification code**:

1. Read the email address shown on the screen.
2. Retrieve the code sent to that address.
3. Enter the code.
4. Select **Verify and create account**.

If **Choose a password** appears next:

1. Enter the password you want to use.
2. Select **Set password**.

Never send the code or password to Brandy or another agent. [Create an Alysium account](/getting-started/create-an-alysium-account) covers these steps in context.

## That account is already registered.

The full notice says: “That account is already registered. Please sign in to continue.” Follow [Sign in to Alysium](/getting-started/sign-in-to-alysium).

Changing the email spelling identifies a different account; it does not finish access to the existing one. After successful sign-in, [Home](https://app.alysium.ai/spaces) opens the account's active space.

## An unrecognized or repeated message

Note the form, action, exact message, device and browser. If the matching recovery does not work, contact [support@alysium.ai](mailto:support@alysium.ai) using [Get help from a person](/help/get-help-from-a-person). Leave passwords, codes and reset links out of the request.
