<span id="sign-in-and-verification-messages" />

Find the message shown on your account screen. A form verification check, an email confirmation and a password problem each need a different next step.

## Complete verification to continue.

Complete the verification check displayed on the form, then submit the form. This check is separate from confirming your email address.

If you see **Verification failed. Retry to continue.**, select **Retry verification**, complete the new check and submit the original form again. You can [work through the form verification check](/getting-started/fix-a-verification-check) if that step keeps failing.

<span id="youre-almost-there-just-confirm-your-email" />

## You're almost there! Just confirm your email

The notice asks you to confirm your email before signing in. Check the inbox and spam folder for the address you entered, open the confirmation email and follow its link. Then try signing in again.

To request another email, check the address on the sign-in form, complete any displayed form verification and select **Resend email** on the notice. **Sent!** confirms that a fresh link was requested; check that inbox again.

<span id="that-email-and-password-dont-match" />

## That email and password don't match.

This message does not identify which entry is wrong. Check that you are using the intended email address and password. If you normally use Google, use the Google sign-in option instead.

For an email-and-password account, **Forgot password?** opens the reset flow. Request the reset email for that account, then follow the email's link to choose a new password. You can [follow the full password reset steps](/getting-started/reset-your-password) if you need help completing it.

## Wait before resending another link

**Almost — you can request another link in a moment. Hang tight, then try again.** means another resend is temporarily limited. Wait before trying **Resend email** again.

**We couldn't resend just now. Give it another go in a moment.** also calls for a later retry. Use the result of that retry to decide whether the request succeeded.

## Verification code or Choose a password

These steps can appear when turning a guest account into an account you can return to.

- On **Check your email**, retrieve the code sent to the address shown, enter it in **Verification code** and select **Verify and create account**.
- If **Choose a password** appears, enter the password you want to use and select **Set password** to finish that step.

Complete the step already on screen. The [account creation guide](/getting-started/create-an-alysium-account) explains how these guest-account steps fit into registration.

## That account is already registered.

Use [Sign in](https://app.alysium.ai/auth/login) to access the existing account. Use its email and password or its Google sign-in method. Changing the email spelling will not recover the original account.

Successful sign-in may return you to the task you were completing. You can open [Home](https://app.alysium.ai/spaces) to reach your active space.

<span id="an-unrecognized-or-repeated-message" />

## If the matching action does not help

Email [support@alysium.ai](mailto:support@alysium.ai) with the form you were using, the exact message, the action you tried and its result. Keep passwords, verification codes and reset links out of the request. You can [prepare a help request](/help/get-help-from-a-person) with the details relevant to your problem.
