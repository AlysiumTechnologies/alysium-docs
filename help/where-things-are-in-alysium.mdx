Use this map to find the screen for creating an agent, adding reference material, changing a setting or chatting. The main app manages your work, the builder edits one agent, and visitor chat has its own menus.

## Main app

The main sidebar links to these areas. When it is hidden on a smaller screen, use the top **Open navigation menu** button.

| Area | What you can do there |
|---|---|
| [Home](https://app.alysium.ai/spaces) | See your current space's agents. Select **Build** on the intended agent's card to edit it, or **Create New Agent** to start another. |
| [Chat](https://app.alysium.ai/chat) | Choose an agent under **Your Agents** or **Shared with You**, when present, or search for it. Use the conversation sidebar to find existing chats. |
| [Library](https://app.alysium.ai/library) | Organize reusable documents, pasted text and saved website sources in projects and folders. |
| [Analytics](https://app.alysium.ai/analytics) | Review agent activity, retained conversations and available answer feedback. |
| [AgentHub](https://app.alysium.ai/agenthub), labelled **Agenthub** in the sidebar | Browse available agents and inspect each offer's access and subscription choices. |

A **space** holds agents, files and its plan and usage allowance. Home opens your current space; you choose the agent there. Material stored in Library becomes an agent's knowledge when you attach it to that agent.

On a narrow Chat screen, **Conversations and agents** opens Chat's own drawer. It is separate from the main app's navigation menu.

## Account and space settings

Select **Profile Settings** in the sidebar or avatar menu. The [settings entry](https://app.alysium.ai/spaces?settings=team) opens the current space's **Team** tab, where you can select another tab.

| Tab | What it contains |
|---|---|
| **Team** | Current space owner information. Spaces currently contain only their owner; invitations and member-role changes are unavailable. |
| **Space Settings** | The space's creator handle. |
| [Billing](https://app.alysium.ai/spaces?settings=billing) | The space plan and payment controls, plus **Agent Access and Subscriptions** for individual agents. This link opens Billing directly. |
| **Consumption** | The space's credit usage. This differs from agents' conversation Analytics. |
| **Privacy** | Separate **Product analytics** and **Session Replay** choices. |
| **Creator** | Creator setup, offers, subscriber and payout views for the space owner. |

A Pro space plan and a subscription to a creator's agent are separate purchases. **Profile Settings** is also separate from the agent's profile: it has no personal-name or account-photo editor.

## Agent builder

Open Home and select **Build** on the intended agent's card. The builder's main tabs are **Build**, **Design** and **Deploy**. On a narrow screen, these sit in the bottom dock.

### Build: behavior, knowledge and profile

Within Build, **Settings** contains the setup controls and **Profile** contains the agent's public presentation. A wide screen shows chat beside those controls; a narrow screen has a separate **Chat Preview** view.

| Location | What you can find there |
|---|---|
| Start of **Settings** | **Agent Name**, **Welcome Message** and **Suggested Conversation Starters**. |
| **Agent Builder** section in Settings | **AI Models**, response fine-tuning settings, **Agent Instructions** and **Skills**. Scroll to this section. |
| **Knowledge** section farther down Settings | **Upload Documents**, **Paste Text**, **Add from Library** and website knowledge controls. **Behavior**, inside Knowledge, appears when knowledge is present and controls how answers should use it. |
| **Tools** section | Available tool setup. [Current action-tool limits](/help/what-alysium-cannot-do-yet) explain what this version can use in chat. |
| **Profile** | The agent's avatar, banner and **Description**. These images belong to the agent. |
| **Chat Preview** | Try the editable agent before publishing it. Preview messages use the space's credits. |

Knowledge and Website are sections within Settings, rather than main builder tabs. The description explains the agent to people; instructions guide its behavior; knowledge supplies reference material.

Agent name, instructions, description and a valid welcome message save automatically. Starter text saves when you click or tap outside its field. Wait for saving to finish before leaving. You can reopen the same agent to check that an edit remains.

When testing, include the context each preview request needs. You can [plan checks for facts, missing information and task boundaries](/build-your-agent/test-your-agent-while-you-build).

### Design: visitor appearance

Design contains theme, chat-window text, visitor-menu content, features and conversation-navigation choices. On a narrow screen, use its **Design** view for controls and **Preview** to inspect appearance; a wide screen shows both.

For a theme change, **Change** opens the theme choices and **Done** closes them. After editing Design, select **Save Changes** and wait for **All Changes Saved**. The appearance preview can show unsaved edits, so check the save result before leaving. You can [adjust the visitor appearance in more detail](/design-your-widget/change-how-your-widget-looks).

### Deploy: sharing and publishing

The launch card shows the agent's readiness. **Finish in Build** identifies missing name or instructions. **Make agent live** saves Published status and Public access together; **Live** confirms that launch state.

| Method | What it prepares |
|---|---|
| **Share link + QR** | A standalone visitor-chat destination. The agent must be live and **Direct link** enabled before its usable link and QR appear. |
| **Embed on a website** | Website installation code and **Allowed websites**. Installing the code is separate from designing the widget. |
| **Share & Sell** | Paid-offer and marketplace setup, with separate requirements. Copies of another creator's agent do not offer this relisting option. |

**Advanced** holds separate controls, including permanent deletion. Making an agent live does not enable every delivery method or create an AgentHub listing. The chat header's **Share** is a separate chat-access flow; use Deploy for the [standalone link and QR task](/share-and-deploy/share-your-agent-with-a-link-and-qr-code).

## Visitor chat menus

A website widget has **Home**, **Chat** and **Account** browse navigation. During an active chat, use **Back to browse** to return to that navigation when the footer is hidden.

Account includes **About This Agent**, **View conversations**, **Your uploaded files**, **Conversation history**, **Data & Privacy** and **Help & Support**. **Terms & Privacy** appears when the creator has supplied its link. Help & Support opens the creator's configured help destination or the chat's contact screen.

**Your uploaded files** is a place to review chat files, separate from the creator's Library. **Data & Privacy** describes that visitor chat; the main app's Privacy tab controls optional product analytics and Session Replay.

A standalone direct-link chat uses its own **Open menu** control during chat. Its navigation differs from the website widget's footer. Access to visitor chat does not give someone permission to edit the agent.

## Find the right surface

For creator work, [Home](https://app.alysium.ai/spaces) gets you to your current space and the intended agent's **Build** button. For visitor history, uploaded files or chat privacy, use that chat's own menu.

You can [look up an unfamiliar term](/help/alysium-glossary), or [follow a complete first-agent project](/about-alysium/how-to-get-started) to see how the builder's areas work together.
