Use this map to find the screen for building an agent, adding reference material, changing settings or chatting.

The main app manages your work. The builder edits one agent. A visitor chat, including a website widget, has its own menus. If you only see visitor chat, open [Home](https://app.alysium.ai/spaces) to reach the main app with your creator account. If asked to sign in, sign in and open Home again if needed.

On a small screen, use the navigation-menu button at the top when the sidebar is hidden.

## Main app

| Area | Use it for |
|---|---|
| [Home](https://app.alysium.ai/spaces) | Opens your active space's agents. Select an agent to enter its builder, or select **Create New Agent** to start another. |
| [Chat](https://app.alysium.ai/chat) | Opens the conversation area. Find an agent under **Your Agents** or **Shared with You**, or use search, then open it to begin or resume a conversation. |
| [Library](https://app.alysium.ai/library) | Stores documents, pasted text, folders, projects and saved website sources for organization and reuse. |
| [AgentHub](https://app.alysium.ai/agenthub), labelled **Agenthub** in the sidebar | Browse or search available agents. Open an agent's page to inspect its details and offered access or subscription choices. |
| [Analytics](https://app.alysium.ai/analytics) | Review your agents' activity, conversations and available answer feedback. This differs from Consumption, which shows space credit usage. |

A space holds your agents, files and plan. The Home link opens your active space; it does not choose an agent for you.

A file in Library is not automatically available to every agent. Attach the file or a suitable folder to the agent's **Knowledge**. A visitor's conversation attachment is a separate kind of upload.

## Account and space settings

Select **Profile Settings** in the sidebar or avatar menu. You can also [open Team settings](https://app.alysium.ai/spaces?settings=team), which opens that tab for your active space, then select the tab you need.

| Tab | Use it for |
|---|---|
| **Team** | The space's owner information. A space currently contains only its owner; inviting members and assigning roles are unavailable. |
| **Space Settings** | The creator handle. |
| [Billing](https://app.alysium.ai/spaces?settings=billing) | The space's plan and payment controls, plus individual agent subscriptions. This link opens Billing for the active space. |
| **Consumption** | Credits used by the space. |
| **Privacy** | Optional analytics choices. |
| **Creator**, when available | Creator and payout views. |

A Pro space plan and a subscription to an individual agent are separate purchases. **Profile Settings** does not contain a personal-name or account-photo editor.

## Agent builder

Open [Home](https://app.alysium.ai/spaces), then select the intended agent. Within its builder, use **Build**, **Design** or **Deploy** for the area you need.

### Build: behavior, knowledge and profile

| Location | What you can find there |
|---|---|
| **Build → Settings → Agent Instructions** | The agent's job, behavior and boundaries. |
| **Build → Settings → Knowledge** | Files, pasted text, Library attachments and website content. |
| **Build → Settings → Agent Name** | The agent's name. |
| Other controls in **Build → Settings** | Welcome message, starter prompts, model choice and optional tools. See [What Alysium cannot do yet](/help/what-alysium-cannot-do-yet) for current action-tool limits. |
| **Build → Profile** | The agent's public description and images. These do not change your personal account photo. |
| **Build → Chat Preview** | A working conversation to try the agent while editing. On a wide screen, the preview can appear beside the controls. |

The description explains the agent to people; instructions guide how it answers. Start with its job and source facts before changing advanced settings.

Chat Preview can use credits. You can try an agent in the builder before making it public.

### Design: visitor appearance

Open **Design** for website-chat appearance: theme, chat-window text, visible features and visitor-menu settings. Check the appearance preview, then select **Save Changes** after editing.

Seeing an edit in the Design preview does not by itself confirm that it was saved for visitors.

### Deploy: sharing and publishing

| Control or card | Purpose |
|---|---|
| Launch card | Making the agent live, with its publication and public-access requirements. |
| **Share link + QR** | Standalone chat link and QR code. |
| **Embed on a website** | Website installation code and **Allowed websites**. |
| **Share & Sell** | Marketplace setup with separate requirements. This option can be absent on a copy of another creator's agent. |

The chat header's **Share** menu is a separate collaboration-link flow. Use [Share your agent with a link and QR code](/share-and-deploy/share-your-agent-with-a-link-and-qr-code) for the Deploy link and QR task.

## Visitor chat menus

A website widget has its own **Home**, **Chat** and **Account** navigation. Depending on enabled features, Account can offer **View conversations**, **Your uploaded files**, **Data & Privacy** and **About This Agent**.

These are visitor options. To change the agent's Build, Design or Deploy settings, open the main app and select the agent from Home.

## If a control is missing

Check whether you are in the main app, an agent's builder or visitor chat. Then check the agent and active space. Being able to chat with someone else's agent does not grant permission to edit it.

For an unavailable invitation, account-profile editor or chat action, check [What Alysium cannot do yet](/help/what-alysium-cannot-do-yet). A missing control does not establish that another menu contains a working version.

Use [How to get started](/about-alysium/how-to-get-started) for a first-agent journey, or [Alysium glossary](/help/alysium-glossary) for an unfamiliar term. The task guides explain the inputs, saves and results after this map gets you to the right screen.
