<span id="add-a-website-to-your-agent’s-knowledge" />

Give your agent reference information from a public website. You supply the starting address, scan its pages, review what was collected and save the useful pages for answers.

Choose a website you own or are allowed to use. A public FAQ or service page is a manageable first source. The agent answers from the saved material; a scan collects that material ahead of the conversation.

<span id="if-the-form-is-unavailable" />

## Open the website setup

1. Open [Home](https://app.alysium.ai/spaces) and select your agent.
2. Open **Build** and scroll down to **Knowledge**. If you are viewing Profile or Chat Preview, select **Settings** first.
3. In the **Website** section of Knowledge, select **Add your website**.

If you already added a website to this agent, you will see its source card here instead. **Review pages** opens the collected material, and **Refresh** scans the saved address again. To keep that source and add another starting address, [collect the new website in Library](/knowledge-and-library/add-a-website-to-your-agents-knowledge#use-library-to-collect-a-website-for-reuse) and attach its folder to the agent.

## Enter the address and choose the scan scope

For a new website, enter the full URL of the public page you want the scan to start from. Use a page that contains the information you need or links to it, rather than a page behind a customer login.

You can leave the optional settings unchanged for a first scan. Select **Crawl settings** if you want to adjust how much to collect or when to scan again:

| Setting | What it controls |
|---|---|
| Link depth | How far the scanner follows links from your starting page. A larger depth can reach pages farther away. |
| Maximum pages | The most pages the scan should collect. It may find fewer. |
| Pages to skip | Pages or sections you want to leave out. |
| Re-scan schedule | When to request another scan for updated website information. |

Use the labels and values shown in the form. For **Pages to skip**, a path such as `/blog` excludes that section and its pages. Press Enter or Space after typing a path to add it as an entry; use its remove button to undo it.

Select **Scan website**. If the form marks a field, correct the value and submit again. Wait for the scan results; you can use **Stop scan** if you need to stop collection.

## Review and save the pages

The results show page names, addresses and how many pages were found. Expand a page to read the collected text. Check that it contains the facts you want the agent to use, and **Remove** any unwanted pages.

On this first scan, **Scanned** means a page has been collected but has not yet been saved as answerable knowledge.

1. Select **Save to Memory** to prepare the remaining unsaved pages for answers. For a single pending page, you can use its **Save** action.
2. Wait for the intended pages to show **Saved**. **Saving…** means that work is still underway.
3. Check the switch on the website source card. It should show **Active** when you want the agent to use this source; **Paused** turns that use off.

If you close the results, **Review pages** on the source card opens them again. Pages already marked Saved have completed the saving step.

## Check an answer against the source

Use the chat beside the Build settings, or select **Chat Preview** within Build on a smaller screen. Ask about a specific fact you just read on a Saved page. Select **Send message** or press Enter, then compare the reply with the collected text. The completion message's **Ask in the preview** action can send a suggested question for you.

For example, if the collected FAQ says a service is available on Saturdays, ask whether it is available on Saturdays. Use an actual fact from your source so you can tell whether the reply is supported.

If the answer misses the information, check that the relevant page is Saved and the source is Active. Then review **Agent Instructions** for a conflicting rule. The [knowledge troubleshooting guide](/knowledge-and-library/why-your-agent-cant-find-something) has further source and answer checks.

## Update or retry the website source

When the website changes, select **Refresh** on its source card. Refresh uses the address you saved and processes changed pages. Review the collected result before relying on the new information in answers. The source's schedule requests later scans; **Active** controls whether its saved knowledge is used.

Use the recovery offered for the state you see:

| What you see | What to do |
|---|---|
| A page shows **Failed** | Select that row's **Retry**, then check its status. |
| The scan says **The last scan failed. Try again.** | Select **Try again**. On the source card, a failed refresh offers **Retry**. |
| A message asks you to wait before retrying | Wait for the countdown and use the retry control when it becomes available. |
| No useful pages were collected | Check that your starting page opens publicly and contains readable text, or links to the material within your chosen scope. For material the scanner cannot read, add its text as a document. |

For information the scanner cannot collect, you can add an approved file with **Browse files** under Knowledge, or enter a passage in **Paste Text** and select **Add as Document**. Wait for the resulting document to become Ready. The [file upload guide](/knowledge-and-library/upload-files-to-your-agent) explains supported formats and limits.

If repeated attempts still fail, email [Alysium support](mailto:support@alysium.ai). Include the URL you tried to scan, the agent's name, the action you tried and any message the screen displayed. Say what happened when you retried.

## Use Library to collect a website for reuse

Library is useful when you want to organize website material centrally or add another starting address while keeping an agent's existing source. Collection and attachment are separate steps here:

1. Open [Library](https://app.alysium.ai/library), then the project where you want to keep the website.
2. Select **Add new**, then **Add your website**. Enter the starting URL, check the destination and adjust **Crawl settings** if needed.
3. Select **Add website**. Open the resulting website entry and check its **Pages** list and collected text. Library processes those pages during collection. If the entry was saved but the scan could not start, read the displayed result and use **Scan again** from that existing entry when you can retry.
4. Open your agent in Build, return to its Settings view if needed and scroll to Knowledge. Select **Add from Library**, expand the destination project and select the website's folder.
5. Check the selection summary and select **Attach**. Confirm the folder appears in **Attached knowledge**, then try a question about one of its collected facts.

Attaching that folder gives the agent access to eligible material already there and eligible pages added there later. You can [choose a different Library attachment scope](/knowledge-and-library/use-library-files-in-an-agent) if you want a narrower selection.

For a saved Library website, its three-dot menu contains **Website settings**, where you can [change the collection scope and schedule](/knowledge-and-library/change-website-scan-settings).
