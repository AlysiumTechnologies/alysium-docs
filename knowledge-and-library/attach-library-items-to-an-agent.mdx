Choose a saved source in Library, then choose which agent or agents should use it. This is useful when the material is already organized and you want to attach it without opening each builder first.

Attaching knowledge does not publish an agent or make Library public. You need access to the material and permission to edit each selected agent.

**Already in the agent chooser?** Continue with [Choose the agents](#choose-the-agents).

## Choose the material

1. Open [Library](https://app.alysium.ai/library).
2. Find the intended file, folder or project.
3. Open its **Attach to agent** action.
4. Continue with [Choose the agents](#choose-the-agents).

For several files, select the files first. Use the bulk attachment action. Continue with [Choose the agents](#choose-the-agents).

Library opens your current space's saved material. If the link asks you to sign in, sign in. Open Library again if needed.

Attaching a file includes that file. A folder or project covers its eligible contents, including eligible material added there later.

For example, choose a fictional **Approved FAQ** folder only when its ongoing contents belong in the selected agents' knowledge. Avoid attaching an entire project containing private drafts just for convenience.

## Choose the agents

1. Read the summary of material being attached.
2. Use **Search agents** if needed.
3. Select the intended agents with their checkboxes.
4. Review the selected count.
5. Select **Attach** for one agent, or the button naming the selected number of agents.
6. Wait for the operation to finish.
7. Read the result.

The chooser supports multiple agents. Check the selection rather than assuming the first visible row is the only target. If the action only partly succeeds, inspect each returned outcome before retrying.

## Verify an attachment

1. Open [Home](https://app.alysium.ai/spaces).
2. Select one of the agents you chose.
3. Open **Build**.
4. Open **Settings**.
5. Find **Knowledge**.
6. Check the source in **Attached knowledge**.

Home opens your active space, where you choose the agent. Repeat this check for any target whose result is uncertain.

No second upload or Design **Save Changes** action is required. A file that is still processing must become **Ready** before useful knowledge questions. Try a question answered by the source, and use [Control how your agent uses its knowledge](/knowledge-and-library/control-how-your-agent-uses-its-knowledge) for its Behavior choices.

## If an agent is missing or an outcome is unclear

Clear the agent search and check the current space. An agent you cannot edit may not be offered. If the space has no agents yet, follow [Create your first agent](/build-your-agent/create-your-first-agent), then return to this attachment task.

For an uncertain or partial result, check the actual attachments rather than assuming every target changed. You can instead start from a particular builder using [Use Library files in an agent](/knowledge-and-library/use-library-files-in-an-agent).

If you chose the wrong agent or source scope, follow [Remove a file from your agent](/knowledge-and-library/remove-a-file-from-your-agent). Removing one agent's attachment leaves the Library material saved.
