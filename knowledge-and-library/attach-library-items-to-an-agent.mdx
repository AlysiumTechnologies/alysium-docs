<span id="attach-library-items-to-an-agent" />

Choose saved material in Library, then choose the agents that should use it for answers. You can reuse the same source across several agents without uploading it again.

## Choose the material

Open [Library](https://app.alysium.ai/library), which contains your current space's saved material. Choose the scope before attaching it:

- A **file** gives the agent that file.
- A **folder or project** gives the agent its eligible contents, including eligible material added there later.

For example, attach an **Approved FAQ** folder when everything you will put there belongs in the agent's knowledge. Choose individual files if the wider project also contains drafts.

Use the action for the material you chose:

| Material | How to open the agent chooser |
|---|---|
| One ordinary file | Open its three-dot menu and select **Attach to agent**. This works on the Library landing and inside a project or folder. |
| A project or folder from its card | Select the **Projects** breadcrumb to return to the Library landing. Find its card, open its three-dot menu and select **Attach to agent**. |
| Several ordinary files, or an ordinary child folder inside a project or folder | Select their checkboxes, then select **Attach to agent** in the selection bar. |

Visitor uploads need approval through their separate workflow before becoming agent knowledge.

## Choose the agents

1. Read the material summary in the chooser.
2. Choose agents from the unfiltered list, using **Show more** to load more of the roster, or enter a name in **Search agents** to work with one search's results.
3. Select the intended agents' checkboxes within that list. Finish this attachment before changing the search to choose a different set of agents.
4. Select **Attach** for one agent, or **Attach to N agents** for several.
5. Wait for the result and read the message. It can report new attachments, material already attached, refusals or a partial result.

An already attached source is reused. For a partial result, check the named agents before retrying only the missing attachment.

## Verify an attachment

1. Open [Home](https://app.alysium.ai/spaces) and select **Build** on one of the chosen agents' cards.
2. Select **Settings** if another Build view is open, then scroll down to **Knowledge**.
3. Check the source in **Attached knowledge**. Wait for the file you want to test to show **Ready**.
4. Ask a self-contained question that the source actually answers in the chat beside the settings. On a smaller screen, select **Chat Preview** within Build. Compare the answer with the source.

A folder or project marked **Live** remains connected to its ongoing contents; check individual files for **Ready** before testing them. Preview messages use your space's credits.

Repeat the attachment check for any agent whose result was uncertain. Once the intended sources are attached, you can [choose how closely answers follow the knowledge](/knowledge-and-library/control-how-your-agent-uses-its-knowledge).

## If an agent is missing or an outcome is unclear

Clear a mistaken **Search agents** query and use **Show more** to inspect the unfiltered roster. If loading fails, select **Try again**. If the chooser says **No agents yet**, [create an agent](/build-your-agent/create-your-first-agent), then return to Library.

If an attachment is refused, read the result before retrying. If it times out or only partly succeeds, inspect **Attached knowledge** in the affected agents first; an unclear result does not establish which attachments changed.

If you chose the wrong source or agent, you can [remove the attachment](/knowledge-and-library/remove-a-file-from-your-agent) while leaving the material saved in Library. When you are already editing one agent, you can instead [choose saved material through Add from Library](/knowledge-and-library/use-library-files-in-an-agent).
