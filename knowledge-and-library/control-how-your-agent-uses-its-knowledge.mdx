Choose how closely your agent should follow its sources, whether it should search knowledge before answering and how it should handle a missing answer. These choices apply to this agent's attached file and website knowledge.

## Open Behavior

1. Open [Home](https://app.alysium.ai/spaces) and select **Build** on the intended agent's card.
2. Select **Settings** if another Build view is open, then scroll down to **Knowledge**.
3. Open **Behavior** if it is collapsed. Its summary shows the current grounding, search-first setting and standard or custom missing-answer reply.

Behavior appears after an agent has a file attachment, a folder or project attachment, or a website source. An attached folder can still be empty, so check that the agent has useful, prepared content before testing these choices.

## Choose the answer boundary

Under **Answer grounding**, select the approach that fits the agent's job:

| Choice | What it asks the agent to do |
|---|---|
| **Strict** | Answer from retrieved knowledge and acknowledge when it does not contain the answer. |
| **Balanced** | Prefer its knowledge while allowing general information. Claims about your business or offering should stay grounded in your sources. This is the default. |
| **Open** | Use its knowledge alongside general information, preferring the source facts when the two conflict. |

For a factual customer FAQ, start with **Strict**. For an agent that explains broad topics or helps brainstorm, **Balanced** or **Open** may fit better. These settings guide the answers; they do not guarantee that the agent will avoid mistakes.

## Decide whether to search first

**Always consult knowledge before answering** is on by default. When the agent has usable knowledge, this makes it search that knowledge at the start of a reply. The agent can decide whether further searches are needed.

Turn it off if you want the agent to choose when to search. It can still use knowledge, and it is still instructed to search for factual questions about your business or offering. Turning this off does not disable the attached sources.

Grounding and search-first behavior serve different purposes: grounding guides what the answer may draw on, while this switch controls the first search. Neither setting makes an unprocessed or unattached source available.

## Write the missing-answer reply

In **When the answer isn't in my knowledge…**, enter up to **500 characters** of guidance for a knowledge gap. Leave it blank to use the standard guidance.

Give the person a useful next action. For a café whose FAQ directs customers to its counter, you could write:

> I don't have that detail in the café FAQ. Please ask a café team member at the counter.

Use your business's actual contact route. The agent uses this wording as guidance and may phrase its reply differently. Ask it to direct the person to help; do not say that it has sent an email, created a ticket or changed an account.

## Apply and save a factual-FAQ setup

For an agent that should answer from a supplied FAQ:

1. Select **Strict** under **Answer grounding**.
2. Keep **Always consult knowledge before answering** on.
3. Enter missing-answer guidance with the real contact route.
4. Pause for about a second to let these choices save automatically before leaving.

Return to [Home](https://app.alysium.ai/spaces) and reopen **Build** on the same agent. Select **Settings** if needed, scroll down to **Knowledge** and open **Behavior**. Check that the three choices remain as you set them.

## Try a known fact and a gap

First check the sources in **Knowledge**. A file should be **Ready** in **Attached knowledge**. For a direct website source, open **Review pages**, check that the relevant page is **Saved**, and keep the source **Active**. Choose a specific fact in that source and a question it does not answer.

Preview messages use your space’s credits. Use the chat beside the Build settings, or select **Chat Preview** within Build on a narrow screen:

1. Ask the question that the source answers. Select **Send message** or press Enter.
2. Compare the complete reply with the actual source passage.
3. Ask the uncovered question and send it.
4. Check whether the reply handles the gap as you intended and gives the useful next action.

Ask about the source's subject in a complete question. You can [plan a broader set of preview checks](/build-your-agent/test-your-agent-while-you-build) as you refine the setup.

## If the behavior does not match

If a fact is missing, check that the source contains it, is attached to this agent and has finished processing before loosening the grounding. A folder or project attachment needs eligible content inside it.

If the agent invents a policy or ignores the gap guidance, recheck the saved choices in Behavior. Scroll up to **Agent Instructions** in the **Agent Builder** section and look for a conflicting direction. Let any correction save, then ask the question again and compare the full reply. For a source-specific problem, you can [check why the agent cannot find the information](/knowledge-and-library/why-your-agent-cant-find-something).
