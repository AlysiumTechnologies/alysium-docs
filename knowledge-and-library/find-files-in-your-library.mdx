Search your space's saved material by name, narrow the file results and preview the source before using it. Finding a file in Library lets you check its contents; its attachment to an agent is a separate choice.

## Search by name

1. Open [Library](https://app.alysium.ai/library). If you are inside a project or folder, select the **Projects** breadcrumb to return to the landing.
2. In **Search files, folders and projects**, enter a recognisable part of the name, such as **customer** for **Customer questions.md**. File search ignores capitalisation and matches part of the filename, rather than words inside the document.
3. Open a matching file using its thumbnail or its three-dot menu's **Preview** action.
4. Read the contents and check the file's status to confirm you found the source you intended.

The landing searches across locations in your current space. Inside a project, **Search project** searches files at that project's root. Inside a folder, **Search folder** searches files directly in that folder. These scoped fields do not search files nested in subfolders. Open a subfolder to search there, or use **Projects** to return to the search across locations.

Subfolder cards remain visible during a scoped file search. Their presence does not mean the query searched their contents.

You can switch the display with **View as list** or **View as grid**. Inspect the actual source before choosing it: a familiar name or a recent date does not establish that it is the latest approved version.

## Narrow the results

Use **Type** to narrow the file families shown. Use **Usage** to choose how files are being used:

| Usage choice | What it shows |
|---|---|
| **All** | Files regardless of usage. |
| **Attached** | Files used by at least one agent. |
| **Unused** | Files used by no agents. |
| **Visitor uploads** | Files sent by visitors. These still need approval before becoming agent knowledge. |

If a file disappears from the results, clear any unintended **Type** filter and set **Usage** to **All** before deciding it is missing.

## Choose a sort order

Open **Sort**, which shows the current choice. Choose **Newest** for recently added files, **Oldest** for earlier ones, or **A–Z** or **Z–A** to order names alphabetically. **Most relevant** is also available; for files, it currently uses the same order as **Newest**.

Sorting and filtering change the view. They leave file contents and agent answer settings unchanged.

## If the file is still missing

1. Select **Projects** to search across the current space rather than only the open location.
2. Shorten or clear the name query, clear an unintended **Type** filter and choose **Usage → All**.
3. Check the project or folder chosen when the file was saved.
4. Check [Trash](https://app.alysium.ai/library?view=trash) for a deleted file. You can [restore recoverable files](/knowledge-and-library/restore-or-permanently-delete-from-trash) from there.

If an upload is still processing or has failed, inspect the existing attempt's status before uploading another copy. The [upload and file messages](/help/upload-and-file-messages) explain those states and the recovery actions available for that attempt.

Once you find the right material, you can [move or rename it](/knowledge-and-library/organise-your-library), or [choose the agents that should use it](/knowledge-and-library/attach-library-items-to-an-agent).
