Search and filter material already saved in your space before uploading another copy. Finding a document is separate from checking which agents have it attached.

## Search by name

1. Open [Library](https://app.alysium.ai/library).
2. Enter a recognizable part of the name in **Search files and folders**.
3. Open a matching result, or use its **Preview** action.
4. Check that it has the intended version and contents.

Library opens your current space's material. If the link asks you to sign in, sign in. Open Library again if needed.

For example, search **customer** rather than the full fictional filename `Customer questions.md`. If nothing matches, shorten the query and check the active project or location. Search does not reveal material you are not allowed to read.

## Narrow the results

Type choices narrow the families of items shown. Usage filters help you find material by how it is used:

| Usage choice | Use it for |
|---|---|
| **All** | Removing an unintended usage restriction from the results. |
| **Attached** | Material used as agent knowledge. |
| **Unused** | Material not attached. |
| **Visitor uploads** | The separate category of files sent by visitors. These are not automatically approved agent knowledge. |

A forgotten filter can hide a file that still exists. Clear filters you do not need before deciding a source is missing.

## Choose a sort order

Use **Newest** for a file added recently, or **Oldest** for earlier material. **A–Z** and **Z–A** help when you know the name. **Most relevant** is available for relevance-based searching.

Sorting changes the view without changing file contents or the agent's answer behavior. A familiar filename alone does not establish that a document is the latest approved version; inspect the result.

## If the file is still missing

1. Check the account and space you are using.
2. Check the destination chosen during upload.
3. Clear unintended search text and filters.
4. Check **Trash**.

Deleted files are hidden from ordinary Library views but can still be recoverable in Trash. Use [Restore or permanently delete from Trash](/knowledge-and-library/restore-or-permanently-delete-from-trash) if that is where you find the source.

If an upload is processing or failed, inspect its status instead of uploading another copy because search did not show it. [Upload and file messages](/help/upload-and-file-messages) explains those states.

Once you find the correct source, use [Organise your Library](/knowledge-and-library/organise-your-library) to move or rename it, or [Attach Library items to an agent](/knowledge-and-library/attach-library-items-to-an-agent) to choose which agents should use it.
