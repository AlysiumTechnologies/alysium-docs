<span id="fix-a-file-that-failed-to-process" />

Check which step stopped before retrying a file. Uploading, preparing its contents and attaching it to an agent are separate stages:

| Stage | What happens |
|---|---|
| Transfer | The file moves from your device to Alysium. |
| Processing | Alysium prepares readable knowledge from the saved file. |
| Attachment | The saved file is connected to the intended agent. |

## Find the failed item

For a file uploaded through an agent:

1. Open [Home](https://app.alysium.ai/spaces) and select **Build** on that agent's card.
2. Select **Settings** if another Build view is open, then scroll down to **Knowledge**.
3. Find the filename in **Attached knowledge** and check its status.

An upload still open can show **Failed**, a message and **Retry**. A saved file loaded when you return later can show **Failed** and **Remove**, without the upload's message or Retry action.

If the upload started in [Library](https://app.alysium.ai/library), check its **Upload files** dialog while the upload is still open. It can show the failed stage, a message and **Retry**. For a file already saved, find it in its Library project or folder.

**Ready** means processing finished. A processing spinner means the file is still being prepared; wait for its result.

## Correct the cause

When the upload gives a refusal, use that message to choose the correction:

| Refusal concerns | What to change |
|---|---|
| File format | Export a genuine supported file. Alysium accepts CSV, Word (.doc or .docx), Markdown (.md or .markdown), PDF, plain text (.text or .txt), and Excel (.xls or .xlsx). Renaming an extension does not convert the contents. |
| File size | Reduce or split the file so each file is at most **25 MiB**. |
| Storage | Reduce the selection to fit the space still available, or resolve the space's storage usage before selecting files again. You can [check what counts toward storage](/knowledge-and-library/storage-limits). |

A changed or re-exported file needs a new selection:

- **Upload it to an agent:** use **Browse files** under **Upload Documents** in that agent’s Knowledge, select the corrected file on your device and confirm.
- **Keep it in Library:** open [Library](https://app.alysium.ai/library), open the project or folder where you want to save it, then select **Add new** → **Upload files**. In the upload dialog, select **Browse files**, choose the corrected file and confirm. Check the destination shown in the dialog.

Uploading starts on selection. This creates a new upload; **Retry** does not replace an existing item’s contents with your edited file. A Library-only upload must be attached separately if an agent should use it.

## Retry the existing item when offered

If the original upload row offers **Retry**, select it and read the result. Retry attempts the step that stopped, which may be transfer, processing or attachment. Wait for the updated status.

For a saved failed file, including one whose agent row only offers Remove:

1. Open [Library](https://app.alysium.ai/library) and find the same file in its project or folder.
2. Open the file's three-dot menu and select **Try again** when offered.
3. Read the action's result. If it starts retrying, wait for the file's updated status.

**Try again** requests processing of the file already stored in Library. It does not upload revised contents from your device.

If the result says **Retry this file from its upload queue.**, return to the original upload attempt if it is still open and use its **Retry** action. If that attempt is no longer available, or Retry reports that the original file is unavailable and cannot continue, the saved item has not been recovered. Contact [support@alysium.ai](mailto:support@alysium.ai) with the filename, the affected agent if applicable, the visible status, the action you tried and its result. Do the same if the offered retry finishes with another failure.

## Recover the attachment

If a warning says the file was saved in Library but not attached, select **Retry attachment** beside that warning. Check that the file appears in the intended agent's **Attached knowledge**. This retries the connection without uploading or processing another copy.

To attach a saved file to an agent yourself:

1. Open **Build** on the intended agent's card in [Home](https://app.alysium.ai/spaces), select **Settings** if needed and scroll down to **Knowledge**.
2. Select **Add from Library** and expand the file's project and folder.
3. Select the file and choose **Attach**.
4. Check that file in **Attached knowledge**.

You can [attach a whole folder or project](/knowledge-and-library/use-library-files-in-an-agent) when the agent should also use other eligible files in that container.

## Check the recovered result

Preview messages use your space’s credits. For an agent, check that the intended file is **Ready** in **Attached knowledge**. Choose a specific fact in the file, then ask a question about it in the chat beside the Build settings. On a narrow screen, select **Chat Preview** within Build. Select **Send message** or press Enter, then compare the full reply with the file's actual contents.

If you are keeping the file only in Library, check its status in the list view. If Library shows file cards, select the list icon above the files (**View as list**), then check that the file is **Ready**.

If you remove an attachment from the agent, **Remove** revokes that selected connection. The agent may still have access through an attached folder or project. A failed upload's **Delete** action is separate cleanup; it does not retry the file.
