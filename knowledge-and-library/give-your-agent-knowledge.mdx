Add reference material that your agent should use when answering. Instructions tell it how to behave; knowledge supplies facts from sources you attach.

Use material you are allowed to share with the agent's audience. Start with a small, trustworthy source you can read yourself, such as a current FAQ. Describing a business during agent creation does not add its documents or establish its policies.

## Find Knowledge

1. Open [Home](https://app.alysium.ai/spaces).
2. Select the agent you want to edit.
3. Open **Build** → **Settings**.
4. Find **Knowledge**.

Home opens your current space; you choose the intended agent there. If its Knowledge card is already open, continue with [Choose a source](#choose-a-source).

## Choose a source

| What you have | Entry in Knowledge | Complete guide |
|---|---|---|
| A supported file on your device | **Upload Documents** | [Upload files to your agent](/knowledge-and-library/upload-files-to-your-agent) |
| A short passage of approved text | **Paste Text** | [Paste text as knowledge](/knowledge-and-library/paste-text-as-knowledge) |
| Files, folders or projects already in your space | **Add from Library** | [Use Library files in an agent](/knowledge-and-library/use-library-files-in-an-agent) |
| Readable pages from a public website | **Add your website** | [Add a website to your agent's knowledge](/knowledge-and-library/add-a-website-to-your-agents-knowledge) |

Choose one main source first so you can check exactly what information you have supplied. You need permission to edit the agent and use the material.

## Add one document

For a first file upload:

1. Under **Upload Documents**, select **Browse files**.
2. Select your reference document on your device.
3. Wait for its row in **Attached knowledge** to show **Ready**.

The upload saves the document and attaches it to this agent. The [full upload guide](/knowledge-and-library/upload-files-to-your-agent) explains file formats, limits and failures.

If you chose a different method, follow its complete guide in the table. Once the source is attached and ready, continue with [Check what the attachment includes](#check-what-the-attachment-includes).

## Check what the attachment includes

Sources attach to a particular agent. A file stored only in [Library](https://app.alysium.ai/library) is not automatically available to every agent.

An individual-file attachment includes that file. A folder or project attachment covers its eligible contents, including eligible material added there later. Choose a container only when that whole scope suits this agent's audience.

Uploads, pasted submissions and Library attachments have their own saving actions. You do not use Design's **Save Changes** to add knowledge.

## Choose how answers use it

After a source is attached, open **Behavior** in Knowledge. The grounding choices serve different purposes:

- **Strict** directs answers to stay within supplied knowledge.
- **Balanced** prefers that knowledge while identifying added general information.
- **Open** allows the knowledge alongside general information.

**Always consult knowledge before answering** controls whether factual questions start with a search of the attached material. Follow [Control how your agent uses its knowledge](/knowledge-and-library/control-how-your-agent-uses-its-knowledge) to make those choices and save them.

Then ask the preview a question your actual source answers. Compare the reply with the source. These settings guide behavior; they do not guarantee accurate answers.

## If the source is not usable yet

If a file fails, follow [Fix a file that failed to process](/knowledge-and-library/fix-a-file-that-failed-to-process). Use **Retry** only when the row offers it. If the document was saved but not attached, use **Retry attachment** instead of adding another copy.

For website pages, check that they are **Saved** and the source is **Active** using the website guide. If the agent still misses information from an attached, ready source, use [Why your agent can't find something](/knowledge-and-library/why-your-agent-cant-find-something).
