Give your agent the reference information it should use when answering questions. Instructions describe its job and how to behave; knowledge supplies the facts, such as your menu, course notes or returns policy.

Start with a small, current source you can check yourself. Choose information you are allowed to share with the agent's audience, and remove outdated or conflicting details before adding it.

## Find Knowledge

Open [Home](https://app.alysium.ai/spaces) and select **Build** on the card for the agent you want to edit. If the builder is showing Profile or Chat Preview, select **Settings**. Scroll down to **Knowledge**.

## Choose a source

| Your material | How to add it | When it is useful |
|---|---|---|
| A file on your device | **Upload Documents** | Use a PDF, Word document, spreadsheet, CSV, Markdown or plain-text file. [File uploads](/knowledge-and-library/upload-files-to-your-agent) support several formats, up to 25 MiB per file. |
| A passage you can copy | **Paste Text** | Turn a FAQ or set of notes into a document with **Add as Document**. [Pasting text](/knowledge-and-library/paste-text-as-knowledge) is useful when you do not need to prepare a file first. |
| Material already saved in your space | **Add from Library** | Reuse an existing file, folder or project. [Library attachments](/knowledge-and-library/use-library-files-in-an-agent) let you choose the scope this agent can use. |
| Pages on a public website | **Add your website** | [Add the website as a source](/knowledge-and-library/add-a-website-to-your-agents-knowledge), then choose which pages to save for the agent. |

An upload or pasted submission in the builder saves a document in Library and attaches it to this agent. A document saved only in Library still needs an attachment before the agent can use it.

## Add one document

For a file on your device, select **Browse files** under **Upload Documents**. Choose the file and confirm the selection in your device's picker. Selecting it starts the upload.

For copied text, enter the passage in **Paste Text** and select **Add as Document**. Typing in the box alone does not submit it.

Wait for the document in **Attached knowledge** to show **Ready**. It may first show **Queued**, **Uploading** or **Processing** while Alysium transfers and prepares it. Ready means preparation has finished.

To reuse a Library file instead, select **Add from Library**, expand its project and folder, select the file and choose **Attach**. Check that it appears in Attached knowledge and is Ready.

## Check what the attachment includes

An individual-file attachment gives this agent access to that file. A folder or project attachment covers eligible contents already inside it and eligible material added there later. Choose that broader scope only when those contents suit the agent's job and audience.

Folder and project rows show **Live**. Check the individual documents' readiness too: Live describes the continuing attachment, rather than the preparation of every file inside it.

## Choose how answers use it

Open **Behavior** within Knowledge after adding a source. Choose the approach that fits the agent's job:

- **Strict** directs the agent to answer from its knowledge and use its not-found reply for questions the sources do not answer.
- **Balanced** directs it to prefer your knowledge and say when it adds general information.
- **Open** lets it use your knowledge alongside general information.

**Always consult knowledge before answering** directs the agent to search its sources first for factual questions. Changes save automatically; wait for saving to finish before testing. You can also [set a reply for missing information](/knowledge-and-library/control-how-your-agent-uses-its-knowledge) as you refine the agent.

Try a question the source actually answers in the chat beside the Build settings. On a smaller screen, select **Chat Preview** within Build. Type the question and select **Send message** or press Enter, then compare the reply with the source. Ready and the behavior choices help you prepare the agent; check the answers themselves before relying on them.

## If the source is not usable yet

- **An upload fails during this attempt:** read the displayed error and use **Retry** if the row offers it. Select the original file again if asked.
- **A saved file shows Failed after you return:** its row can show only the status and **Remove**, without an error detail or Retry. If Retry is unavailable, [get help with the failed document](/help/get-help-from-a-person) using its filename and visible status.
- **The document was saved in Library but not attached:** select **Retry attachment** in the warning. This connects the saved document; submitting another copy repeats the saving step.
- **You added a website:** check that the pages are **Saved** and the source is **Active**. These are separate checks in the [website source setup](/knowledge-and-library/add-a-website-to-your-agents-knowledge).

If an attached, Ready source still does not supply an expected answer, [check the source and the agent's instructions](/knowledge-and-library/why-your-agent-cant-find-something).
