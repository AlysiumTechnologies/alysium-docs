Turn a short FAQ, approved explanation or set of notes into a document your agent can search.

Pasted knowledge supplies reference facts. It is separate from sending a chat message or writing Agent Instructions. Use text you are allowed to share with this agent's audience and an agent you can edit.

## Find Paste Text

1. Open [Home](https://app.alysium.ai/spaces).
2. Select the intended agent.
3. Open **Build** → **Settings**.
4. Find **Knowledge** → **Paste Text**, beside the upload area.

If the box is already open for the right agent, continue with [Prepare the passage](#prepare-the-passage). Home opens your current space so you can select your own agent.

This builder box saves and attaches the text to the agent you are editing. The [Library alternative](#save-in-library-with-a-chosen-name) saves a document in Library first.

## Prepare the passage

Write direct facts the agent should be able to look up. For a fictional shop:

> Ridge and River Outdoor Shop is fictional. Customers asking about a return should bring the unused product and purchase receipt to staff. This note does not state delivery times or live stock.

Replace this with your actual approved information. A meaningful opening line makes the saved source easier to recognize. Avoid an unexplained list of links, and keep passwords and confidential customer records out of practice material.

The builder accepts up to **1,000,000 characters**. It creates the document without asking for a separate title in this box.

## Submit it to this agent

1. Enter the text in **Paste Text**.
2. Check the character count and any validation message.
3. Select **Add as Document**.
4. Wait for the resulting source in **Attached knowledge** to show **Ready**.

Typing alone does not submit the text. The box clears after a successful save; an error leaves the text available to correct.

A second deliberate submission creates another document. It does not update the first one in place.

## Check an answer from the passage

Use the chat beside the Build settings, or select **Chat Preview** within Build on a narrow screen.

Ask a question the passage answers. For the fictional shop note, ask what to bring for a return. Enter it in the message box, then select **Send message** or press Enter. Compare the reply with the note: it says the unused product and purchase receipt.

After Ready, follow [Control how your agent uses its knowledge](/knowledge-and-library/control-how-your-agent-uses-its-knowledge) to choose how the agent should handle questions the passage does not answer.

## Save in Library with a chosen name

Use this route when organization or a chosen title matters more than the shortest direct-agent path. You need permission to add content in the chosen Library location.

1. Open [Library](https://app.alysium.ai/library).
2. Select **Add new**.
3. Select **Paste text**.
4. Enter **Name (optional)** if you want a chosen title.
5. Paste the passage.
6. Select **Save to library**.

This saves a Library document. To let a particular agent use it, follow [Use Library files in an agent](/knowledge-and-library/use-library-files-in-an-agent) to attach it through **Add from Library**. Then return to [Check an answer from the passage](#check-an-answer-from-the-passage).

## If the paste fails

- **The text is too long:** shorten it or divide it into useful separate documents.
- **Storage is full:** resolve the space's storage issue before retrying. [Storage limits](/knowledge-and-library/storage-limits) explains what uses storage.
- **The text remains with an error:** correct the problem and retry the existing submission instead of adding identical copies.
- **The document is saved but not attached:** select **Retry attachment** instead of pasting another copy. Check that it appears in the intended agent's **Attached knowledge**.

[File and storage limits](/help/file-and-storage-limits) explains the separate limits for other kinds of uploads.
