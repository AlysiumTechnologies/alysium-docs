<span id="paste-text-as-knowledge" />

Turn a FAQ, approved explanation or set of notes into a document your agent can search. Pasted knowledge supplies reference facts; Agent Instructions describe how the agent should use them.

Use the builder's **Paste Text** box to save a document and attach it to the agent in one submission. The Library route lets you give the document a chosen name and attach it afterward.

## Find Paste Text

Open [Home](https://app.alysium.ai/spaces) and select **Build** on the intended agent's card. If the builder is showing Profile or Chat Preview, select **Settings**. Scroll down to **Knowledge** and find **Paste Text**. It sits beside Upload Documents on a wide screen and below it on a smaller screen.

## Prepare the passage

Use clear, current facts you are allowed to share with the agent's audience. Give the passage a meaningful opening line so you can recognize its subject later. Include the actual information the agent needs to answer, rather than a list of unexplained links.

For practice, you can use this fictional shop note:

> Ridge and River Outdoor Shop — fictional practice FAQ
>
> Customers requesting a return should bring the unused product and purchase receipt to staff at the shop. Staff review damaged items separately.
>
> This note does not supply delivery times or live stock information.

Replace the example with approved information before using it with real customers.

The builder accepts up to **1,000,000 characters**. The box shows character and word counts and creates a document without a separate title field.

## Submit it to this agent

1. Enter your passage in **Paste Text**.
2. Check the text, counts and any validation message.
3. Select **Add as Document**.
4. Wait for the document in **Attached knowledge** to show **Ready**.

Typing alone does not submit the text. A successful save clears the box, saves a document in Library and attaches it to this agent. Ready means the contents have finished preparation for knowledge search.

An error leaves the text in the box so you can correct it. If the document was saved but its attachment failed, the box clears because saving succeeded; use the warning's **Retry attachment** action. Submitting the passage again creates another document rather than updating or attaching the saved one.

## Check an answer from the passage

Use the chat beside the Build settings. On a smaller screen, select **Chat Preview** within Build.

For the practice passage, enter **What should a customer bring for a return?** Select **Send message** or press Enter, then compare the reply with the note. It should name the unused product and purchase receipt. Ask about delivery times too, and check how the agent handles information the passage does not supply.

For your own passage, try a specific question it answers and one it leaves unanswered. Knowledge's **Behavior** section lets you [choose how the agent uses its sources and responds when information is missing](/knowledge-and-library/control-how-your-agent-uses-its-knowledge). Check the reply itself even when the source is Ready.

## Save in Library with a chosen name

Use Library when you want to choose a document name or save the passage in a particular location first.

1. Open [Library](https://app.alysium.ai/library) and navigate to the destination where you want the document.
2. Select **Add new**, then **Paste text**.
3. Enter a title in **Name (optional)** if you want to choose one.
4. Paste the passage and check the destination shown in the dialog.
5. Select **Save to library**.

This saves a `.txt` document in the displayed destination. To attach it, return to Home, select Build on the intended agent, select Settings if needed and scroll to Knowledge. Select **Add from Library**, expand the document's project and folder, select the document and choose **Attach**. Check that it appears in **Attached knowledge** and is Ready, then test a question in the preview.

You can also [attach a whole Library folder or project](/knowledge-and-library/use-library-files-in-an-agent) when its eligible contents belong with this agent, including material added there later.

## If the paste fails

- **The passage is too long:** shorten it or split it into useful separate documents, then submit the corrected text.
- **The form keeps your text and shows an error:** read the message, correct the cause and retry the existing submission.
- **Storage is full:** resolve the space's storage use before retrying. In the Library dialog, the storage-full message can replace the form. The [storage limits guide](/knowledge-and-library/storage-limits) explains the space's allowance and Library usage.
- **The document was saved but not attached:** use **Retry attachment** in the builder warning, then check Attached knowledge. Pasting another copy repeats the successful saving step.
- **A saved document shows Failed:** a saved row can show the status and **Remove** without an error detail or Retry. If Retry is unavailable, [get help with the saved document](/help/get-help-from-a-person) using its name and visible status. Repeatedly submitting the passage creates extra documents.
