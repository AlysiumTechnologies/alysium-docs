Team access to Library is not currently available. A space contains only you, its owner; inviting teammates and assigning member roles are unavailable. A Library sharing control does not create another space member.

You can reuse saved material across your own agents, or share an agent so people can ask it questions.

## Reuse material across your own agents

Keep one saved source in Library and attach it to the agents that need it. This avoids uploading another copy for each agent.

Choose the scope before attaching. A file supplies that source. An attached folder or project covers eligible contents now and material added there later. For example, an **Approved FAQ** folder can keep customer-facing sources separate from draft material.

To reuse a saved reference file:

1. Open [Library](https://app.alysium.ai/library), find the file and open its three-dot menu. Select **Attach to agent**.
2. Select the checkboxes for the intended agents from the list. Use **Show more** to load more agents when needed.
3. Select **Attach** for one agent, or the button showing the selected count, such as **Attach to 2 agents**, for several. Wait and read the result. If only some attachments succeed, check the named agents before retrying a missing attachment.
4. Open [Home](https://app.alysium.ai/spaces) and select **Build** on each intended agent's card. Select **Settings** if needed, scroll to **Knowledge** and check the file in **Attached knowledge**. It should reach **Ready** before you use it for a source question.

You can also [attach a folder or project from Library](/knowledge-and-library/attach-library-items-to-an-agent) when its broader scope fits the job. While working in one agent, **Add from Library** in Knowledge lets you expand the source location, select the material and choose **Attach**.

Reusing a source lets your agents consult it. It does not give another person access to manage Library.

## Sharing an agent is a different task

An agent's visitor link lets people chat with the agent. It does not invite them into your space or give them Library management access. Choose knowledge suitable for those visitors before [sharing the agent with a link or QR code](/share-and-deploy/share-your-agent-with-a-link-and-qr-code).

If you need people to work together on Library files, email [Alysium support](mailto:support@alysium.ai) and describe the collaboration you need.
