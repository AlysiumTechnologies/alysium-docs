Storage is the space used by saved files. Chat credits measure a separate kind of usage. Turning on chat overages does not buy extra file storage, and shortening an answer does not erase documents.

## Space allowances

| Plan | Storage allowance |
|---|---|
| Free | 2 GB |
| Pro | 100 GB |

These allowances belong to the space, rather than to each agent. Open [Library](https://app.alysium.ai/library) to review your current space's material and actual storage display.

Reusing one saved source in several agents does not require another stored copy. Uploading intentional duplicates creates separate stored material.

## What still uses storage

| Material or action | Effect on storage |
|---|---|
| Files in **Trash** | Still count until permanently erased. |
| Retained visitor uploads | Can consume the owning space's storage. |
| Detaching a source from an agent | Leaves the document saved, so does not free its storage. |
| Website-derived material | Can have different recorded sizes. Use the actual usage display rather than counting source rows. |

An empty agent attachment list does not mean the space's documents were deleted. Attachment controls determine what an agent uses; Library and Trash controls manage the saved material.

## If an upload is refused for storage

Review which files are no longer needed and how agents use them. For example, a fictional space might have outdated manuals alongside the approved current manual. Remove and erase only the saved material you intend to discard, rather than deleting the current manual because it is large.

Use [Restore or permanently delete from Trash](/knowledge-and-library/restore-or-permanently-delete-from-trash) to understand recovery, **Remove from agents** and permanent erasure before choosing an action.

Holds and pending deletion can keep files retained. After erasure completes, check the storage display before retrying the upload. A confirmation request alone does not prove that space was released.

Each uploaded file must also meet its format and individual-size limits, even when the space has room. See [File and storage limits](/help/file-and-storage-limits) for those separate rules.

If you need to keep the material, [Billing](https://app.alysium.ai/spaces?settings=billing) opens your active space's plan and payment settings. Review the current allowance and displayed plan offer before deciding whether a plan change suits the need.
