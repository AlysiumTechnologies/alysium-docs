Add documents your agent can search when answering questions. A current FAQ, handbook or set of class notes gives it specific information to use alongside the instructions that describe its job.

Choose material you are allowed to share with the agent's audience. Start with a clear document you can read yourself so you can compare its facts with the agent's replies.

## Choose a supported document

| Format | Accepted file extensions |
|---|---|
| PDF | `.pdf` |
| Word | `.doc`, `.docx` |
| Excel | `.xls`, `.xlsx` |
| CSV | `.csv` |
| Plain text | `.text`, `.txt` |
| Markdown | `.md`, `.markdown` |

Each file can be up to **25 MiB**, and your space needs enough available storage for the selection. Review the document for outdated facts, unexplained abbreviations and conflicting versions before uploading it.

## Make a practice file if you need one

You can use your own document or copy this fictional example into a plain-text editor:

> Ridge and River Outdoor Shop — fictional practice FAQ
>
> Returns: Bring the unused product and purchase receipt to the shop. Staff review damaged items separately.
>
> Boot fitting: Try both boots with the socks you expect to hike in. Ask staff for help if the fit is uncertain.
>
> Delivery times are not supplied in this FAQ.

Save it as **Customer questions.txt** somewhere you can find again. Choose plain text if the editor asks for a format. Replace the fictional material with your approved information before using the agent with real customers.

## Find Upload Documents

Open [Home](https://app.alysium.ai/spaces) and select **Build** on the intended agent's card. Select **Settings** if the builder is showing Profile or Chat Preview, then scroll down to **Knowledge**. Find **Upload Documents**.

## Select the file

1. Select **Browse files**.
2. Choose one or more supported documents in your device's file picker.
3. Confirm the selection in the picker. Uploading starts immediately.

You can also drag files from your device onto **Drop files here**.

## Wait for Ready

Find each file in **Attached knowledge** and check its state:

| State | What is happening |
|---|---|
| **Queued** | The file is waiting to start. |
| **Uploading** | Its contents are transferring. |
| **Processing** | Alysium is preparing the contents for knowledge search. |
| **Ready** | Preparation is complete. |
| **Failed** | This attempt did not finish; the recovery depends on the actions shown. |

A successful builder upload saves the document in Library and attaches it to this agent as part of the submission. Wait for Ready before testing its contents. You can later [reuse the Library file in another agent](/knowledge-and-library/use-library-files-in-an-agent).

## Try a source question

Use the chat beside the Build settings, or select **Chat Preview** within Build on a smaller screen.

For the practice file, enter **What should a customer bring when requesting a return?** Select **Send message** or press Enter. Compare the reply with the FAQ: it says the unused product and purchase receipt. Then ask **What are the delivery times?** The source does not supply those times, so check how the agent handles that gap.

For your own document, test a fact it contains and a question it leaves unanswered. You can [choose how the agent uses its knowledge and responds to missing information](/knowledge-and-library/control-how-your-agent-uses-its-knowledge) in Knowledge's **Behavior** section.

A completion message may offer **Ask in the preview**. Selecting it sends the suggested question to the preview.

## If the file type is rejected

Read the alert naming the rejected files and accepted types. An unsupported extension rejects the whole selection, so check all the selected files before trying again. Export unsupported material to one of the formats above; changing the filename's extension does not convert the document.

For a short passage, you can [paste the text into Knowledge](/knowledge-and-library/paste-text-as-knowledge) instead.

## If size or storage blocks the upload

For a file above 25 MiB, reduce its size or split the material into smaller supported documents. For an alert that the selection exceeds available storage, resolve the space's storage use before resubmitting. You can check the space's allowance and Library usage in the [storage limits guide](/knowledge-and-library/storage-limits).

## If uploading or processing fails

During the current upload attempt, a **Failed** row can show an error message and **Retry**. Read that message, correct the cause and select Retry. If Alysium asks for the original file, select it again, then wait for Ready.

If you return later to a saved document marked Failed, its row shows the status and **Remove**, without an error detail or Retry. [Get help with the failed document](/help/get-help-from-a-person) using the filename, file type and visible status. Include an error message if one was displayed during the attempt. The [failed-file guide](/knowledge-and-library/fix-a-file-that-failed-to-process) explains the different stages in more detail.

## If the file is saved but not attached

Select **Retry attachment** in the warning. The document is already saved in Library; this action retries its connection to the agent. Check **Attached knowledge** for the file and its Ready state before testing it. Uploading another copy repeats the saving step instead of retrying that connection.
