<span id="use-library-files-in-an-agent" />

Give an agent access to saved Library material without uploading it again. You can choose an individual file or connect a folder or project so eligible material added there later is included too.

## Open Add from Library

1. Open [Home](https://app.alysium.ai/spaces) and select **Build** on the intended agent's card.
2. In Build, select **Settings** if you are viewing another panel, then scroll to **Knowledge**.
3. Review **Attached knowledge** for the sources the agent already uses, including attached folders and projects. Then select **Add from Library**.

The dialog shows projects, folders and files. If the material is still only on your device, [upload it to the agent](/knowledge-and-library/upload-files-to-your-agent) first.

## Choose the source scope

| Select | What the agent can use |
|---|---|
| A file's checkbox | That individual source. |
| A folder's or project's checkbox | Its eligible contents now and eligible material added there later. |

Choose a scope you want the agent to keep using. For example, a **Customer help** project might contain **Approved FAQ** and **Draft promotions** folders. Select the **Approved FAQ** folder or an exact file inside it if the agent should use only approved material. Selecting the whole project would also include eligible drafts and later additions.

Click a project or folder's **name or chevron** to open it. Use its **checkbox** to select the whole container. Opening it alone does not select it.

To find a source:

- **Browse:** open its project and folder, then select the intended checkbox. With the search box cleared, use **Show more projects**, **Show more folders** or **Show more files** when offered to load more items.
- **Search:** enter part of the name in **Search the library**. Use a more specific name if the results do not reveal the item you want. If it is still missing, clear the search and browse its project and folder, then select its checkbox.

Search matches names rather than words inside documents. A matching folder name does not display every file beneath it; clear the query to browse its contents.

**Attached** marks an individual file already attached directly to this agent. **included** marks an item covered by a parent folder or project you have selected in this dialog. Selecting a parent includes its eligible contents, so you do not need to select each child too.

Check **Attached knowledge** when deciding whether another attachment is needed: material covered by an already attached folder or project may still be selectable in the picker.

## Attach the selection

1. Read the selection summary and check that it includes only the intended files, folders or projects.
2. Select **Attach** and wait for the request to finish. Read the result, including any items it could not attach.
3. Check the selected source in **Attached knowledge**.

A folder or project can be a useful selection even when the summary says **No new files right now**: the attachment still covers eligible material added there later. Its **Live** marker in Attached knowledge identifies this ongoing coverage.

Reusing Library material saves the attachment without another upload or a separate Design save. An individual file must show **Ready** before you test an answer from it; connecting a folder does not finish processing its files.

To check a source, enter a self-contained question it answers in the chat beside Build, or open **Chat Preview** on a smaller screen. Select **Send message** or press Enter, then compare the answer with the source. Preview requests use your space's credits. You can [plan a broader set of preview checks](/build-your-agent/test-your-agent-while-you-build) as you refine the agent.

## If an item is missing or attachment fails

If a project or folder shows a loading error with **Retry**, use that control. If the dialog is empty or does not show material you know is saved, select **Cancel**, then reopen **Add from Library**. Clear any search and browse again. Check the current space and the source's location in [Library](https://app.alysium.ai/library) before concluding the file is absent.

A file in Trash needs to be [restored](/knowledge-and-library/restore-or-permanently-delete-from-trash) before you can choose it here. Visitor uploads also need deliberate promotion before they become agent knowledge; [files visitors send you](/widget-visitors/files-visitors-send-you) explains that distinction.

If attachment reports a failure, partial result or timeout, read the message and check **Attached knowledge** before repeating the action. Keep successful attachments and retry only what is still missing. A selectable file may already be covered by an attached folder or project.

If you attached the wrong scope, use **Remove** on that attachment in **Attached knowledge**, read any confirmation and wait for the result. Check the remaining attachments afterward; another folder or project may still cover the same file. [Removing an attachment](/knowledge-and-library/remove-a-file-from-your-agent) leaves the Library material saved.

When you want to start from saved material and choose several agents, you can instead [attach Library items from Library](/knowledge-and-library/attach-library-items-to-an-agent).
