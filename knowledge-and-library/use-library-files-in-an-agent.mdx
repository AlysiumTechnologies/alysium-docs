Connect saved files, folders or projects to an agent without uploading them again. Use **Add from Library** when you already know which agent needs the material.

You need editing access to the intended agent and access to the selected Library material.

**Already in the Add from Library picker?** Continue with [Choose the source scope](#choose-the-source-scope).

## Open Add from Library

1. Open [Home](https://app.alysium.ai/spaces).
2. Select the intended agent.
3. Open **Build**.
4. Open **Settings**.
5. Find **Knowledge**.
6. Select **Add from Library**.
7. Continue with [Choose the source scope](#choose-the-source-scope).

Home opens your active space, where you choose the agent. If it asks you to sign in, sign in. Open Home again if needed.

The picker shows projects, folders and documents. Seeing a source there does not mean it is already attached. If the material is still only on your device, follow [Upload files to your agent](/knowledge-and-library/upload-files-to-your-agent), or upload it through [Library](https://app.alysium.ai/library) first.

## Choose the source scope

| Selection | What the agent can use |
|---|---|
| File | That individual source. |
| Folder or project | Its eligible contents now, including eligible material added there later. |

For a first attachment, choose one well-understood file unless you deliberately want the ongoing scope of a folder or project.

For example, a fictional **Customer help** project might contain **Approved FAQ** and **Draft promotions** folders. If the agent should only use approved FAQ material, choose that folder or an exact file inside it. Attaching the whole project could include drafts and future material you did not intend the agent to use. These are example names, rather than default folders.

## Attach the selection

1. Expand the project containing the source.
2. Expand a folder if needed.
3. Use **Search the library** if the name is hard to find.
4. Select the intended file, folder or project.
5. Read the selection summary.
6. Select **Attach**.
7. Check the result in **Attached knowledge**.

An item already attached, or covered by another selected container, can be unavailable as an extra selection.

A successful attachment is saved without a second upload or a Design **Save Changes** action. Confirm that the actual file is **Ready** before asking about it. Attaching a processing file does not finish its preparation. Folder and project rows identify the wider coverage.

## If an item is missing or attachment fails

Check the current space and project, then clear an unintended search. Check **Trash** if the source was deleted. A source already covered by an attached folder or project may not need another attachment.

Visitor-upload material needs deliberate promotion before it is eligible as agent knowledge. [Files visitors send you](/widget-visitors/files-visitors-send-you) explains the distinction between a visitor attachment and a creator's knowledge source.

If permission is refused, read the error. Selecting an item in the picker does not grant new access to it. After a failed action, check the actual **Attached knowledge** list before retrying.

If you attached the wrong scope, use [Remove a file from your agent](/knowledge-and-library/remove-a-file-from-your-agent). Detaching it leaves the Library source saved. To start from a source and choose several agents instead, use [Attach Library items to an agent](/knowledge-and-library/attach-library-items-to-an-agent).
