<span id="why-your-agent-can’t-find-something" />

An agent can miss information because the source is attached to another agent, still processing, paused or missing the answer in its readable contents. Check the connection and the saved facts, make one correction, then ask the same question again.

<span id="open-the-intended-agent’s-knowledge" />
<span id="open-the-intended-agents-knowledge" />

## Open Knowledge on the intended agent

Open [Home](https://app.alysium.ai/spaces) and select **Build** on the card for the agent whose answer you are checking. Select **Settings** if needed, then scroll down to **Knowledge**.

## Check attachment and readiness

Read **Attached knowledge** on this agent. A file stored in [Library](https://app.alysium.ai/library) is not automatically available to every agent.

If the intended file is missing:

1. Select **Add from Library**.
2. Expand the relevant project or folder and select the file. Select a folder or project only if you want to include its eligible contents, including material added there later.
3. Select **Attach**, then check for its entry in **Attached knowledge**.

Check the source's state before testing:

| What you see | What to do |
|---|---|
| **Queued**, **Uploading** or **Processing** | Wait for **Ready**. Being listed does not mean preparation has finished. |
| **Failed** | Use **Retry** on the current failed attempt when offered. For a saved file, open Library, find the same file and choose **Try again** from its three-dot menu when offered. Read the result and wait for **Ready**. If told to retry from its upload queue, use that queue’s **Retry** only if the original attempt is still available. The [file-processing guide](/knowledge-and-library/fix-a-file-that-failed-to-process) explains other failure messages and recovery limits. |
| A warning that the file was saved in Library but not attached | Select **Retry attachment**, then check the attachment. This retries the connection to the saved file. |

For an attached folder or project, check that the file is still inside that location and has finished processing. An empty folder supplies no searchable text. Moving a file changes which folder or project attachments cover it; an individual attachment to that file remains in place.

## Check website knowledge separately

For a website added directly to the agent, scroll to **Website** in the settings and find its source card.

1. Select **Review pages** and expand the relevant page to read the collected text.
2. Check for **Saved**. If the page is only **Scanned**, select its **Save** action, or use **Save to Memory** to process pending and failed pages, and wait for saving to finish.
3. Check that the source is **Active**. If it is **Paused**, switch it to **Active** to let the agent use it.

If the public website has changed, select **Refresh** on the source. This uses its saved address to collect changes. Check the resulting page status and saved text before testing; the agent does not browse the current website for every question.

For website material collected through Library, check that the saved pages or their Library folder are attached to this agent. Collection processes the pages into that folder without the direct-agent source's initial **Save to Memory** step. You can [review both ways of adding website knowledge](/knowledge-and-library/add-a-website-to-your-agents-knowledge) for more detail.

## Read the actual source

For a Library file, open [Library](https://app.alysium.ai/library) and select its thumbnail, or open its three-dot menu and choose **Preview**. For an agent Website source, read the expanded page in **Review pages**.

Look for the passage that answers your question. Check the actual contents and version, not just the filename. If the text is missing or unreadable, compare it with the approved original; the appearance of a page or screenshot does not establish that its words are available to search.

For example, a returns FAQ cannot answer a delivery-times question if it contains no delivery information. Add the approved delivery facts:

1. Return to the agent's **Settings** and scroll to **Knowledge**.
2. In **Paste Text**, paste the approved passage and select **Add as Document**.
3. Wait for the new document to show **Ready** in **Attached knowledge**.

The submission saves the passage in Library and attaches it to this agent. For a new file instead, select **Browse files** under **Upload Documents**, choose it on your device and confirm the selection. Uploading starts immediately; wait for **Ready**. You can [check supported file types and upload limits](/knowledge-and-library/upload-files-to-your-agent) when choosing a document.

## Check answer behavior and instructions

Once the agent has knowledge attached or a website source, open **Behavior** in **Knowledge**. **Answer grounding** controls how answers use the sources: **Strict** asks the agent to stay within its knowledge, **Balanced** prefers that knowledge while allowing identified general knowledge, and **Open** uses both as inputs.

For a factual FAQ, select **Strict** and turn on **Always consult knowledge before answering** to have the agent search first. In **When the answer isn’t in my knowledge…**, write how it should handle gaps, such as acknowledging that the FAQ has no answer and giving your real contact route. These settings guide answers; they do not guarantee correctness.

Scroll to **Agent Builder** within Settings and read **Agent Instructions**. Correct any conflicting rule, such as an instruction to invent an answer when the source is silent. Behavior changes and instructions save automatically; wait for saving to finish before testing. The [knowledge behavior guide](/knowledge-and-library/control-how-your-agent-uses-its-knowledge) explains these choices in more depth.

## Ask a direct question again

Use the chat beside the Build settings on a wide screen, or select **Chat Preview** within Build on a smaller screen. Preview conversations use your space's credits.

Enter the same direct question, including the subject and any details needed to understand it without earlier messages. Use terms from the relevant passage, then select **Send message** or press Enter. Compare the answer with that passage, including its conditions and exceptions.

If the source is attached, **Ready** or **Saved** and **Active** as appropriate, contains the answer and is still missed, email [support@alysium.ai](mailto:support@alysium.ai). Include the agent name, source title or website page address, exact question, visible source state and the answer you received.

## Avoid changes that obscure the cause

Correct one attachment, source or behavior issue at a time so you can tell what helped. Deliberately uploading the same file again creates another document; it does not replace the first one. Use [the attachment removal steps](/knowledge-and-library/remove-a-file-from-your-agent) when an old source should no longer be used.

A different model cannot supply a private business fact that you have not added. Put the approved fact in a usable source, finish saving or processing, then test it again.
