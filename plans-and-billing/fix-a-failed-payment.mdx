Resolve the payment issue on the affected subscription, then check its resulting status and access in Alysium. Changing a card alone does not prove an unpaid invoice was paid.

First read whether the warning names **Alysium Pro** or a **creator's agent**. These have separate bills and payment-management paths. Updating one does not necessarily update the other.

- For the space's Pro plan, continue with [Resolve a Pro payment problem](#resolve-a-pro-payment-problem).
- For a purchased agent, continue with [Find the affected agent](#find-the-affected-agent).
- If you already used **Fix billing** on that agent's warning and its portal opened, continue with [Check the creator-agent payment in its portal](#check-the-creator-agent-payment-in-its-portal).

## Resolve a Pro payment problem

You manage the Pro payment for the space you own. The Billing link opens the current space, so confirm its name before using the portal.

1. Open [Billing](https://app.alysium.ai/spaces?settings=billing).
2. Check the affected space's name and plan status.
3. Select **Manage Subscription & Billing**. If details are unavailable, use **Open Billing Portal** when offered.
4. Confirm the intended Pro subscription in the portal.
5. Open the unpaid invoice or payment issue shown there.
6. Update the payment method if needed.
7. Follow any payment action the portal offers.
8. Check the portal's payment result.
9. Return to Alysium.
10. Reopen [Billing](https://app.alysium.ai/spaces?settings=billing).
11. Check the resulting plan status.

Portal options vary by subscription. Use the options actually shown; merely opening the portal or saving a replacement card does not establish payment success.

## Find the affected agent

Use the account that purchased the agent. If you are already in Billing, start at step 2.

1. Open [Billing](https://app.alysium.ai/spaces?settings=billing).
2. Find **Agent Access and Subscriptions**.
3. Locate the agent and creator named in the warning.
4. Select **Fix billing**, when offered.
5. Continue with [Check the creator-agent payment in its portal](#check-the-creator-agent-payment-in-its-portal).

## Check the creator-agent payment in its portal

1. Confirm that the portal shows the affected creator's subscription.
2. Read its payment issue or unpaid invoice.
3. Update the payment details if needed.
4. Follow any payment action the portal offers.
5. Check the payment result.
6. Return to Alysium.
7. Reopen [Billing](https://app.alysium.ai/spaces?settings=billing).
8. Check the named agent's card.
9. Reopen the affected chat to check its access notice.

A payment warning can leave agent access temporarily available while payment is retried. A blocked warning means messaging is paused. Pro has separate payment checks; do not assume it has the same grace behavior. Remaining credits do not override a payment block.

For example, if one purchased agent reports a failed payment while Pro is active, work on that agent's subscription. If space-funded chats stop and Pro shows a payment issue, resolve the Pro bill. Use the displayed state to identify the affected subscription.

## If the warning remains

If a portal will not open, read its error and retry from the existing Billing record. If a payment option is missing, payment is processing, or a warning remains after confirmed payment, contact billing@alysium.ai. Include the space or agent name, displayed status and payment confirmation reference. Do not send full card details.

Keep using the existing subscription record while the issue is checked. Another checkout can create a separate purchase. For other causes of locked messaging, see [Why a marketplace chat is read-only](/agenthub/why-a-marketplace-chat-is-read-only). For invoices and payment-method changes without a warning, see [Update your payment method or see invoices](/plans-and-billing/update-your-payment-method-or-see-invoices).
