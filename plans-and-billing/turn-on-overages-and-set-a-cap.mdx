Choose whether an active Pro space can use paid AI usage after its included credits are spent, and how much additional usage it may incur in the billing period. You manage this setting for the space you own.

## Choose what additional spending is allowed

**On-Demand Usage** is paid usage after the included credits run out. It is billed after use. The **Billing Period Limit** controls that additional usage; the recurring Pro subscription fee is separate.

| Mode | Effect |
|---|---|
| **Fixed** | Sets a USD limit for additional usage in the billing period. |
| **Unlimited** | Removes the fixed dollar cap on additional usage. |
| **Disabled** | Stops usage when the included credits are spent. |

Choose **Disabled** if you want no on-demand usage. A lower setting does not erase charges already incurred. **Unlimited** permits additional usage charges without this fixed cap; it does not add free credits.

For example, entering **10** in Fixed means a **$10 additional-usage limit** for that billing period. This is an illustrative budget, not a recommended amount or the total subscription price. Read the usage meter to see additional usage already accumulated.

## Set and save the limit

The [Billing link](https://app.alysium.ai/spaces?settings=billing) opens the current space's settings. Check its name before changing spending. Already at **On-Demand Usage** in the intended space? Start at step 3.

1. Open [Billing](https://app.alysium.ai/spaces?settings=billing).
2. Find **On-Demand Usage** beneath the plan controls.
3. Open the menu beside **Billing Period Limit**.
4. Select **Fixed**, **Unlimited** or **Disabled**, according to your decision.
5. If you selected **Fixed**, enter the intended limit in the USD amount field.
6. Select **Save**.
7. Wait for the success message.
8. Reopen [Billing](https://app.alysium.ai/spaces?settings=billing).
9. Check that **On-Demand Usage** shows the saved mode and, for Fixed, the intended amount.

Selecting a mode or editing the field alone does not save it. The saved setting determines whether usage can continue after included credits are spent. [Check your usage](/plans-and-billing/check-your-usage) explains how to read the remaining allowance and recorded activity.

## If the controls or Save are unavailable

These controls require an active Pro subscription and its space owner. Check the plan's status in Billing. Use [Upgrade to Pro](/plans-and-billing/upgrade-to-pro) only if you intend to purchase that plan. A payment issue needs [Fix a failed payment](/plans-and-billing/fix-a-failed-payment).

For **Fixed**, enter a valid nonnegative dollar amount and correct any field validation message.

If a save error appears, do not rely on the unsaved selection. Reload Billing and check the persisted value before trying again. Contact billing@alysium.ai with the space, intended mode/amount and error if the setting cannot be confirmed.

If usage has stopped, [What happens when you run out of credits](/plans-and-billing/what-happens-when-you-run-out-of-credits) helps distinguish a spent allowance, a fixed cap and an agent-specific limit.
