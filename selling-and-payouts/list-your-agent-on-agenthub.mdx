Prepare public listing details and submit an agent for AgentHub discovery. Use a source agent whose selling setup you can manage, with [creator application approval](/selling-and-payouts/apply-to-sell-on-agenthub) where required.

An AgentHub review is separate from [making the source agent live](/share-and-deploy/make-your-agent-live).

## Gather the listing material

Prepare a public title, one-sentence tagline, short description and an image you may publish. The agent needs a clear purpose, saved instructions and suitable reference facts. Your visible creator profile needs a name and username.

Paid offers also need [saved pricing](/selling-and-payouts/price-your-agent) and [ready Stripe payments](/selling-and-payouts/set-up-stripe-to-get-paid).

**Already in Listing details?** Continue with [Fill the public copy](#fill-the-public-copy). If the details are already saved, continue with [Check readiness and submit](#check-readiness-and-submit).

## Open the listing editor

1. Open [Home](https://app.alysium.ai/spaces).
2. Select the intended source agent.
3. Open **Deploy**.
4. Select **Share & Sell**.
5. Select **Edit listing** on the **AgentHub** card.
6. Check that **Listing details** is open.

Home opens your active space, where you choose the source agent. If it asks you to sign in, sign in and open Home again if needed.

## Fill the public copy

| Field | What to write |
|---|---|
| **Listing header** | The public title. |
| **Tagline** | The short sentence beneath the title. |
| **Short description** | What the agent does and who it serves. |

Complete all three for AgentHub. Use the displayed length counters and describe help the agent can actually provide.

For a fictional café FAQ assistant, a header could be **Café visitor guide**, with the tagline **Clear answers from the café FAQ**. A short description could explain that it answers from the attached menu and accessibility notes, and directs booking changes to staff. Adapt the example to facts and behavior you have actually supplied.

## Complete discovery and media

Describe an actual task in a capability row. Use **Add capability** for another row. Remove an unwanted row with its removal control. Choose relevant available tags in the tag selector; use a selected tag's X to remove it. Expand **Category** to choose the **Listing category**.

Expand **Full description** and fill **Detailed sales copy** if you need a longer About this agent explanation. **Internal notes → Notes** is for your reference rather than buyer copy.

At least one image is required; the first is the preview image. Gallery upload/removal saves as you perform it. **Cancel** does not undo an uploaded image.

For the listing image:

1. Expand **Media**.
2. Select its upload tile.
3. Choose an image you may publish.
4. Check the gallery result.

Continue with [Save the listing details](#save-the-listing-details).

## Save the listing details

1. Select **Save** in Listing details.
2. Check the saved summary.
3. Continue with [Check readiness and submit](#check-readiness-and-submit).

If Save is disabled, check the required copy and Media before retrying.

## Check readiness and submit

Read the AgentHub readiness checklist. Complete the named requirement before submitting: publication/public access, visible creator profile, active version, pricing or payment readiness are separate conditions.

Use [Publish a new version](/selling-and-payouts/publish-a-new-version) if an active version is missing. The linked launch, pricing and Stripe guides above cover those requirements.

1. Select **Submit to AgentHub** when offered.
2. Check for **In review**.

Submission is not immediate storefront visibility. An approved listing still needs a published/public source, visible creator profile, active version and active discovery. Paid listings also need ready payments.

Later changes can require the card's update or resubmit action so review uses the saved offer. Read that action and resulting status. If blocked, address the named checklist item instead of resubmitting the unchanged setup.
