Publish a saved agent snapshot with accurate release notes. Use the source agent whose version you intend to update.

A version is a saved snapshot of configuration. Publishing makes it available to buyers immediately; it does not wait for AgentHub storefront approval. Existing users stay on their current version until they choose to update.

The source agent's current reference knowledge can still affect answers. A configuration snapshot does not freeze every future answer.

## Prepare the update

Finish and save the intended instructions and other changes first. [Try the changed behavior in the builder](/build-your-agent/test-your-agent-while-you-build). Have a short, accurate explanation of what changed ready.

For a fictional café assistant, release notes might say:

> Clarified the booking-change boundary and made replies shorter. Updated the FAQ with the approved accessibility information.

Use notes describing changes you actually made. Publishing those words does not make the changes for you.

**Already in the publication window?** Continue with [Publish the snapshot](#publish-the-snapshot).

## Open version publication

1. Open [Home](https://app.alysium.ai/spaces).
2. Select the source agent.
3. Open **Deploy**.
4. Select **Share & Sell**.
5. Find **Version History**.
6. Select **Publish New Version**.
7. Continue with [Publish the snapshot](#publish-the-snapshot).

Home opens your active space, where you choose the source agent. If it asks you to sign in, sign in and open Home again if needed.

## Publish the snapshot

The published snapshot is permanent. **Cancel** in the publication window does not undo a version that has already been published.

1. Read the permanent-snapshot note.
2. Enter meaningful release notes in **What's new in this version?**.
3. Select **Publish Version**.
4. Wait for publishing to finish.
5. Check the new entry and notes in **Version History**.

Do not publish another version just to find out whether the first completed.

## Check the separate listing state

If you changed the storefront offer or discovery copy too, inspect the **AgentHub** card for its separate update/resubmit action. A version can be available to buyers while storefront review remains pending.

Follow [List your agent on Agenthub](/selling-and-payouts/list-your-agent-on-agenthub) for those listing changes. Use [Use your Creator Dashboard](/selling-and-payouts/use-your-creator-dashboard) for the relevant subscriber or listing record.

## If Publish Version is unavailable or fails

Release notes must contain text. If publishing reports an error, keep your notes and check the history and saved source changes. Retry only if the snapshot was not created.

Continue with the listing or buyer communication task that applies to the actual update. A successful publication is the new snapshot in history, not proof that every existing buyer has adopted it.
