Connect your space's payment account so it can accept card subscriptions and receive payouts. New payment setup currently supports US accounts. The [application for AgentHub storefront access](/selling-and-payouts/apply-to-sell-on-agenthub) is a separate process.

## Open payment setup

Open [Team settings](https://app.alysium.ai/spaces?settings=team), which opens your current space's settings. Select **Creator**, then **Setup**.

Under **Finish setting up**, find **Connect Stripe**. The checklist also tracks **Add a bank account**, **Provide tax information** and **Publish your first listing**.

## Start or continue onboarding

- Select **Set up Stripe** to begin payment setup.
- For an existing account with information still needed, select **Continue Stripe onboarding**.

The action opens Stripe's hosted setup. Provide the real business, identity, bank and tax details it requests for your account. Follow the requests shown there, then return to Alysium and select **Creator → Setup** again if needed.

If the checklist says Stripe has no information to collect right now, scroll below the checklist and payment explainer to the payment-status controls. Use **Refresh Stripe status** to check the existing account.

## Refresh the existing status

After working in Stripe, scroll down in **Setup** and select **Refresh Stripe status**. Wait for the check to finish and read the resulting message.

**Card subscriptions and payouts are ready.** confirms current payment readiness. A completed bank row or submitted tax information alone does not establish that full result.

If Alysium offers **Request payment capabilities**, select it to request the payment support the account still needs, then read the updated status. This action is separate from the hosted form. Use **Continue Stripe onboarding** when offered to supply information Stripe still needs.

Requested or pending messages can mean Stripe still needs information or is reviewing the account. You can [match the displayed status to its available action](/selling-and-payouts/what-your-stripe-status-means) if setup is not ready yet.

## Check the remaining setup steps

Bank and tax details are managed in Stripe. For a linked Express account, **Open Stripe Express** opens that account so you can manage those details and inspect payouts. It can be available before the first listing is published or while payment status needs a fresh check.

**Publish your first listing** is a separate checklist item. Its **Open builder** action opens an agent's Deploy area, or Home when there is no agent yet. Check that you have the intended agent open, then select **Share & Sell** to prepare its offer.

The checklist can still show unfinished listing work after payment readiness succeeds. **Setup complete** includes the listing step as well as payment setup.

## Check readiness before paid selling

Once the payment-status message confirms readiness, [set the subscription price and included usage](/selling-and-payouts/price-your-agent) and finish the intended channel's readiness checklist in **Share & Sell**. Payment setup itself does not publish an offer or approve an AgentHub listing.

If status later needs a fresh check, return to **Creator → Setup** and use **Refresh Stripe status** for the existing account.

If **Payment status is unavailable. Try refreshing it.** appears, use that refresh action and read its result. For an onboarding error, restriction, rejection, unreachable-account message or support-review state that you cannot resolve through the offered action, contact [billing@alysium.ai](mailto:billing@alysium.ai) with the visible message and space name. Keep bank details and identity documents in Stripe's secure forms.
