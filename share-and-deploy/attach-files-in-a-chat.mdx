<span id="attach-files-in-a-chat" />

Attach a document or picture to a message so you can ask the agent about its contents. Choose material you are allowed to share, and read any upload notice before sending personal or confidential information.

File input must be enabled for the agent. In a website widget, uploads also need history saving to be on. Questions about pictures need a model that can use image input.

## Choose a suitable file

You can attach PDF (`.pdf`), Word (`.docx` or `.doc`), Excel (`.xlsx` or `.xls`), CSV (`.csv`), plain-text (`.txt` or `.text`) and Markdown (`.md` or `.markdown`) files. Supported pictures are GIF (`.gif`), JPEG (`.jpeg` or `.jpg`), PNG (`.png`) and WebP (`.webp`). HTML, SVG and PowerPoint files are not supported.

| Limit | What it applies to |
|---|---|
| **25 MiB** | Each file. |
| **5 files** | One message. |
| **20 stored attachments** | One conversation, including files uploaded before you send a message. |

For example, attach a short document you know well and ask the agent to summarize its main points. You can compare the answer with the original.

<span id="find-the-attachment-action" />

## Attach the file

### In the main app

1. Open [Chat](https://app.alysium.ai/chat) and select the agent you want to ask.
2. Beside the message box, open the plus menu labelled **Add context or attachments** and select **Add files**.
3. Choose the file on your device and confirm your selection.
4. If an inline notice says the files will be processed by AI and shared with the agent's creator, read it. Select **Upload** to proceed or **Cancel** to discard this selection.

If that notice is not needed, uploading starts when you choose the file. The attachment appears above the message box with its upload or processing status.

### In a website widget

1. Open the agent's widget on the website where you use it, then select **Chat**.
2. Beside the message box, open the plus menu labelled **Add context or attachments** and select **Add files or photos**.
3. Choose the file on your device and confirm your selection.
4. Read the **Privacy Notice** if it appears. It explains AI processing. If it says a copy will be shared with the creator, the creator can see and keep that copy and may make it part of the agent's knowledge. Select **Upload** to proceed under the notice, or **Cancel** to stop this upload.

If the notice is not needed, uploading starts when you choose the file.

## Ask about the file

1. Wait for uploading and processing to finish. A filename alone does not mean the file is ready; check the status shown on the attachment.
2. Type a specific question, such as “Summarize the three main recommendations in this document.”
3. Select **Send message**, or press Enter.

The sent message includes the attachment, and the agent's reply follows. Sending stays unavailable while an attachment is still being prepared or has failed.

## Understand where the file goes

A chat attachment belongs to that conversation. It does not automatically become reusable knowledge for everyone who uses the agent. Any creator-sharing notice describes the additional copy you agree to share.

Removing a draft attachment chip alone does not confirm that a stored upload was deleted. In a widget, **Account** → **Your uploaded files** lets you delete stored uploads and check the result. You can [review the creator-copy and deletion steps](/widget-visitors/files-visitors-send-you) for more detail.

## If the file is not ready or the answer misses it

- **Uploading or processing fails:** read the error, use the failed attachment's remove button, then attach the file again.
- **The file is rejected:** correct the type, size or limit named in the message before attaching it again.
- **You canceled the upload notice:** attach the file again and choose **Upload** if you decide to proceed.
- **The answer misses a completed upload:** ask a specific question about the content you want the agent to use, then compare the reply with the file.

## Start a new conversation at the stored limit

When the conversation reaches 20 stored attachments, start a separate conversation for the next task. Earlier history and stored uploads remain; starting fresh does not delete them.

**In the main app:** use the chat-navigation sidebar. On a narrow screen, open it with **Conversations and agents**. Select **Conversations**, then **New conversation**. Check that you have a fresh transcript and empty message box, then attach the file for your new question.

**In a website widget:** wait for the current reply to finish. Open **Add context or attachments** beside the message box and select **New conversation**. The fresh transcript and empty message box are ready for your next question and attachment.
