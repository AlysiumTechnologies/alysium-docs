Use Chat to ask questions of agents you own or can access. You can continue a saved discussion or start a separate conversation for a new topic.

## Find an agent

1. Open [Chat](https://app.alysium.ai/chat), or select **Chat** in the app sidebar.
2. On **Select an Agent**, use search or browse the **Your Agents** and **Shared with You** lists shown.
3. Select the agent to open its chat.

If the hub says **We couldn't load your agents and conversations.**, select **Try again** to reload the list.

## Send a question

The welcome message explains what the agent can help with. A conversation starter is a suggested question: select one that fits your goal, or write your own in the message box.

1. Enter the question you want to ask. Include the details the agent needs for your task.
2. Select **Send message**, or press Enter. Use Shift+Enter for a new line without sending.
3. Check that your question appears in the transcript, then wait for the reply.

The reply appears beneath your question, or an error explains why it could not finish. Text left in the message box has not been sent.

To stay with the same topic, enter and send a follow-up. For example, ask “Can you explain that in two sentences?” to refer to the answer you just received.

## Open a saved conversation

Use the chat-navigation sidebar beside the conversation. On a narrow screen, select **Conversations and agents** to open it.

1. Select **Conversations**.
2. Use **Search conversations** if you need to find a particular discussion.
3. Select the saved conversation and read its recent messages.
4. Enter and send your next question in the message box.

Some retained conversations are read-only after access to an agent changes. You can read that history, but an old transcript does not grant permission to send another message. Follow any access notice shown in the chat.

Website widgets have their own account and history controls. You can [choose whether widget messages are saved and reopen a saved discussion](/widget-visitors/visitor-accounts-and-saved-history) from the widget.

## Start a fresh topic

For a separate task, use **New conversation** rather than adding it to an unrelated discussion.

1. Open the chat-navigation sidebar with **Conversations and agents** if you are on a narrow screen.
2. Select **Conversations**, then **New conversation**.
3. Check that the fresh transcript and empty message box are shown, then enter and send your new question.

This starts a separate discussion with the same agent. The earlier conversation and its stored uploads remain available according to your access; they are not deleted.

## Understand controls and access notices

When file input is enabled, **Add context or attachments** → **Add files** lets you [attach a document or picture to your question](/share-and-deploy/attach-files-in-a-chat). Wait for the attachment to finish processing before sending.

If an answer offers **Helpful** or **Not helpful**, you can [rate that individual answer](/share-and-deploy/rate-an-answer). This is separate from asking a follow-up or giving an overall conversation check-in.

If an access or billing notice blocks sending, use the action or explanation in that notice. If sending reports an error, read its result before trying the question again.
