A conversation check-in asks about the whole discussion. It is optional and appears occasionally in eligible main-app chats and visitor widgets. You do not have to find one after every chat.

Look for **How did this conversation go?** near the end of the transcript. This differs from the thumbs below an individual answer; use [Rate an answer](/share-and-deploy/rate-an-answer) to identify a particular reply.

## Give an overall score

Choose the score that describes the whole conversation:

| Choice | What happens next |
|---|---|
| **Not great** | Opens an optional follow-up about the problem. |
| **Okay** or **Great** | Can finish with a thanks message after the score saves. |

1. Select **Not great**, **Okay** or **Great**.
2. Wait for the score to save.
3. Check the thanks or saved state.

The score saves from your selection. You do not need to write a note to give an overall score. If **Not great** opens a follow-up and you want to explain, continue with [Add an optional note](#add-an-optional-note).

## Add an optional note

The note field identifies its audience: the agent's team and Alysium. Include the task detail they need to understand the problem.

For example, a fictional note might say: “I found the website code, but I could not tell whether publishing the page had applied the change.” It names the task and the point where the person got stuck.

1. Select a relevant reason if one fits.
2. Enter a note if you want to add detail.
3. Check the note's character counter.
4. Shorten the note if it exceeds the limit.
5. Select **Send** to submit the written note.
6. Check the resulting thanks or saved state.

The written note needs **Send**. Text left in the box has not been submitted just because the overall score saved. If the note is too long, Send may be unavailable until you shorten it.

## Continue chatting

Select **Minimize** if the check-in takes up space. This folds it so you can continue using the conversation.

You can keep chatting without completing the optional follow-up. The check-in is not required to get another answer or end a chat.

## If it does not save or does not appear

Read any save error. Use the displayed retry action when available, then check for a saved or thanks state.

If no check-in appears, there is no check-in you need to complete: these prompts are offered only occasionally to eligible conversations. For a specific response, use **Helpful** or **Not helpful** when those controls are available; follow [Rate an answer](/share-and-deploy/rate-an-answer).
