<span id="conversation-check-ins" />

If **How did this conversation go?** appears near the end of a chat, you can give optional feedback about the whole discussion. This differs from the thumbs below an individual reply, which let you [rate a particular answer](/share-and-deploy/rate-an-answer).

## Give an overall score

Select the choice that best describes the conversation:

| Choice | What happens |
|---|---|
| **Not great** | Saves your score and opens **What went wrong?** for an optional explanation. |
| **Okay** or **Great** | Saves your score and shows **Thanks for the feedback** after saving succeeds. |

The score saves from your selection; no note is required. Wait for the save result. A selected face alone does not confirm that the score saved—read any error shown on the card.

## Add an optional note

After **Not great**, you can explain the problem in **What went wrong?**. Your note goes to the space that owns the agent and to Alysium. The form identifies the space or the agent's creator, so read that audience information before sharing details.

1. Select a reason if one fits. The reason saves when you select it.
2. Write an optional note of up to **280 characters**. For example: “I asked which documents I needed, but the answer did not say where to upload them.”
3. Check the character counter and shorten the note if it exceeds 280 characters.
4. Select **Send** and wait for the thanks or save result.

You can select **Send** without writing a note. The written note needs Send even if your score and reason have already saved; typing alone does not submit it. Send is unavailable while the note is over the limit.

## Continue chatting

Select **Minimize** to fold the check-in. Select the same chevron again to reopen it; Escape also folds it.

You can keep chatting without completing the optional follow-up. Sending another message removes the check-in from the current page.

<span id="if-it-does-not-save-or-does-not-appear" />

## If feedback does not save

If the card shows **Didn't save. Retry**, select **Retry** and wait for the result. A failed save keeps your typed note, so you can check it before retrying.

A check-in is optional. If no card is shown, there is no overall score you need to submit; you can still rate a particular answer when its feedback controls are available.
