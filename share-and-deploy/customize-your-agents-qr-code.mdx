Change the colors, pattern and center image of the QR code people scan to open your agent. The appearance can change while the destination stays the same.

## Open the QR editor

1. Open [Home](https://app.alysium.ai/spaces) and select **Build** on the intended agent’s card.
2. Open **Deploy**. On a narrow screen, this navigation is at the bottom.
3. If the agent is not live, check the launch card. Complete any missing name or Agent Instructions in Build, then return and select **Make agent live**. Wait for the launch change to save.
4. Select **Share link + QR** and turn **Direct link** on. Wait for the address and QR code to appear.
5. Select **Try your live agent** to check the destination, then return and select **Customize QR** to expand the appearance controls.

## Choose colors

Under **What should it look like?**, select a swatch: **Text color**, **Brand color**, **Accent color** or **Black**. These use colors from the agent’s theme.

For your own colors, select **Add a new color**. The editor offers:

- **Solid color** for one code color, or **Gradient** for starting and ending colors.
- **Code** and **Background** controls for the pattern and the area behind it.
- A hue selector, saturation and brightness controls, and a hex field for an exact color.
- Gradient **Style** choices: **Left to right**, **Top to bottom**, **Diagonal**, **Reverse diagonal** and **Radial**.

Start with a dark code on a light background so it is easy to scan. Check the preview as you change the colors. Alysium may adjust a color for readability and show a message explaining the adjustment.

## Choose dots and a center

Under **How should the dots look?**, select **Rounded**, **Square**, **Dots** or **Petal**. Each choice changes the whole pattern.

Under **What goes in the middle?**, choose:

| Option | What appears in the center |
|---|---|
| **Nothing** | The code pattern, without a center image. |
| **Initials** | The agent’s initials. |
| **Agent picture** | The agent’s profile picture. The option indicates when no profile picture has been added. |
| **Upload** | A logo or photo you provide. |

To add a profile picture, open **Build → Profile**, scroll to **Agent Images**, and upload an **Avatar**. The [profile guide](/build-your-agent/set-your-agents-name-picture-and-description) explains the image controls.

**Surprise me** tries another combination of the available appearance choices. It keeps your custom colors and uploaded image available for later use.

## Upload a center image

Use a **PNG, JPG or WebP** image up to **2 MB**. Choose something recognizable when shown small.

1. Select **Upload** under **What goes in the middle?**.
2. Select the upload area and choose the file, or drop the file into that area.
3. Wait for the upload and saving to finish, then check the QR preview.

**Use a different image** replaces the uploaded center image. **Remove** clears it and switches the center to **Agent picture**; your profile picture stays in place.

## Save and download the result

QR appearance changes save automatically. Wait for **Saving…** to finish before distributing the result. If you see a save error, correct it and check the saved appearance by reopening the editor.

Once the QR preview is ready, choose **Download PNG** for an ordinary image file or **SVG** for an image that can scale for printing. **Copy image** is also available in browsers that support copying images. Downloading or copying the picture does not confirm that the appearance settings saved.

Open the downloaded image and scan it with a phone. Check that it opens the intended agent. Before printing many copies, test a sample at the size and distance people will use. Download and test a new image after making further changes.

## If a change does not work

If an upload fails, read its error and choose a supported image within the size limit. If the upload area specifically asks you to open the agent from a workspace, return to [Home](https://app.alysium.ai/spaces), select its **Build** button and reopen **Deploy → Share link + QR → Customize QR**.

If an appearance change fails to save, read the deployment error, check the saved result by reopening the editor, and repeat the intended change if needed.

If export says **Export failed — try again**, wait for the preview to be ready and try the export again. If the QR preview cannot load, you can still copy the separately displayed text link to share the agent.

For a printed code that is difficult to scan, try a simple, high-contrast appearance and test another sample before printing more copies.
