Change the picture people scan to open your agent. You can adjust colors, the shape of the code and what appears in its center without creating a new agent.

Use an agent whose deployment settings you can edit. [Make the agent live](/share-and-deploy/make-your-agent-live) and [enable its direct link](/share-and-deploy/share-your-agent-with-a-link-and-qr-code) first so you can check the destination as well as the picture.

**Already in the QR editor?** Continue with [Choose colors](#choose-colors), [Choose dots and a center](#choose-dots-and-a-center) or [Save and download the result](#save-and-download-the-result).

## Open the QR editor

1. Open [Home](https://app.alysium.ai/spaces).
2. Select the intended agent.
3. Open **Deploy**.
4. Select **Share link + QR**.
5. Select **Customize QR**.

Home opens your active space, where you choose the agent. If it asks you to sign in, sign in. Open Home again if needed.

The editor starts from your widget's appearance and shows a live QR preview. After each appearance change, check the preview and wait for **Saving…** to finish before changing another option.

It is fine to use the first version; continue with [Save and download the result](#save-and-download-the-result) if you want to keep it.

## Choose colors

Under **What should it look like?**, choose a color swatch or open the color editor using **Add a new color**.

- **Code** changes the dark pattern the camera reads.
- **Background** changes the area behind the pattern.
- **Solid color** uses one pattern color.
- **Gradient** blends starting and ending pattern colors. Choose each end color and the offered **Gradient style**.
- The color editor lets you pick a hue and adjust saturation and brightness. Use its hex color field if you already have an exact brand color.

For a simple starting choice, use a dark code on a light background. This is a suggested practice choice, not a required brand style. Colors may be adjusted slightly so cameras can read the code.

Check the preview after a change. Continue with [Choose dots and a center](#choose-dots-and-a-center) for another adjustment, or [Save and download the result](#save-and-download-the-result) when ready.

## Choose dots and a center

Under **How should the dots look?**, choose **Rounded**, **Square**, **Dots** or **Petal**. Each sample changes the complete code pattern; you do not have to configure each corner separately.

Under **What goes in the middle?**, choose the option you want:

| Option | Result |
|---|---|
| **Nothing** | Leaves the full code pattern visible. |
| **Initials** | Shows the agent's initials. |
| **Agent picture** | Uses its profile picture. If it has no picture, [add an agent picture](/build-your-agent/set-your-agents-name-picture-and-description) or choose another center. |
| **Upload** | Uses your own logo or photo. Continue with [Upload a center image](#upload-a-center-image). |

**Surprise me** offers another combination if you want to explore the available looks. Once you have the appearance you want, continue with [Save and download the result](#save-and-download-the-result).

## Upload a center image

Use **PNG, JPG or WebP** up to **2 MB**. The image becomes a small square, so choose something recognizable at a small size.

1. Select **Upload** under **What goes in the middle?**.
2. Select the upload area.
3. Choose the image file.
4. Check the preview.

You can drop the image into the upload area instead of selecting it. Then continue from the preview check in step 4.

Once uploaded, **Use a different image** replaces it. **Remove** removes the custom image and returns the center choice to the agent picture; it does not delete the agent's profile picture. Continue with [Save and download the result](#save-and-download-the-result).

## Save and download the result

The editor saves changes as you make them. Downloading creates an image file; it is not the action that saves editor settings.

1. Check the preview after your appearance changes.
2. Wait for **Saving…** to finish.
3. Select **Download PNG**.
4. Locate the downloaded image.
5. Scan it with a phone.
6. Check that it opens the intended agent.
7. Check it again at the size and distance people will actually use.

Test the downloaded image before printing more copies. If you make another change, wait for saving and download the updated result before testing it.

## If a change does not work

If an image upload fails, read the error and try a supported file within the size limit. If the upload area says it needs a workspace, open the agent from [Home](https://app.alysium.ai/spaces) and follow [Open the QR editor](#open-the-qr-editor) before retrying.

If the QR preview cannot load, the separately displayed text link remains a way to share the agent. Use [Share your agent with a link and QR code](/share-and-deploy/share-your-agent-with-a-link-and-qr-code) to copy it.

If a printed sample is hard to scan, return to a simple, high-contrast appearance and try again before printing more copies.
