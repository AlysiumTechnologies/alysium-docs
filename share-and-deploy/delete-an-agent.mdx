Use permanent deletion only when you want to remove the agent itself. If you only need to pause public chats, [unpublish it](/share-and-deploy/unpublish-your-agent) so you can keep editing it.

In your current space, deletion is an owner action. Being able to build or publish an agent is not the same as being able to delete it.

**Already in the deletion dialog?** Continue with [Read the consequences](#read-the-consequences) before exporting or confirming.

## Open the deletion panel

1. Open [Home](https://app.alysium.ai/spaces).
2. Select the intended agent.
3. Open **Deploy**.
4. Expand **Advanced**.
5. Check the agent's name.
6. Select **Delete Agent**.

Home opens your active space, where you choose the agent. If it asks you to sign in, sign in. Open Home again if needed.

Similar names can make it easy to select the wrong agent. Check the name again in the confirmation before continuing.

## Read the consequences

The confirmation explains what will be removed and what will be preserved. It lists the agent and its settings, past conversations, marketplace listing, and favorites/bookmarks as items affected by deletion. Reviews, ratings and marketplace history have separate preservation behavior described there.

The agent's widgets and links will stop working. Library documents are managed separately, so deleting an agent is not a way to clear every source file in your space. Other agents may still use those files.

If you need conversation records, continue with [Export conversations first](#export-conversations-first). Otherwise continue with [Confirm permanent removal](#confirm-permanent-removal).

## Export conversations first

Choose **Export as CSV** for a spreadsheet-friendly file, or **Export as Text** for a readable conversation archive. The deletion dialog exports the agent's conversations together.

1. Find **Export conversations** in the deletion dialog.
2. Select **Export Data**.
3. Select **Export as CSV** or **Export as Text**.
4. Wait for the download.
5. Open the downloaded file.
6. Check that it contains the records you intended to keep.

Exporting does not delete the agent. For a missing file, check your browser's Downloads and confirm that it finished downloading.

If export reports an error, read it before retrying the export. If you still cannot obtain records you need, select **Cancel** to leave deletion and use [Get help from a person](/help/get-help-from-a-person).

Continue with [Confirm permanent removal](#confirm-permanent-removal) only after checking any records you intend to keep.

## Confirm permanent removal

1. Read the full deletion warning.
2. Find the confirmation field labelled with the agent's name.
3. Type that name into the field.
4. Select **Delete Permanently**.
5. Wait for deletion to finish.
6. Follow the resulting navigation.

For example, if your fictional practice agent is named **Practice Café Helper**, type that name rather than your account name. Use the name shown in your own dialog.

**Cancel** closes the dialog before deletion. The final button remains disabled until the confirmation name is accepted. Treat this as permanent removal, not a reversible Draft status.

## Check completion or recover from an error

After successful deletion, the agent should no longer be available as an editable agent from Home.

If the final button is disabled, check the typed name and whether another action is still running. If an error appears, read it before retrying. If you are unsure whether deletion completed, return to [Home](https://app.alysium.ai/spaces) and check for the agent before repeating the action.

Do not delete Library sources because the agent was removed. Review their other uses first. Use [Storage limits](/knowledge-and-library/storage-limits) if your original goal was to free file storage.
