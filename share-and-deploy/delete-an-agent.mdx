<span id="delete-an-agent" />

Permanently deleting an agent removes the agent, its settings and its conversations. You cannot restore the agent from Trash.

If you want to pause public chats and keep the agent, open its **Deploy** tab, select **Launch settings**, then **Unpublish**. Wait for the status to save. You can [bring it back later](/share-and-deploy/unpublish-your-agent).

## Open the deletion panel

1. Open [Home](https://app.alysium.ai/spaces) and select **Build** on the agent you want to remove.
2. Open **Deploy**. On a narrow screen, this navigation is at the bottom.
3. Scroll down and expand **Advanced**.
4. Find **Danger Zone** and select **Delete Agent**.

Check the agent’s name in the confirmation dialog before taking any further action.

## Read the consequences

Deleting the agent stops its public link and website widgets from serving it. Its marketplace listing is withdrawn, while some reviews and marketplace history are preserved.

Files in your Library remain. If the agent received visitor uploads, their folder remains as an ordinary Library folder with **(agent deleted)** added to its name. Those files can still use storage. Review their other uses before removing them; [storage limits](/knowledge-and-library/storage-limits) explains what counts toward your allowance.

An agent with marketplace purchases cannot be permanently deleted. Unpublishing can stop public access to the source agent, but does not cancel purchases or subscriptions.

## Export conversations first

If you need to keep conversation records, check the actual downloaded content before deleting the agent. Exports can omit conversations or show **No content available** where Alysium displays readable messages. This can happen in both Text and CSV files.

1. In the dialog’s **Export conversations** section, select **Export Data**.
2. Select **Export as CSV** for a spreadsheet file or **Export as Text** for a plain-text file.
3. Wait for the download, then open the file from your browser’s Downloads.
4. Compare the conversations and message text you need with the records shown in Alysium.

If needed records or text are missing, select **Cancel** to leave deletion. Email [support@alysium.ai](mailto:support@alysium.ai) with the agent’s name, the export action you tried and what is missing from the file. Changing formats or retrying is not a reliable way to restore missing message text.

If the download itself fails, read the export alert and check your browser’s Downloads. You can retry a failed download, but cancel deletion if you still cannot obtain the records you need.

## Confirm permanent removal

1. Read the deletion warning and check the agent’s name again.
2. Type the displayed name into the confirmation field. Avoid extra spaces; capitalization does not need to match.
3. Select **Delete Permanently** and wait for the result.

The final button stays disabled until the name is accepted. **Cancel** closes the dialog before deletion begins; it is unavailable while deletion is running.

## Check completion or recover from an error

After a successful deletion, Alysium returns to Home. Check that the agent is no longer available there.

If **Delete Permanently** remains disabled, check the typed name and whether deletion is already running. If the dialog reports an error, read that message before trying again. A message that the agent has marketplace purchases means it cannot be hard-deleted; use **Cancel**, then unpublish it if you want to stop its public delivery.

If you are unsure whether deletion completed, check [Home](https://app.alysium.ai/spaces) for the agent before repeating the action.
