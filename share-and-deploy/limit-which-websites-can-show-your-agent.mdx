<span id="limit-which-websites-can-show-your-agent" />

Use **Allowed websites** to choose which website hostnames can load your embedded agent. A hostname identifies the website, such as `www.example.com`; it does not identify a particular page.

These rules apply to website embeds. Your agent’s separate direct link has its own switch.

## Open Allowed websites

1. Open [Home](https://app.alysium.ai/spaces) and select **Build** on the intended agent’s card.
2. Open **Deploy**. On a narrow screen, this navigation is at the bottom.
3. Select **Embed on a website** and scroll to **Allowed websites**.

You can prepare the saved list before making the agent live or installing it on a website.

## Choose the hostnames

Enter a hostname alone, without `https://` or a page path. For `https://www.example.com/help`, enter `www.example.com`.

Choose entries that cover the websites you intend to use:

| Entry | Websites it covers |
|---|---|
| `example.com` | Exactly `example.com`. Add `www.example.com` separately if you use that address. |
| `www.example.com` | Exactly `www.example.com`. |
| `*.example.com` | `example.com` and its subdomains, including `www.example.com` and `help.example.com`. |

Use the narrowest list that covers your installation. These rules cannot limit the widget to a particular page path.

## Save a restriction

1. Turn on **Restrict embedding to allowed websites**, changing **Any website** to **Restricted**. This reveals the website input.
2. Enter a hostname in **Add a website**, then select **Add website**.
3. Wait for the success feedback and check that the hostname appears in the saved list.
4. Repeat for the other hostnames you need.

Each addition and switch change saves automatically. A hostname still typed in the input has not been added. **Restricted** needs a nonempty saved list: an empty list allows embedding on any website even while the switch is on.

If the widget is already installed, open the published website and check that it loads the intended agent. If you have not installed it yet, make the agent live using **Make agent live** in the launch card, completing any missing name or Agent Instructions in Build first. Then copy the generated embed code from **Embed on a website**, paste the entire snippet once into your website’s custom-code facility before the closing body tag, and save and publish the website. Open the published page and check that it loads the intended agent. The [website installation guide](/share-and-deploy/put-your-agent-on-your-website) explains that separate task in more detail.

## Change or remove a rule

Use the remove control beside a hostname and wait for the change to save. Check the remaining list before leaving it. Removing the last entry allows any website; it does not block every website.

To allow any website while keeping the list for later, switch **Restricted** back to **Any website** and wait for saving to finish.

## Keep direct-link access separate

To stop sharing the standalone chat page, select **Share link + QR** in Deploy, turn **Direct link** off and wait for the change to save. Website embedding has separate controls and can remain available.

To stop this agent’s public link and website embeds together, select **Launch settings** and **Unpublish** or **Make private**. Wait for the saved status to change. You can [restore public delivery later](/share-and-deploy/unpublish-your-agent).

## Fix a rejected website or failed save

If a hostname is rejected, read the validation message. Check the spelling and remove the protocol, slashes and page path. For a duplicate, check whether the hostname is already in the saved list.

If adding a hostname fails, its text can remain in the input. Read the error, retry the addition and check for the saved row. For another save failure, reopen the panel to check the saved switch and list before repeating the change.

If your website is blocked, compare the hostname in its browser address with the saved entries, including `www` and other subdomains. If an unintended website can still load the widget, check that **Restricted** is saved and that the list is not empty.

If **Website settings could not be loaded** appears, select **Retry** and follow any connection guidance shown after another failure.
