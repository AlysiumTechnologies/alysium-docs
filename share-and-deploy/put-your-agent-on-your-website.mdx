<span id="put-your-agent-on-your-website" />

Add your agent to a published website so visitors can chat there. Alysium generates the installation code; you add it through your website's custom-code or script facility.

## What you need

You need access to add and publish custom code on the website. If someone else manages it, give them the exact generated code and the placement instructions here.

The website embed works independently of **Direct link**. You can keep the standalone link off while using the agent on your website.

## Open the embed panel

1. Open [Home](https://app.alysium.ai/spaces) and select **Build** on the intended agent's card.
2. In **Build → Settings**, check **Agent Name** and **Agent Instructions**. Fill any missing name or instructions, then wait for them to save automatically. Review **Welcome Message** for the greeting visitors will see.
3. Open **Design** to choose appearance and enabled features. Select **Save Changes** near the top and wait for **All Changes Saved**. The preview can show changes before they have saved.
4. Select the main **Deploy** tab. On a narrow screen, the main tabs are at the bottom.
5. Read the launch card. If **Finish in Build** lists a missing field, return to **Build → Settings**, complete it and let it save. Select **Make agent live** when available, including from **Needs attention**, and wait through **Making live…**. Check the confirmed summary for **Published** and **Public access on**. With the required fields present, the card shows **Live**.
6. Select **Embed on a website** and wait for the website settings to load.

An agent already showing Published and public access on has completed the delivery settings. If it still says **Needs attention**, finish any name or instructions listed under **Finish in Build**. You can [review the launch controls](/share-and-deploy/make-your-agent-live) for more detail.

## Copy the current code

Under **Add it to your site**, select **Copy code**. Wait through **Copying…** and check for **Copied!**.

Copy the entire code Alysium supplies for this agent. It includes the agent's identity and saved placement. If it includes a container element for an inline installation, keep that element with the script.

The default placement is a floating launcher at the bottom right. Existing installations can appear inline or fill the page, so the visible result depends on the generated code. Use the current code when replacing an installation.

If copying fails, select all the displayed code in its read-only box and copy it manually.

## Install it on your website

1. Open your website editor's facility for custom code or scripts.
2. Paste the whole snippet once, before the closing body tag where the editor supports that placement.
3. Save the website change and publish it using that service's publishing controls.
4. Open the published page. Find the agent in its installed position and open it if it uses a launcher.
5. Check that it is the intended agent. Ask a question it should answer and compare the response with your source material. This test uses normal AI resources.

A website draft or editor preview can differ from the published page. Check the page visitors will actually open.

The installed agent loads its saved Design settings. To change its appearance later, return to **Design**, make the change, select **Save Changes** and check the published result. Use freshly generated code when changing or replacing the installation itself.

## Choose which websites may use it

**Allowed websites**, in the same **Embed on a website** panel, can limit the hostnames where the embed is allowed. These rules apply to website embedding; they do not make a standalone Direct link private.

Choose the hostnames visitors actually use:

| Entry | What it allows |
|---|---|
| `example.com` | That exact hostname. It does not also allow `www.example.com`. |
| `www.example.com` | That exact www hostname. |
| `*.example.com` | The base `example.com` and its subdomains, including `www.example.com`. |

To restrict the installation:

1. Turn on **Restrict embedding to allowed websites**. The section changes from **Any website** to **Restricted** and reveals the entry field.
2. In **Add a website**, enter a hostname without `https://` or a page path.
3. Select **Add website** and wait for the saved hostname to appear. Add another rule if needed.
4. Reopen the published page on its actual hostname and check that the agent still opens.

Each switch change and website addition saves automatically. A restriction needs at least one saved hostname to take effect; turning it on with an empty list does not block all websites. Correct an invalid or duplicate entry using the displayed message. If an addition fails, the input remains so you can retry it.

You can [change or remove allowed websites](/share-and-deploy/limit-which-websites-can-show-your-agent) as your installation changes.

## Check completion

The published page shows the intended agent, it opens, and you have checked a useful reply. If restrictions are on, the page's actual hostname is allowed. Copying the code or saving a website draft alone does not confirm the installation.

## Find the cause if it does not appear

If the code is unavailable in Alysium, check the launch summary for Published and public access on, then wait for the website settings to finish loading. For **Website settings could not be loaded**, select **Retry**. If retry also fails, check your connection and try again.

If the code is available but the agent is missing from the published site, check that you published the website change and pasted the full code in the correct page or site-wide script location. Compare the page's hostname, including www or another subdomain, with the saved Allowed websites rules.

If an open panel shows **Access Denied**, recheck Published, public access and the website rules. For a session interruption that offers **Retry**, use that action and follow the message it returns. Other connection failures may show different guidance; [widget troubleshooting](/widget-visitors/when-the-widget-will-not-load) covers those visitor states.

For an unresolved installation problem, send [Alysium support](mailto:support@alysium.ai) the agent's name, published website address, action you tried and exact visible result.
