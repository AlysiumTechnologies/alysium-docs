Use answer feedback to tell the creator whether a particular reply helped. It is useful when an answer missed the question, was unclear or solved the problem well.

The creator must have enabled answer feedback, and the answer must be saved and eligible for rating. The controls sit below the completed answer in your chat or widget. Some layouts reveal older answers' controls when you hover over or focus the answer.

## Give a rating

**Helpful** is the thumbs-up control. **Not helpful** is the thumbs-down control. You can rate an answer without adding a reason or written note.

1. Find the answer you want to rate.
2. Select **Helpful** or **Not helpful** below it.
3. Wait for the selected state or thanks message.
4. Check that there is no save error.

The vote saves when you select it. If **Not helpful** opens a follow-up and you want to explain, continue with [Explain what went wrong](#explain-what-went-wrong).

## Explain what went wrong

The note field names its audience: the people responsible for the agent and Alysium. Feedback does not itself rewrite the agent's instructions, guarantee a corrected answer or create a support conversation.

A useful fictional note might say: “The answer explained setup but did not tell me where to find Upload Documents.” Keep passwords and private account information out of the note.

1. Select a reason if one fits.
2. Enter an optional note describing the problem.
3. Check the character counter beneath the note.
4. Shorten the note if it exceeds the limit.
5. Select **Send** to submit the written note.
6. Check for a thanks or saved state without a save error.

A selected reason saves when selected. A written note needs **Send**. If Send becomes unavailable because the note is too long, shorten it before trying again.

## Change or clear the vote

Select the other thumb to change your vote. Select the chosen thumb again to clear it. Check the resulting selected state and any save error.

## Ask for another answer

After a saved negative rating on the latest answer, **Try again** may appear. Select it if you want the agent to generate another response. This is a new chat request and can use credits or preview allowance.

**Retry** beside a failed feedback save has a different purpose: it retries saving the feedback. It does not ask the agent for another answer.

## If feedback did not save

If **Didn't save.** appears, the submission did not complete as intended.

1. Read the displayed error or guidance.
2. Select **Retry** when offered.
3. Wait for the saved state.
4. Check that the save error has cleared.

If controls are absent, look below a completed answer and check whether feedback is enabled. A separate [Conversation check-in](/share-and-deploy/conversation-check-ins) may appear to rate the whole discussion.
