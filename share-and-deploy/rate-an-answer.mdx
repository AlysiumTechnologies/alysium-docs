Use the thumbs below a completed answer to tell the agent's creator whether it helped. You can leave a rating on its own or explain a problem with a reason and an optional note.

In a website widget or direct-link chat, the creator chooses whether to show answer feedback. In Alysium [Chat](https://app.alysium.ai/chat), open the agent's conversation and find the answer you want to rate. Older answers may reveal their controls when you hover over the answer or move keyboard focus to it; on touch screens, the controls stay visible.

## Give a rating

1. Find the thumbs below the completed answer.
2. Select **Helpful** (thumbs up) or **Not helpful** (thumbs down).
3. Check the filled thumb and wait for **Thanks!**, which confirms the vote saved.

The vote saves when you select it. **Not helpful** also opens **What went wrong?**, where you can explain the problem.

## Explain what went wrong

Feedback is shared with the space or agent creator named in the form and with Alysium. Keep passwords and sensitive personal information out of your note.

1. Select a reason that fits, such as **Wrong information**, **Didn't answer my question** or **Hard to understand**. The reason saves when you select it.
2. If you want to add detail, type in **Add a note (optional)**. For example: “The answer gave me opening hours but did not answer whether the entrance is step-free.”
3. Check the counter and keep the note within **280 characters**. If it is too long, shorten it to enable **Send**.
4. Select **Send** to save the written note, then check for **Thanks!** without a save error.

You can close the follow-up or press Escape to dismiss it. Your saved vote and reason remain; a note you have not sent is not submitted.

## Change or clear the vote

Select the other thumb to change your rating. Select the filled thumb again to clear it. Wait for the change to save and check the resulting thumb state.

## Ask for another answer

After a saved negative rating on the latest answer, **Try again** may appear when the chat can send another request. Select it to ask the agent for another answer. This uses a new chat turn and can consume credits or a free-trial message.

This differs from **Retry** beside a feedback error: **Retry** saves your feedback again; **Try again** asks the agent to respond again.

## If feedback did not save

If **Didn't save.** appears, the feedback save failed. Select **Retry** if it is offered, then wait for the error to clear and **Thanks!** to confirm the save. Some errors do not offer a retry.

A rating applies to one answer. A separate [conversation check-in](/share-and-deploy/conversation-check-ins) can ask about the discussion as a whole.
