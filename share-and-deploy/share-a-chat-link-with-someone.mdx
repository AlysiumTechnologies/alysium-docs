Use **Share** in Chat to copy a link for starting a conversation with an agent. The link opens the agent's conversation experience; it does not export your private transcript.

You need chat access that includes sharing. The **Share** button appears only when that permission is available. A space currently contains only its owner, and invitations and member-role workflows are not available. A link does not create a teammate or grant editing access.

For the agent's standard public link and a downloadable QR image, use [Share your agent with a link and QR code](/share-and-deploy/share-your-agent-with-a-link-and-qr-code).

## Open the Share dialog

**Already in the intended agent's Share dialog?** Continue with [Choose the link's audience](#choose-the-link%E2%80%99s-audience).

**Already in the intended agent's chat?** Select **Share** in the chat header, then continue with [Choose the link's audience](#choose-the-link%E2%80%99s-audience).

From elsewhere:

1. Open [Chat](https://app.alysium.ai/chat), or select **Chat** in the sidebar.
2. Select the agent you want someone to use.
3. Select **Share** in its chat header.
4. Continue with [Choose the link's audience](#choose-the-link%E2%80%99s-audience).

The Chat link opens the general area; you choose your agent there. If Share is absent, use the builder's [public link guide](/share-and-deploy/share-your-agent-with-a-link-and-qr-code) for the supported public-sharing route when you can manage that agent. Copying a private workspace address does not grant access.

## Choose the link's audience

In **Get Link**, the audience options have different effects:

| Option | Who it is for |
|---|---|
| **Only People Added Can Access** | People who already have access to the agent. Copying this link does not add anyone or invite a new member. |
| **Anyone with the link** | Public recipients who can start an agent conversation without signing in. |

The restricted option is not a way to add colleagues to your owner-only space. Use **Anyone with the link** only when you intend public chat access. **Can Chat** describes what public recipients can do; it does not offer editing access or a copy of the agent's configuration.

1. Open the audience selector under **Get Link**.
2. Select the intended audience.
3. Check the displayed audience again.
4. Continue with [Copy the link](#copy-the-link).

## Copy the link

1. Select **Copy Link**.
2. Wait for **Copied!**.
3. Paste the link into the message or document you intend to share.

**Copied!** confirms the link reached your clipboard. There is no separate Save button for copying. The audience you selected determines the kind of link generated.

A public chat link does not make its recipient a member of your space. A restricted recipient still needs their own existing agent access.

## If the link does not work

If an error appears instead of **Copied!**, read it and retry copying. If a restricted recipient cannot open the link, check their existing access; sending the same link again will not grant it.

For the standard public destination, follow [Share your agent with a link and QR code](/share-and-deploy/share-your-agent-with-a-link-and-qr-code). Other tiles in the Share dialog are not substitutes for an available sharing feature.
