<span id="share-a-chat-link-with-someone" />

Copy a link that lets someone start a conversation with an agent. The link opens the agent; it does not share your conversation transcript.

## Open the Share dialog

1. Open [Chat](https://app.alysium.ai/chat) and select the agent you want someone to use.
2. Select **Share** in the chat header.
3. Find **Get Link** in the dialog.

<span id="choose-the-link’s-audience" />
<span id="choose-the-links-audience" />

## Choose who can use the link

Open the audience selector under **Get Link** and choose:

| Audience | What the link allows |
|---|---|
| **Anyone with the link** | Public recipients can start a conversation with the agent without signing in. **Can Chat** is the available permission. |
| **Only People Added Can Access** | The recipient must already have access to the agent. Copying or sending this link does not give someone new access. |

Choose **Anyone with the link** when you intend to let a new recipient chat with the agent. The link gives chat access, not permission to edit the agent's setup.

This choice applies to the link you copy now. Changing the audience later does not revoke links you have already copied or shared.

## Copy the link

1. Check the selected audience, then select **Copy Link**.
2. Wait for **Copying...** to change to **Copied!**.
3. Paste the link into the message or document you want to share.

**Copy Link** generates the link and puts it on your clipboard; there is no separate Save action.

If you also want a downloadable QR image, you can [use the agent's standard public link and QR code](/share-and-deploy/share-your-agent-with-a-link-and-qr-code).

## If the link does not work

If copying displays an error instead of **Copied!**, read the message, address the problem it describes and select **Copy Link** again.

For **Only People Added Can Access**, the recipient still needs existing access. Sending the link again will not grant it. If you want that person to start a public chat instead, return to **Get Link**, choose **Anyone with the link** and copy the new link.
