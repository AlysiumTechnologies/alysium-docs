A direct link opens your agent in its own chat page. A QR code opens that same destination when someone scans it with a phone. Use these for an email, social profile, printed sign or another place people need a way into the chat.

First [make the agent live](/share-and-deploy/make-your-agent-live). A QR image is a shortcut to a working link; downloading the image does not make an unpublished agent accessible. Use an agent whose deployment settings you can edit.

**Already in Share link + QR?** Continue with [Enable and copy the actual link](#enable-and-copy-the-actual-link). If Direct link is already saved and the correct address is visible, you can continue with [Save a QR image](#save-a-qr-image).

## Open the sharing panel

1. Open [Home](https://app.alysium.ai/spaces).
2. Select the intended agent.
3. Open **Deploy**.
4. Select **Share link + QR**.
5. Continue with [Enable and copy the actual link](#enable-and-copy-the-actual-link).

Home opens your active space, where you choose the agent. If it asks you to sign in, sign in. Open Home again if needed.

## Enable and copy the actual link

1. Turn on **Direct link** if it is off.
2. Wait for the setting to save.
3. Check that the link appears.
4. Select **Try your live agent**.
5. Check that the visitor experience opens the intended agent.
6. Return to the same agent's **Deploy → Share link + QR** panel.
7. Select **Copy** beside the displayed link.
8. Paste it into your intended destination.

Use the address Alysium displays for this particular agent. You do not need to assemble it from the agent's name or identify its internal number. Do not copy the builder's address bar for customers.

For example, a fictional café owner could paste the copied link into a message inviting customers to ask about the menu. Use your own information in the message.

To make a QR image too, return to the same agent's **Deploy → Share link + QR** panel. Continue with [Save a QR image](#save-a-qr-image).

## Save a QR image

1. Find the QR preview in the same panel.
2. Select **Download PNG**.
3. Locate the downloaded image on your device.
4. Scan that image with a phone.
5. Confirm it opens the intended agent.
6. Place the image on your sign, menu or other material.

If your browser offers **Copy image**, that copies the QR picture to the clipboard. **Copy** beside the text link copies the address instead. Use Download PNG when you need an image file to send to a printer or upload elsewhere.

The QR can be used as offered. To change its colors, dots or center image, open **Customize QR** and continue with [Customize your agent’s QR code](/share-and-deploy/customize-your-agents-qr-code).

## Check the shared result

The direct-link setting is saved, the address opens the intended visitor chat, and the downloaded QR opens that address when scanned. Keep the original downloaded file if you will reuse it.

Changing QR appearance does not create a different agent. If you later turn off **Direct link** or take the agent offline, printed QR images do not bypass that access setting.

A standalone link has separate access from [website embedding](/share-and-deploy/put-your-agent-on-your-website). **Allowed websites** rules govern the embed; they do not make the direct link private.

## If something is missing

If the address or QR is unavailable, check that the launch card is **Live**, Direct link is on, and settings have finished loading and saving. Use any displayed retry action for a failed load.

If copying fails, retry in your browser or use the displayed address. If the QR preview fails, you can still use the text link. If a previously shared link stops working, recheck the live and direct-link settings before distributing another copy.
