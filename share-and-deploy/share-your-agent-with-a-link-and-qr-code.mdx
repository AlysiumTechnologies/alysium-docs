<span id="share-your-agent-with-a-link-and-qr-code" />

A direct link opens your agent on its own chat page. A QR code takes people to the same agent when they scan it with a phone. Use the link in an email or social profile, and the QR image on a sign, menu or other printed material.

## Open the sharing panel

1. Open [Home](https://app.alysium.ai/spaces) and select **Build** on the intended agent's card.
2. In **Build → Settings**, check **Agent Name** and **Agent Instructions**. Fill any missing name or instructions and wait for them to save automatically.
3. Select the main **Deploy** tab. On a narrow screen, the main tabs are at the bottom.
4. Read the launch card. If **Finish in Build** lists anything missing, return to Settings, complete it and let it save. Select **Make agent live** when available, including from **Needs attention**, and wait through **Making live…**. Check the confirmed summary for **Published** and **Public access on**. With the required fields present, the card shows **Live**.
5. Select **Share link + QR** if it is not already selected.

If the agent is already Published with public access on, its delivery settings are complete. Finish any name or instructions still listed under **Finish in Build**. You can [review the launch settings](/share-and-deploy/make-your-agent-live) for more detail.

## Enable and copy the actual link

1. Turn **Direct link** on if it is off. Wait for the change to save and the address and QR preview to appear.
2. Select **Try your live agent**. It opens a new tab; check that the visitor page shows the intended agent. Try a question it should answer. This test uses normal AI resources.
3. Return to **Deploy → Share link + QR** for the same agent.
4. Select **Copy** beside the displayed address. **Copied!** confirms it reached your clipboard.
5. Paste the address into your message, profile or other destination.

Use the address Alysium displays. The builder's address opens your editing page rather than the visitor chat.

If copying fails, retry **Copy** or select the displayed address and copy it manually. Check the pasted address before sending it.

## Save a QR image

The QR preview and export controls are in the same sharing panel. You can use the supplied design without opening **Customize QR**.

1. Wait for the QR preview to finish loading. If you changed its appearance, let those settings finish saving and check that the changes remain when you reopen the panel.
2. Select **Download PNG** to save an image file, or **SVG** for a vector file that can scale for print. If your browser offers **Copy image**, it puts the QR picture on the clipboard instead.
3. Locate and open the saved file, then scan it with a phone. Check that it opens the intended agent.
4. Add the image to your material. Before printing a batch, test it at the final size and the distance people will scan it from.

**Copy** beside the address copies text; **Copy image** copies the QR picture. Downloading a QR file does not save appearance changes or turn the link on.

To choose colors, dots or a center image, open **Customize QR**. You can [customize the QR design](/share-and-deploy/customize-your-agents-qr-code) while preserving the same agent destination.

## Check the shared result

The Direct link setting is saved, the copied address opens the intended visitor chat, and the QR file opens that agent when scanned.

Turning **Direct link** off prevents new requests through that destination, including scans of already printed QR images. Unpublishing the agent or turning public access off also stops new public access.

Website embedding has separate controls. **Allowed websites** limits embeds; it does not make the direct link private. Turning Direct link off does not turn an embed off.

## If something is missing

If the address or QR is unavailable, check Published, public access on and the saved Direct link setting. Wait for settings to finish loading or saving. A failed settings load offers **Retry**. If a Direct link change fails, Alysium restores the previous setting and says **That change did not save — the link is unchanged.** Check the switch before trying again.

If the QR preview or export fails, read the displayed error. You can still copy and share the text address while the QR is unavailable. If a previously shared link stops opening, recheck the agent's publication, public access and Direct link settings.

If those settings are confirmed but Alysium still cannot supply the address, or the destination continues to fail, contact [Alysium support](mailto:support@alysium.ai) with the agent's name, the action you tried and the exact visible result.
