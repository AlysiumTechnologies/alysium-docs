<span id="unpublish-your-agent" />

Pause new requests through your agent's public link and website embed while you revise it. Unpublishing keeps the agent available to edit, along with its settings, existing conversations and Library materials. You can make it live again when you are ready.

[Permanent deletion](/share-and-deploy/delete-an-agent) removes the agent irreversibly and is a separate action.

## Find the controls

1. Open [Home](https://app.alysium.ai/spaces) and select **Build** on the intended agent's card.
2. Open the main **Deploy** tab. On a narrow screen, the main tabs are at the bottom.
3. Expand **Launch settings** in the launch card above the sharing choices. Read **Development status** and **Public access**.

## Choose the change you need

A public link or website embed needs both **Published** status and **Public access on**. Choose how much you want to pause:

| What you want | Control and effect |
|---|---|
| Return the agent to a draft while you edit | **Unpublish** changes Development status to **Draft**, closing its public link and embed. Public access remains a separate setting. |
| Keep Published status but close public access | **Make private** turns Public access off, closing its public link and embed. |
| Close only the standalone link and its QR destination | Turn **Direct link** off under **Share link + QR**. Website embeds keep their own access settings. |
| Keep the agent available on certain websites | Use **Allowed websites** under **Embed on a website**. These rules do not restrict the standalone link. |

If Development status is already **Draft**, or Public access is already off, that field already prevents new public requests to this agent. A previously downloaded or printed QR code cannot bypass those settings.

You can [limit the websites that show your agent](/share-and-deploy/limit-which-websites-can-show-your-agent) without pausing every installation. Removing every allowed website does not block all embeds; use **Unpublish** or **Make private** to pause them all.

## What happens to other sharing

An AgentHub listing requires a published, public source agent, so unpublishing or making the source private can make it unavailable there. Marketplace listing, channel and version settings remain separate under **Share & Sell**.

Purchased marketplace copies live in buyers’ own spaces. Unpublishing your source does not take every purchased copy offline, cancel a subscription or issue a refund.

## Stop public use

1. In **Launch settings**, select **Unpublish**, or **Make private** if you want to keep Published status.
2. Wait for the action to finish. There is no separate Save button.
3. Check the saved summary: **Unpublish** should leave Development status at **Draft**; **Make private** should leave **Public access off**.

The overall badge may say **Needs attention** because one launch setting is still on. Check the individual setting you changed to confirm the pause.

If you see **Development status did not save. Try again.** or **Public access did not save. Try again.**, reopen the same agent's **Deploy → Launch settings** and check the saved fields before retrying the intended action. A value changing on screen before saving finishes is not confirmation.

## Turn off only the direct link

1. In **Deploy**, select **Share link + QR**.
2. Wait for the settings to load, then turn **Direct link** off.
3. Wait for saving to finish and check that the switch remains off. The sharing address and QR disappear once the change is confirmed.

This closes the standalone link and QR destination while leaving website embed access separate. You do not need to change your website's embed code for this action.

If the settings fail to load, select the displayed **Retry**. If saving fails, the switch returns to its saved value and the message says **That change did not save — the link is unchanged.** Check that value before trying again.

## Bring it back

1. Finish your changes in **Build** and wait for them to save. For changes in **Design**, select **Save Changes** and wait for **All Changes Saved**.
2. Return to **Deploy**. If **Finish in Build** lists missing items, open the main **Build** tab, complete those items and return to **Deploy**.
3. If the card already shows **Live**, Published status and Public access are already on. Otherwise, select **Make agent live** to restore both settings together. Wait for the action to finish and check **Live**, **Published** and **Public access on**.
4. For the standalone link, select **Share link + QR**, turn **Direct link** on if needed and wait for it to save. Use **Try your live agent** to check the actual destination.

For an existing website embed, open your published website and check the agent there. Its installation and allowed-website rules still apply; you can [check the website setup](/share-and-deploy/put-your-agent-on-your-website) if needed. Making the agent live again does not publish a marketplace version or reactivate every paid channel.
