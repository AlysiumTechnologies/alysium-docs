Take an agent offline while keeping it available to edit. Use this when you need to pause a public release, change its setup or stop accepting public chats. Use an agent whose deployment settings you can edit.

Unpublishing is different from [permanently deleting an agent](/share-and-deploy/delete-an-agent).

**Already in Launch settings?** Continue with [Choose the change you need](#choose-the-change-you-need).

## Find the controls

1. Open [Home](https://app.alysium.ai/spaces).
2. Select the intended agent.
3. Open **Deploy**.
4. Expand **Launch settings**.
5. Read the development status and public-access state.
6. Continue with [Choose the change you need](#choose-the-change-you-need).

Home opens your active space, where you choose the agent. If it asks you to sign in, sign in. Open Home again if needed.

## Choose the change you need

| Control | Effect |
|---|---|
| **Unpublish** | Changes a Published agent back to Draft. |
| **Make private** | Turns public access off while leaving development status separate. |
| **Direct link**, under **Share link + QR** | Controls only the standalone sharing link and its QR destination. |
| **Allowed websites**, under **Embed on a website** | Controls which websites may load the embed. |

For a fictional café assistant, use Unpublish or Make private if you need to stop all public use while revising it. Continue with [Stop public use](#stop-public-use).

If you only want to stop the link/QR destination while keeping your website widget, continue with [Turn off only the direct link](#turn-off-only-the-direct-link). To change embed hosts, follow [Limit which websites can show your agent](/share-and-deploy/limit-which-websites-can-show-your-agent).

## Stop public use

1. Select **Unpublish** to return to Draft, or **Make private** to turn off public access.
2. Wait for the action to finish saving.
3. Check that the summary shows the intended development status or public-access state.
4. Check that the launch card no longer describes the agent as a live public agent.

There is no separate Save button. If saving fails, read the displayed error and retry rather than assuming the agent is offline.

## Turn off only the direct link

1. Open **Share link + QR** in the same agent's **Deploy** area.
2. Turn **Direct link** off.
3. Wait for the setting to save.
4. Check that the switch remains off.

This turns off the standalone destination without changing embed access. The website widget still depends on publication, public access and any saved website restrictions.

## What happens to other sharing

Public access affects both external links and website embeds. A printed QR code cannot keep an offline agent accessible.

An AgentHub listing also requires a published, public source agent, so taking the source offline can make its listing unavailable. Listing visibility and paid-access arrangements have their own controls under **Share & Sell**. Unpublishing does not confirm that a subscription has been cancelled or refunded.

The agent remains available to edit.

## Bring it back

After completing changes in Build and Design, return to Deploy and follow [Make your agent live](/share-and-deploy/make-your-agent-live). Confirm **Live**, then check the sharing method you intend to use.

A standalone link also needs Direct link on. A website embed has its own allowed-website rules; follow [Put your agent on your website](/share-and-deploy/put-your-agent-on-your-website) to check that installation.
