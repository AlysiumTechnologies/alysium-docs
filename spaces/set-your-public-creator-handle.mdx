Set the handle Alysium uses to identify work published by your space, including its skills. It is separate from your account name and each agent's name. Only the space owner can save a change.

If you want to rename the assistant itself, use [Set your agent's name, picture and description](/build-your-agent/set-your-agents-name-picture-and-description). For your personal name or picture, use [Update your profile and avatar](/getting-started/update-your-profile-and-avatar).

## Choose a valid handle

Use **2–32 characters**: lowercase letters, numbers and single hyphens between parts. Spaces, leading or trailing hyphens, and reserved names are not valid. Alysium normalizes uppercase to lowercase and checks whether the handle is available.

For example, a fictional workshop might try `river-workshop`. Choose a value appropriate to your own work; the example may already be taken.

The field shows the **@** symbol beside your handle. Enter the handle itself, rather than a full website address or email.

## Open the Handle field

**Already viewing the Creator handle card in Space Settings?** Continue with [Check the new value](#check-the-new-value).

1. Open [Team settings](https://app.alysium.ai/spaces?settings=team).
2. Select **Space Settings**.
3. Find the **Creator handle** card.
4. Review the current **Handle** value.
5. Continue with [Check the new value](#check-the-new-value).

The link opens settings for your active space. Check the space before changing its public identity.

## Check the new value

1. Enter your chosen handle in **Handle**.
2. Wait for the availability check to finish.
3. Read the result beneath the field.

If the value already matches the saved handle, no new save is needed. If it is invalid, taken or reserved, choose another value and repeat this check. If **That handle is available.** appears and you want to use it, continue with [Save the handle](#save-the-handle).

An availability result is not proof of saving. **Cancel** restores the previously saved field value before you save a new one.

## Save the handle

1. Select **Save handle** when available.
2. Wait for the save to finish.
3. Look for **Handle saved.**

You can reopen **Space Settings** to check that the normalized handle remains saved.

## Understand what remains linked

Changing the handle changes how the space's skills are addressed. It preserves existing links and does not require buyers to reattach the skill. It does not create a new account or rename your agents.

Saving a handle also does not finish marketplace or payment setup. Follow [Selling agents with Alysium](/about-alysium/selling-agents-with-alysium) if publishing an offer is your goal.

## If Save handle is unavailable or fails

An empty, invalid, taken or reserved value cannot be saved. The availability check or save in progress can temporarily disable the action. Read the field's explanation before retrying.

If a valid, changed value repeatedly fails, use [Get help from a person](/help/get-help-from-a-person). Include the handle you tried and the exact message. Only the space owner can save the change; a support request does not itself confirm it was saved.
