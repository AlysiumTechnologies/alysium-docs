Choose the public handle for work published by your space, including its skills. The handle belongs to the space; your personal profile name and each agent's name are separate. Only the space owner can save a change.

## Choose a valid handle

Use **2–32 characters**: lowercase letters, numbers and single hyphens between parts, such as `river-workshop`. A handle cannot contain spaces, start or end with a hyphen, or use consecutive hyphens. It must be available and cannot be a reserved name.

Alysium converts uppercase letters to lowercase and removes spaces at the beginning and end. Enter just the handle: the field already shows **@** beside it.

## Set and save your handle

1. Open [Team settings](https://app.alysium.ai/spaces?settings=team) for your active space. Select **Space Settings**, then find the **Creator handle** card.
2. Enter your chosen value in **Handle**. Wait for the availability check and read the result beneath the field. If it is invalid, taken or reserved, choose another value. **That handle is available.** means you can try saving it.
3. Select **Save handle** and wait for **Handle saved.** This saves the handle for this space.

Before saving, **Cancel** restores the previously saved value. To confirm a completed change, reopen **Space Settings** and check that the new, lowercase handle remains in the field.

<span id="understand-what-remains-linked" />

## What changes with the handle

The handle identifies your skills in names such as `river-workshop/skill-name`, helping agents distinguish your work from another creator's. Changing it updates how your skills are addressed. Existing skill attachments and buyers' access to those skills remain linked.

You can [change an agent's name and picture](/build-your-agent/set-your-agents-name-picture-and-description) or [update your personal profile](/getting-started/update-your-profile-and-avatar) separately.

<span id="if-save-handle-is-unavailable-or-fails" />

## If the handle cannot be saved

**Save handle** is unavailable when the value is unchanged or empty, while a check or save is running, or after an unsuccessful availability check. Read the field's message and correct an invalid, taken or reserved value. If the field already contains the saved handle, no new save is needed.

A handle can be claimed by someone else between checking and saving. If you see **That handle was just taken. Try another.**, choose a different one and check it again.

If a valid, changed handle repeatedly fails, email [support@alysium.ai](mailto:support@alysium.ai) with the handle you tried and the exact message displayed.
