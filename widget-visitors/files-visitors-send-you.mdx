A visitor can send a file through a website widget when the agent offers uploads. The agent can use the file to answer that visitor's question. The upload notice also tells the visitor whether the creator can see and keep a copy.

These upload steps apply to an embedded website widget. The standalone chat opened from an agent's direct link has no file-upload control in its message box, though its Account area can show existing uploads.

## Upload a file as a visitor

Choose a file you are allowed to share. For example, you could send an event timetable and ask the agent to list the afternoon activities.

PDF, Word, text or Markdown files, CSV or Excel spreadsheets, and PNG, JPEG, GIF or WebP images are supported. The limits are **25 MiB per file**, **5 files per message** and **20 stored files per conversation**. Files uploaded for a message you have not sent yet count toward the stored-file limit. You can [check the full list of file extensions](/share-and-deploy/attach-files-in-a-chat) for an unusual format.

1. Open the agent's widget on the website, then select **Chat**.
2. Select the plus menu beside the message box, labelled **Add context or attachments**.
3. Select **Add files or photos**, then choose the file on your device.

## Decide whether to upload

On your first upload, read the **Privacy Notice**. It explains that AI will process the file to answer you. Do not upload sensitive personal information such as identity documents, financial data or passwords.

When creator sharing is enabled, the notice also explains that the creator can see the file, keeps a copy and may add it to the agent's knowledge. Decide whether you want to share the file on those terms.

Select **Cancel** to stop this upload, or select **Upload** to proceed. If you have already accepted the same notice in this session, the upload can start without asking again.

Wait for the attachment to finish uploading and processing. Its name appearing beside the message box alone does not mean it is ready. Once it is ready, type your question and select the arrow labelled **Send message**, or press Enter. The agent can then use the attachment for its reply.

## What the creator receives

If the notice describes creator sharing, the creator can see and retain a copy of the file. They may later add suitable material to the agent's knowledge for use in other conversations. Uploading a conversation attachment does not automatically make it agent knowledge.

If you manage the agent, you can [review its widget upload and sharing options](/design-your-widget/turn-widget-features-on-or-off).

## Delete an upload as a visitor

Use the same agent and visitor session where you uploaded the file. The deletion confirmation explains that it also removes the copy shared with the creator and cannot be undone.

1. If a conversation is open, select **Back to browse**.
2. Open **Account**, then select **Your uploaded files**.
3. Find the file, open its file menu and select **Delete**.
4. Check the file name in the confirmation. Select **Keep** to cancel, or **Delete** to confirm.
5. Wait for **File deleted** before treating the file as removed.

Deleting the upload does not erase the conversation or retract an answer someone has already read. You can [read more about visitor data and privacy](/widget-visitors/visitor-data-and-privacy).

## If uploading or deletion fails

For a rejected upload, read the attachment's error and check its file type, size and the conversation limits above. If the error asks you to add the file again, remove the failed attachment and select it again through **Add files or photos**. Wait for processing to finish before sending your question.

If the gallery shows **Couldn't delete.**, select its **Try again** action and wait for **File deleted**. Use that final result to confirm deletion of the stored upload and any shared creator copy.
