Use a visitor account to return to saved conversations with an agent. In the website widget, you can also choose whether future messages are saved. Connected guests can change that choice too.

## Start in the right widget

Open the widget on the website where you use the agent. If a conversation is open, select **Back to browse** to return to the widget's navigation, then select **Account** at the bottom.

These are the visitor controls for that agent, separate from the creator's Alysium workspace.

## Create an account

1. In **Account**, select **Sign In**, then select **Sign up** on the sign-in form.
2. On **Get started**, enter your **Email** and a **Password** of at least eight characters.
3. Read the linked Terms of Service and Privacy Policy, then select **Continue**.
4. If **Check your email** appears, check the displayed address. Enter the six-digit code sent there in **Verification code**, then select **Verify & Create Account**.

Account creation may finish after Continue without showing the code screen. When it succeeds, the widget returns to chat. Reopen Account to see your signed-in profile and **Sign Out**.

Correct any displayed field or submission error before trying again. On the code screen, use **Resend code** if you need another code, or use the back control to correct the email address.

## Sign in to an existing account

1. In **Account**, select **Sign In**.
2. Enter the account's **Email** and **Password**. Complete any verification shown in the form.
3. Select **Sign in** and wait for the widget to return to chat.

Reopen Account to check that your signed-in profile and **Sign Out** appear. If the form reports an error, correct the details or verification it identifies before submitting again.

## Choose whether future messages are saved

The **Conversation history** switch applies to you and this agent:

- Turn it **on** to save future messages to history so you can resume later.
- Turn it **off** to stop future messages being added to that history.

1. Open **Account** and find **Conversation history**.
2. Wait for the preference to load, then set the switch to your choice.
3. Wait for the small saving spinner to finish. The setting saves automatically; there is no separate Save button.
4. Leave Account, then reopen it and wait for the preference to load again. Check that the switch still shows your choice.

If it returns to its earlier state, check again after reloading the website widget and reopening Account. Treat the change as saved only when that fresh check confirms it.

Turning history off does not erase earlier saved chats or uploaded files. Turning it back on does not recover messages that were not saved. You can [review the separate privacy and deletion choices](/widget-visitors/visitor-data-and-privacy) before deciding what to share.

## Resume a saved conversation

1. Open **Account** and select **View conversations**.
2. Select a conversation from the list.
3. Wait for its messages to appear, then read them before continuing the discussion.

If a conversation is missing, check that you are using the same agent and account. Guest history belongs to that browser, website and agent session; a different browser or website, or cleared browser data, may no longer have the same guest session. A visitor account helps you return across devices, but does not combine every agent's history into one list.
