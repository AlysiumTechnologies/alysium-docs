Use the widget's **Account** menu to sign in and manage whether future chat messages are saved. A visitor account helps you return to saved conversations. A connected guest can also change the conversation-history setting.

This guide covers the visitor menu inside an agent's website widget. It is separate from the creator's Alysium workspace.

## Start in the right widget

Open the agent on the website where you use it, then select **Account**. To use another agent's widget, open that agent's actual website or shared link. There is no single builder link that opens every visitor's saved history.

From Account, choose the task you need:

- [Create an account](#create-an-account) if you do not have one.
- [Sign in](#sign-in-to-an-existing-account) if you already have an account.
- [Choose future message saving](#choose-whether-future-messages-are-saved) to change Conversation history.
- [Resume a conversation](#resume-a-saved-conversation) to look for an earlier chat.

**Already on an account screen?** Continue with [Create an account](#create-an-account) or [Sign in to an existing account](#sign-in-to-an-existing-account), depending on your task. **Already signed in?** Go directly to [future message saving](#choose-whether-future-messages-are-saved) or [saved conversations](#resume-a-saved-conversation).

## Create an account

Use an email inbox you can open: the account-creation flow sends a verification code there. Your password must contain at least 8 characters.

1. Select **Sign up** from the available Account or sign-in screen.
2. Enter your email address in **Email**.
3. Enter a password in **Password**.
4. Use **Show password** if you need to check what you typed.
5. Read the Terms of Service and Privacy Policy linked beneath the form.
6. Select **Continue**.
7. On **Check your email**, check the displayed email address.
8. Find the six-digit code in that inbox.
9. Enter it in **Verification code**.
10. Select **Verify & Create Account**.
11. Wait for the signed-in experience.

If the email does not arrive, check your spam folder. Use **Resend code** when available. Follow any displayed error before trying another code. Never share your verification code or password in a chat.

After the account connects, continue with [Choose whether future messages are saved](#choose-whether-future-messages-are-saved) or [Resume a saved conversation](#resume-a-saved-conversation).

## Sign in to an existing account

1. Select **Sign in** from Account or the available account screen.
2. Enter the account's **Email**.
3. Enter its **Password**.
4. Submit with **Sign in**.
5. Wait for the account to connect.
6. Continue with [Resume a saved conversation](#resume-a-saved-conversation), or [change future message saving](#choose-whether-future-messages-are-saved).

Use the password-recovery option if offered when you cannot sign in. Google sign-in appears only where supported and may be absent inside an embedded website widget. Use the options shown.

Signing in and signing up are different flows. The email verification code in the previous section belongs to account creation.

## Choose whether future messages are saved

Wait for the widget's chat session to connect. This control can be used by connected guests as well as signed-in visitors.

1. Open **Account**.
2. Find **Conversation history**.
3. Wait for the control to become available.
4. Turn it on to save chats for later, or off to stop future messages being saved to history.
5. Wait for the update to finish.
6. Open **Data & Privacy**.
7. Check the displayed **Conversation Retention** state.

Turning history off does not erase earlier saved conversations or uploaded files.

If **Sign in to change** appears, the required session is not available yet. Use the offered sign-in route or resolve the connection, then return to this section. For a widget that cannot connect, follow [When the widget will not load](/widget-visitors/when-the-widget-will-not-load).

## Resume a saved conversation

1. Open **Account**.
2. Select **View conversations**.
3. Select an available conversation.
4. Read its recent messages before continuing the discussion.

If the chat is missing, check that you are using the same agent and account and that history was enabled when you used it. A different browser, different website or cleared browser data can change a guest session. Do not assume a guest chat will be available on another device.

A saved history setting does not promise that every conversation from every website will appear together.
