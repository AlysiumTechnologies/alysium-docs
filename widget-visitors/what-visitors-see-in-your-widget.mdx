The widget is the small chat experience installed on a website. Visitors use it to ask the agent questions; they do not need access to your agent builder.

They see the welcome content, chat controls and menu options available for that agent and their visitor session.

## Open the actual visitor view

Go to the published website where the widget is installed and open its chat launcher. Use that website's address rather than an Alysium builder link.

Creators can find installation controls from [Home](https://app.alysium.ai/spaces): select the intended agent, then open **Deploy** → **Embed on a website**. For a separate chat page, use the actual link under **Share link + QR**.

A separate chat link does not show whether the website installation works.

## Welcome, questions and chat

The welcome message explains what the agent helps with. Offered starter prompts are suggested questions visitors can choose to begin. For example, a fictional café might offer a menu question. The creator supplies the actual wording and information.

To send your own question:

1. Open **Chat** in the widget.
2. Enter a question in the message box.
3. Select the arrow button labelled **Send message**, or press Enter.
4. Wait for the response.

Ask a follow-up if you need more detail. A useful first-visit check is whether the expected agent is identified, the question appears in Chat and a response arrives.

## What the navigation means

| Item | Where it takes the visitor |
|---|---|
| **Home** | The welcome experience. |
| **Chat** | The conversation. |
| **Account** | The visitor's account menu. |

Account can provide **Conversation history**, **View conversations**, **Your uploaded files**, **Data & Privacy**, **About This Agent** and help options. Available features and links depend on creator configuration and the visitor's session.

Optional **Conversations** or **Resources** items may also appear in the main navigation.

## What the creator controls

| Creator area | What it supplies |
|---|---|
| **Build** | Instructions, knowledge, welcome message and starter questions. |
| **Design** | Appearance and enabled widget features. |
| **Deploy** | Public link or website installation. |

Opening Account does not let a visitor change the agent's instructions. Visitor account and history choices apply to the visitor's chat experience.

When checking a release, read the welcome content, try an offered starter, send your own question and inspect Account. Check the installed widget as well as the builder preview.

If the welcome wording is wrong, review the intended agent's Build settings. For appearance or feature differences, check its saved Design choices.

## If the visit does not work as expected

Use [When the widget will not load](/widget-visitors/when-the-widget-will-not-load) for a missing launcher or connection problem.

For a missing old conversation, check the same agent, account and website. A session on one website does not automatically follow a visitor to another. [Visitor accounts and saved history](/widget-visitors/visitor-accounts-and-saved-history) explains those limits.

[Your widget on phones](/widget-visitors/your-widget-on-phones) covers a phone visit.
