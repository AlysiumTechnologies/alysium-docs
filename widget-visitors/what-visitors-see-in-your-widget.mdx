Visitors use the widget to ask your agent questions from a website. They see its greeting, conversation and visitor menus, while you manage its instructions and reference information in the agent builder.

## Open the actual visitor view

Visit the published website where the widget is installed. With a floating installation, select its chat launcher. An inline or fullscreen installation may show the chat directly instead.

To find this agent's website installation settings, open [Home](https://app.alysium.ai/spaces), select **Build** on its card, then open **Deploy → Embed on a website**. A separate chat page is available through **Share link + QR** when sharing is enabled. That page gives visitors another way to chat; checking it does not verify the website installation.

## Welcome, questions and chat

The opening **Home** view introduces the agent through its greeting and description. If starter questions are enabled, visitors can select one to send that question. Write starters that match questions the agent's information can answer.

To ask something else, open **Chat**, type in the message box, then select **Send message** or press Enter. Use Shift+Enter for a new line. The question appears in the conversation, followed by the agent's response when it finishes.

A useful first-visit check is whether the widget identifies the intended agent, explains what it helps with and responds to a question it should be able to answer. Compare the answer with the information you supplied.

## What the navigation means

| Item | What visitors use it for |
|---|---|
| **Home** | Read the introduction and choose an offered starter question. |
| **Chat** | Write messages and read the conversation. |
| **Conversations**, when enabled | Open the conversation list through a main-navigation shortcut. |
| **Account** | Find history, uploaded files, privacy information and help. |

During an active chat, the bottom navigation is hidden. Select **Back to browse** in the chat header to return to the browsing view, then open Account or another navigation item.

**Account** contains:

- **About This Agent**, with public information about its creator.
- **Conversation history**, the visitor's preference for saving conversations.
- **View conversations**, which remains available even when the main Conversations shortcut is hidden.
- **Your uploaded files**, the visitor's own uploaded-file gallery.
- **Data & Privacy** and **Help & Support**.
- **Terms & Privacy**, if the creator has supplied a policy link.

Help & Support opens the creator's external help page when one is configured; otherwise it opens the widget's contact screen. These are help routes supplied for that agent. The visitor's Account menu is separate from your agent-building settings.

## What the creator controls

| Creator area | What it supplies |
|---|---|
| **Build** | The agent's instructions, reference knowledge, welcome message and starter questions. |
| **Design** | The widget's appearance, menu details and feature switches. |
| **Deploy** | Public access, sharing and website installation. |

Visitors also make choices within their own experience. For example, turning off **Conversation history** makes their conversation temporary and hides attachments. The [visitor account guide](/widget-visitors/visitor-accounts-and-saved-history) explains saved-history limits and account choices.

For a release check, read the opening content, try an offered starter or your own question, and inspect Account on the published website. If the welcome text is wrong, correct it in Build settings. If a menu detail or feature differs from what you intended, check the saved Design configuration.

## If the visit does not work as expected

If a floating launcher is missing, check the published page and try reloading it. A visitor who still cannot open the chat should give the website owner the page address and describe what happened. The owner can [check the installation and access settings](/widget-visitors/when-the-widget-will-not-load).

An open panel may show an access or connection message instead of a conversation. Read that message; use **Retry** if it is offered.

For missing old conversations, check the same agent, website and visitor account. A visit on one website does not guarantee access to history on another. The [phone guide](/widget-visitors/your-widget-on-phones) explains the phone layout and the differences between an installed widget and a separate chat link.
